02違いのまとめ

  • スイッチ方式は、エレコムが「メカニカル（静音赤軸／リニア）」、HHKBが「静電容量無接点方式（Type-Sのキー構造）」と記載されています。エレコムのページには、キーピッチ19.0mm、キーストローク3.8mm、アクチュエーションポイント2.0mm、動作圧45gも記載されています。
  • 接続は、エレコムがUSB有線（USB-Aプラグ、ケーブル長約1.8m）のみ、HHKBがBluetoothとUSB（Type-C）の両方で、Bluetoothは4台まで登録できると記載されています。HHKBのページには、電源は単3形乾電池2本またはUSB給電（メーカー公式ページ）とも記載されています。
  • キー配列とサイズは、エレコムが「日本語配列、108キー、フルサイズ」で幅約446×奥行約137×高さ約33mm、HHKBが日本語配列で約29.4×12×4cmと記載されています。HHKBのページには、テンキーがない旨の注記があります。重量は、エレコムのページに約1,055g（ケーブル含まず）と記載されています。HHKBのページには重量の記載がありません。
  • 付属品は、エレコムが「キーボード本体、USB-A - USB Type-Cケーブル」、HHKBが「USBケーブルは付属しない（メーカー公式ページの記載）」と記載されています。
  • 機能は、エレコムのページにNキーロールオーバー対応、最大1,000Hzのレポートレートが記載されています。HHKBのページにはキーマップ変更機能と、傾き3段階調節が記載されています。
  • 電源は、エレコム Leggero 有線のページに「USBバスパワー」、HHKB Professional HYBRID Type-Sのページに「単3形乾電池2本またはUSB給電（メーカー公式ページ）」と記載されています。HHKB Professional HYBRID Type-Sのページには、乾電池とUSB給電をどう使い分けるかの詳しい説明がありません。
  • キー数は、エレコム Leggero 有線のページに「108キー」と記載があります。HHKB Professional HYBRID Type-Sのページにはキー数の数字がなく、注意点に「キー数が少なく、慣れるまで操作に戸惑うことがある」と書かれています。
  • 対応OSは、エレコム Leggero 有線のページに「Windows 11/10、macOS Tahoe 26、ChromeOS（USB-Aポート搭載機）」と記載されています。HHKB Professional HYBRID Type-Sのページには、対応OSの記載がありません。

  • 静かな環境でタイピングしたいなら：エレコム Leggero 有線は「静音赤軸（リニア）」、HHKB Professional HYBRID Type-Sは静粛性（Silent）を意識した「Type-S」のキー構造と記載されています。どちらのページにも、打鍵音の大きさを示す数値は記載がありません。

05スペック用語のかんたん解説

比較表に出てくる用語を、一般的な意味で簡単に説明します。数値や対応の有無は各商品ページ・Amazon商品ページでご確認ください。

▸リニア（静音赤軸）

メカニカルスイッチの種類のひとつで、一般に、押し込む途中でカチッとした引っかかりがなく、まっすぐ沈む感触のタイプを指します。静音タイプは、底打ちの音を抑える工夫がされた軸とされます。エレコム Leggero 有線のページに「静音赤軸（リニア）」と記載され、タクタイル圧（引っかかりの圧力）はないと書かれています。

▸静電容量無接点方式

キーを押した際の電気的な容量の変化を検知する方式です。一般に、金属の接点が触れ合う方式とは構造が異なるとされます。HHKB Professional HYBRID Type-Sのページに「静電容量無接点方式（Type-Sのキー構造）」と記載されています。エレコム Leggero 有線はメカニカルのため、方式が異なります。

▸ストローク・アクチュエーションポイント・動作圧

ストロークはキーを押し込める深さ、アクチュエーションポイントは入力が認識される深さ、動作圧はキーを押すのに必要な力の目安です。エレコム Leggero 有線のページに「3.8mm」「2.0mm」「45g」と記載されています。HHKB Professional HYBRID Type-Sのページには、これらの数値の記載がありません。

▸Nキーロールオーバーとレポートレート

Nキーロールオーバーは、同時に押した複数のキーを、それぞれ認識できる性能を示す表記です。レポートレートは、キーボードがパソコンへ入力を知らせる回数（1秒あたり）で、一般に数値が大きいほど反映が早いとされます。エレコム Leggero 有線のページに「Nキーロールオーバー対応」「最大1,000Hz」と記載されています。HHKB Professional HYBRID Type-Sのページには記載がありません。

▸日本語配列と108キー

日本語配列は、かなの刻印や変換キーなどを含む、日本向けの配列です。108キーは、テンキーを含むフルサイズの配列を指す表記です。エレコム Leggero 有線のページに「日本語配列、108キー、フルサイズ（かな表記を省いたキー印字）」と記載され、HHKB Professional HYBRID Type-Sのページは日本語配列と記載されています。

  • 必要なキー：テンキーが必要かを決める。エレコム Leggero 有線はテンキー付きの108キー、HHKB Professional HYBRID Type-Sにはテンキーがないと記載されている。
  • 接続方式：エレコム Leggero 有線は有線のみ、HHKB Professional HYBRID Type-SはBluetooth（4台まで登録）とUSB（Type-C）。使うパソコンのポートと、切り替えたい端末の数を確認する。
  • 電源とケーブル：HHKB Professional HYBRID Type-Sは乾電池2本またはUSB給電で、USBケーブルは付属しない。USB-C対応のケーブルが手元にあるかを確認する。
  • 設置スペース：エレコム Leggero 有線は幅約446mm、HHKB Professional HYBRID Type-Sは約29.4cm。机の上に置く場所と、キーボードトレイの幅を確認する。
  • キー印字：エレコム Leggero 有線はかな表記を省いたキー印字。かな入力をふだん使う場合は、慣れが必要になる可能性がある。
  • 対応OS：エレコム Leggero 有線にはWindows、macOS、ChromeOSの記載がある。HHKB Professional HYBRID Type-Sのページには対応OSの記載がないため、使うOSで問題がないかを確認する。

07よくある質問

Q.エレコム LeggeroとHHKB Professional HYBRID Type-Sの主な違いは何ですか？

各商品ページの記載では、スイッチ方式がメカニカル（静音赤軸）と静電容量無接点方式、接続がUSB有線のみとBluetooth＋USB（Type-C）、サイズが幅約446mmの108キーフルサイズと約29.4×12×4cmです。付属品も、USBケーブルが付属するエレコムと、付属しないHHKBで異なります。配列は、どちらも日本語配列です。

Q.ワイヤレスで使えるのはどちらですか？

HHKBのページに、Bluetoothとの接続（4台まで登録）とUSB（Type-C）接続が記載されています。エレコムのページには、USB有線（USB-Aプラグ、ケーブル長約1.8m）と記載されており、ワイヤレス接続の記載はありません。

Q.テンキーはありますか？

エレコムのページに「日本語配列、108キー、フルサイズ」と記載されています。HHKBのページには、テンキーがなく数字入力が多い作業には向かない場合があるという注記があります。

Q.どちらを選べばいいですか？

接続方式、サイズ、スイッチ方式を基準にすると整理しやすくなります。有線でテンキー付きのフルサイズを使いたいならエレコム、BluetoothとUSB-Cを使い分けたい、コンパクトな配列や静電容量無接点方式を使いたいならHHKBのページが候補になります。キーボードの見方の基本はキーボードの選び方ガイドにまとめています。

Q.USBケーブルは付属しますか？

エレコム Leggero 有線のページの付属品欄に「キーボード本体、USB-A - USB Type-Cケーブル」と記載されています。HHKB Professional HYBRID Type-Sのページには「USBケーブルは付属しない（メーカー公式ページの記載）」と書かれています。

Q.静かなのはどちらですか？

打鍵音の大きさを示す数値は、どちらのページにも記載がありません。エレコム Leggero 有線は「静音赤軸（リニア）」、HHKB Professional HYBRID Type-Sは静粛性（Silent）を意識した「Type-S」のキー構造と記載されています。

Q.重さと大きさはどう違いますか？

エレコム Leggero 有線のページに、幅約446×奥行約137×高さ約33mm（スタンド時は高さ約42mm）、重量約1,055g（ケーブル含まず）と記載されています。HHKB Professional HYBRID Type-Sのページには、本体サイズ約29.4×12×4cmの記載があり、重量の記載はありません。

Q.Macでも使えますか？

エレコム Leggero 有線のページの対応OSに「macOS Tahoe 26」と記載があります。HHKB Professional HYBRID Type-Sのページには、対応OSの記載がありません。お使いのOSで使えるかは、メーカーの案内でご確認ください。

Q.複数のパソコンを切り替えて使えますか？

HHKB Professional HYBRID Type-SのページにBluetoothで4台まで登録できると記載されています。エレコム Leggero 有線は有線のみで、ワイヤレス接続や複数台の登録についての記載がありません。

Q.キーを入れ替えたり、カスタマイズしたりできますか？

HHKB Professional HYBRID Type-Sのページにキーマップ変更機能が記載されています。エレコム Leggero 有線のページには、ホットスワップなどカスタマイズ性についての記載がありません。

Q.キーボード選びの基本を知りたいときは？

スイッチの種類や配列の考え方は、キーボードの選び方ガイドでご覧いただけます。
