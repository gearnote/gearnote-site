01まず知っておきたいスマートホーム機器の種類

スマートホーム機器は、家電を操作する機器と、状態を知らせる機器に大きく分けられます。以下は一般的な説明で、実際の機能は機種ごとに異なります。

種類しくみ一般的な特徴気をつけたい点
スマートプラグコンセントと家電の間に差し込み、電源の入り切りをアプリや音声で行う電源ボタンを押さなくても動き出す家電を、タイマーやスケジュールで操作できる定格電流を超える家電はつなげない。電源を入れても動き出さない家電には向かない
スマート電球既存の照明器具のソケットに取り付け、明るさや色をアプリや音声で変える調光・調色ができる機種があり、器具の交換が不要口金（E26・E17など）と、器具の対応条件を確認する
開閉センサードアや窓の開け閉めを、本体と磁石の位置関係で検知する開閉の通知や、ほかの機器の自動化のきっかけに使われるハブが必要な機種がある。取り付けの隙間の条件を確認する
人感センサー人や動きを検知して、照明などと連動させる人が動くと照明をつけるなどの自動化に使われる検知範囲・角度、設置場所の条件を確認する
温湿度計（スマート）温度と湿度を測り、アプリで確認・記録する加湿器やエアコンなどとの連携に使われる通知や遠隔確認にハブが必要な機種がある

どれが優れているかではなく、自動化したい内容と、すでに持っている機器との組み合わせで選ぶのが一般的です。

02スペック表で見る7つのポイント

1. 接続方式（Wi-Fi・Bluetooth・Matter・Zigbee・Threadなど）

接続方式によって、ハブの要否や、遠隔操作の可否が変わります。仕様表では、SwitchBot プラグミニがBluetoothとWi-Fi、Tapo P110MがMatterとWi-Fi、Amazonベーシック スマートプラグが2.4GHzのWi-Fi、Philips Hue ホワイト E26がBluetoothとZigBee（Hueブリッジ経由でも操作可能）、Aqara 人感センサー P2がThreadとBluetooth 5.0、Tapo T110・T100・T310がSub-1GHz（922MHz）と記載されています。

2. Wi-Fiの周波数帯（2.4GHzのみの機種に注意）

スマートホーム機器の多くは、2.4GHz帯のWi-Fiにつなぎます。5GHz帯のみの設定では、つながらない場合があります。仕様表では、Amazonベーシック スマートプラグが2.4GHz、Tapo P105が2.4GHz（Bluetooth 4.2は初期設定時のみ）、Tapo P110Mが2.4GHz Wi-Fiのみ、Tapo L510Eが2.4GHzのみ、Amazonベーシック スマートLED電球がWiFi（2.4GHz）と記載されています。ルーターの設定は、Wi-Fiルーターの選び方ガイドもご覧ください。

3. ハブ（ブリッジ）が必要かどうか

ハブは、機器とスマートフォンやスマートスピーカーをつなぐ中継機器です。ハブ不要の機種は、単体で使い始められますが、ハブがあると使える機能が増える機種もあります。仕様表では、Tapo P105・Tapo L510Eが「ハブ不要」、Tapo T100・T110・T310が「Tapoスマートハブ（別売り）が必須」、Eufy Security Entry Sensorが「HomeBase 2またはHomeBase S380（別売）が必要」、SwitchBot 開閉センサーが通知にSwitchBotハブミニ／ハブ2との連携が必要と記載されています。

4. スマートプラグの定格（電流・W数）と電力モニタリング

スマートプラグには、つなげる機器の上限があります。上限を超える消費電力の家電は、つなげません。仕様表では、SwitchBot プラグミニが定格電流15A・1500W（最大）、Tapo P110Mが最大負荷1500W・15A、Tapo P105が最大負荷1000W・10Aと記載されています。Tapo P110Mは、電力モニタリング（消費電力の確認・電気料金の目安の表示）に対応と記載されています。

5. スマート電球の口金・明るさ・色温度・調光

電球は、口金のサイズが合わないと取り付けられません。明るさは、ルーメン（lm）で表されます。仕様表では、Tapo L510E・Amazonベーシック スマートLED電球・SwitchBot LED電球がE26口金・800lm、Philips Hue ホワイト E26がE26口金・1,100lm（75W相当・2700K）、Philips Hue フルカラー E17がE17口金・470lm（4,000Kの場合・40W相当）と記載されています。色の範囲は、SwitchBot LED電球がRGBCWマルチカラー（1600万色）、Hue フルカラーが1,600万色以上・色温度1,000〜20,000K・調光0.2〜100%と記載されています。

6. センサーの検知範囲・検知角度・設置方法

人感センサーは、検知できる距離と角度が決まっています。設置場所の広さと向きを確認します。仕様表では、Tapo T100が最大7m・検知角度120°、Aqara 人感センサー P2が最大7m（Aqara Homeで10mまで延長可能）・水平170°／垂直45°、SwitchBot 開閉センサーが最大検知距離5m・最大感知角度が水平90°／垂直55°と記載されています。開閉センサーでは、Eufy Entry Sensorが、センサー本体とマグネットの距離を4cm未満にして底面をそろえて取り付ける、と注意が記載されています。

7. 電池寿命・サイズ・連携サービス・保証

センサー類は電池式のものが多く、電池の種類と寿命が使い勝手に関わります。仕様表では、SwitchBot 開閉センサーが単4電池×2で通常3年、Eufy Entry SensorがCR123Aで最大2年、SwitchBot 温湿度計プロが単3電池×2で約1年、SwitchBot 温湿度計が単4電池×2で約1年と記載されています。連携サービスは、SwitchBot プラグミニがAlexa・Google Home・Siri・IFTTT・SmartThings、Tapo P110MがMatter（Alexa・Google Assistant・Apple Siri対応）と記載されています。保証は、Tapo P105とP110Mがメーカー保証3年、Hue ホワイトが2年と記載されています。

07使う場面別の選び方

まずは1台、家電の入り切りをスマホで操作してみたい

スマートプラグが候補です。ハブ不要と記載されたTapo P105は最大負荷1000W・10Aで、SwitchBot プラグミニは15A・1500W（最大）と記載されています。つなぐ家電の消費電力が、定格に収まるかを先に確認します。2機種の違いはTapo P105とP110Mの違いも参考になります。

電気の使用量も見える化したい

Tapo P110Mは、電力モニタリング（消費電力の確認・電気料金の目安の表示）に対応と記載されています。表示は目安で、実際の請求額とは異なる場合があります。

異なるメーカーの機器をまとめて操作したい

Matterなどの共通規格に対応した機器が候補です。Tapo P110MはMatter対応、Philips Hue フルカラー E17もMatter対応と記載されています。Aqara 人感センサー P2は、Threadに対応と記載されています。操作するアプリやコントローラーの条件は、各メーカーの案内で確認します。

照明の明るさや色を、アプリや音声で変えたい

スマート電球が候補です。口金がE26ならTapo L510E・Amazonベーシック スマートLED電球・SwitchBot LED電球・Philips Hue ホワイト E26、E17ならPhilips Hue フルカラー E17が記載されています。色を変えたい場合は、フルカラーやRGBCWの記載を確認します。照明器具の違いはLED照明の選び方ガイドもご覧ください。

ドアや窓の開け閉めを、スマホに通知したい

開閉センサーが候補です。SwitchBot 開閉センサーは通知にSwitchBotハブが必要、Tapo T110はTapoスマートハブが必須、Eufy Security Entry SensorはEufyのHomeBaseが必要と記載されています。防犯の用途では、防犯カメラの選び方ガイドもご覧ください。

人が入ったら照明をつけるなど、自動化したい

人感センサーが候補です。Tapo T100は最大7m・120°、Aqara 人感センサー P2は最大7m・水平170°／垂直45°（人感＋光センサー）と記載されています。SwitchBot 人感センサーProは、商品名にミリ波レーダー搭載・静止検知対応と記載されています。3機種の違いはSwitchBot 人感センサーPro・Aqara P2・Tapo T100の違いで整理しています。

部屋の温度や湿度を、スマホで確認したい

スマート温湿度計が候補です。SwitchBot 温湿度計プロは温度−20〜80℃・湿度0〜99%、Tapo T310は精度が温度±0.3℃・湿度±3%RH、SwitchBot 温湿度計は最小表示0.1℃／1%RHと記載されています。通知や遠隔確認に必要なハブも、あわせて確認します。

すでに使っているスマートスピーカーで操作したい

連携サービスの記載を確認します。SwitchBot プラグミニはAlexa・Google Home・Siri・IFTTT・SmartThings、Amazonベーシック スマートプラグはWorks with Alexa認定、Aqara 人感センサー P2はApple HomeKit・Google Home・Amazon Alexaと記載されています。スマートスピーカー自体の選び方は、スマートスピーカーの選び方ガイドもご覧ください。

11失敗しやすいポイントと、安全に使うための基本

✅ こうすると失敗しにくい

  • Wi-Fiの周波数帯（2.4GHz）と、ルーターの設定を先に確認する
  • ハブやブリッジが必要かを、仕様表の記載で確認する
  • スマートプラグは、つなぐ家電の消費電力が定格に収まるかを計算する
  • 電球は、口金のサイズと、器具の対応条件を確認する
  • センサーは、検知範囲・角度と、取り付ける場所の条件を確認する
  • 電池式の機器は、電池の種類と交換の時期を把握しておく

⚠️ 避けたいこと

  • ヒーターやストーブなど、電熱器具を無人でスマートプラグから自動オンにする
  • 定格を超える消費電力の家電を、スマートプラグにつなぐ
  • 口金や器具の対応を確認せずに、スマート電球を取り付ける
  • ハブが必須のセンサーを、ハブなしで購入する
  • 防水ではない機器（Eufy Entry Sensorなど）を、屋外に設置する
  • 取扱説明書にない方法で、機器を分解・改造する

13よくある質問

Q.スマートプラグは、どんな家電につなげますか？

定格に収まる消費電力で、電源を入れると動き出す家電が向いています。当サイトの仕様表では、SwitchBot プラグミニが15A・1500W（最大）、Tapo P110Mが最大負荷1500W・15A、Tapo P105が最大負荷1000W・10Aと記載されています。電源ボタンを押さないと動かない家電には、向かない場合があります。

Q.ヒーターなどの暖房器具に、スマートプラグを使ってもよいですか？

消費電力が大きく、無人での運転にも注意が必要です。当サイトの仕様表では、Tapo P105の最大負荷が1000W・10A、Tapo P110Mが1500W・15Aと記載されています。つなぐ機器の消費電力と、機器側の取扱説明書の注意事項を、必ず確認してください。

Q.スマートホーム機器は、5GHzのWi-Fiでも使えますか？

2.4GHz帯のみに対応する機種があります。当サイトの仕様表では、Tapo P110Mが2.4GHz Wi-Fiのみ、Tapo L510Eが2.4GHzのみ、Amazonベーシック スマートプラグ・スマートLED電球が2.4GHzと記載されています。ルーターの設定やスマートフォンの接続帯域は、取扱説明書で確認してください。

Q.ハブがなくても使えますか？

機器によって異なります。当サイトの仕様表では、Tapo P105とTapo L510Eが「ハブ不要」、Tapo T100・T110・T310が「Tapoスマートハブ（別売り）が必須」、Eufy Entry SensorがHomeBase 2またはHomeBase S380が必要と記載されています。購入前に、ハブの要否を確認してください。

Q.Matterとは何ですか？

異なるメーカーのスマートホーム機器を、共通の方法でつなぐための規格です。当サイトの仕様表では、Tapo P110MがMatter対応（Alexa・Google Assistant・Apple Siri対応）、Philips Hue フルカラー E17がMatter対応と記載されています。操作に必要なアプリやコントローラーは、メーカーの案内で確認してください。

Q.スマート電球は、今の照明器具にそのまま付けられますか？

口金のサイズが合っていれば、取り付けられる場合があります。当サイトの仕様表では、Tapo L510E・Amazonベーシック スマートLED電球・SwitchBot LED電球・Philips Hue ホワイトがE26口金、Philips Hue フルカラーがE17口金と記載されています。調光器や密閉型の器具などとの相性は、各メーカーの案内で確認してください。

Q.電球の明るさ（lm）は、どう見ればよいですか？

ルーメン（lm）は、電球の明るさを表す単位です。当サイトの仕様表では、Tapo L510E・Amazonベーシック・SwitchBot LED電球が800lm（60W相当）、Philips Hue ホワイトが1,100lm（75W相当）、Philips Hue フルカラー E17が470lm（4,000Kの場合・40W相当）と記載されています。相当ワットは目安で、部屋の広さや用途に合わせて選びます。

Q.人感センサーは、どのくらいの範囲を検知できますか？

機種により、距離と角度が異なります。当サイトの仕様表では、Tapo T100が最大7m・120°、Aqara 人感センサー P2が最大7m・水平170°／垂直45°（Aqara Homeで10mまで延長可能）、SwitchBot 開閉センサーの最大検知距離が5mと記載されています。設置場所の広さと向きを確認してください。

Q.開閉センサーの電池は、どのくらいもちますか？

メーカーの試験条件による目安が記載されています。当サイトの仕様表では、SwitchBot 開閉センサーが単4電池×2で通常3年（1日あたり80回の開閉などの測定値）、Eufy Security Entry SensorがCR123Aで最大2年と記載されています。開閉の回数や気温により、変わります。

Q.スマート温湿度計は、ハブなしで使えますか？

表示や記録だけなら使える機種があります。当サイトの仕様表では、SwitchBot 温湿度計プロは、天気予報・アラート通知・遠隔確認にSwitchBotハブ製品が必要、SwitchBot 温湿度計は連携サービスにハブが必要と記載されています。Tapo T310はTapoスマートハブが必須と記載されています。

Q.電力モニタリングの電気料金は、正確ですか？

目安として表示されます。当サイトの仕様表では、Tapo P110Mが電力モニタリング（消費電力の確認・電気料金の目安の表示）に対応と記載されています。実際の請求額とは異なる場合があるため、節電の意識づけなどの参考として使います。

Q.屋外でも使えますか？

機器ごとに異なるため、仕様表で確認します。当サイトの仕様表では、Eufy Security Entry Sensorが室内専用（防水非対応）、SwitchBot 温湿度計が防水防塵構造ではないと記載されています。屋外での使用可否や設置条件は、各メーカーの案内に従ってください。
