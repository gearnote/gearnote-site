エアフライヤーのサイズ・寸法の書き方｜ハンドル・順番

エアフライヤー（ノンフライヤー）は、前にバスケットを引き出す形が多く、ハンドルの分だけ奥行の数字が変わります。数字の順番もメーカーでばらばらです。メーカーの表記と、GEARNOTE運営の計算で整理しました。

執筆・確認：GEARNOTE運営（H＆C）　データの時点：2026年11月16日（集計：2026年11月26日）

販売状況：このページに出てくるアイリスオーヤマ FV-M30Aの商品ページには、現在「販売状況のお知らせ」（確認時点でAmazonでの新品の販売・在庫を確認できなかった旨）が付いています。このページでは仕様を読むための資料として掲載を続けています。購入を検討する場合は、Amazonの商品ページで最新の状況をご確認ください。

01同じ機種でも、ハンドルを含むかで奥行が変わる

COSORI PRO LE 4.7Lの製品仕様は、寸法を2行で書いています。「36.5奥行き x 27.4幅 x 30.7高さ cm（ハンドルと排気口を含む）」と「29.6奥行き x 27.4幅 x 30.7高さ cm（ハンドルを含まない）」です（COSORIの製品仕様）。幅と高さは同じで、奥行だけが6.9cm違います（GEARNOTE運営の計算）。

COSORI TurboBlaze 6.0Lも同じ書き方で、奥行は「34」（ハンドルを含まない）と「40」（ハンドルを含む）です（COSORIの製品仕様）。差は6cmです。置き場所の奥行は、ハンドルを含む数字で比べます。このページの集計でも、COSORIの2台はハンドルを含む数字を使っています。

エアフライヤーは、消費者庁の家庭用品品質表示法の電気機械器具の品目一覧（17品目）にありません（消費者庁：電気機械器具の品目一覧）。寸法の書き方は、メーカーがそれぞれ決めています。

順番の注記がないCOMFEE' 4LとNinja Crispiは、並べ直しに使っていません。3つの数字のいちばん長い辺は、COMFEE' 4Lが37.2cm、Ninja Crispi（Lサイズセット時）が29cmです。

04「幅」の数字が説明文と仕様表で合わない例

Ninja ミニエアフライヤーAF080Jの公式ページは、スペックで「サイズ (高さ x 幅 x 奥行) 202 x 276 x 247 mm」と書いています。同じページの説明文には「幅20cmだから、台所のちょっとしたスペースに置けて取り出しやすい。」とあります（Ninjaの公式ページ）。

仕様表どおりに読むと、幅は27.6cmです。説明文の20cmは、仕様表の最初の数字202mm（高さの位置）に近い数字です。どちらの読み方が正しいかは、このページからはわかりません。このページの集計は、仕様表の見出しどおりに読んでいます。置き場所が狭いときは、3つの数字のいちばん長い辺（27.6cm）が収まるかで確かめると、読み方の違いに左右されません。

Ninja Crispiの公式ページは「製品サイズは幅・奥行・高さがすべて30cm以内」と書いています（Ninjaの公式ページ）。商品ページの表記はLサイズセット時29×25×29cm、Sサイズセット時22×21×22cmで、順番の注記はありませんが、どの辺も30cm以内です。

05バスケットを引き出す分と、ケーブル

前にバスケットを引き出す形の機種は、使うときに本体の前に空きが要ります。今回確かめたメーカーのページには、引き出す長さや、周りに空ける距離の数字はありませんでした。このページでは数字を載せていません。機種の取扱説明書で確かめます。

電源コードの長さは、アイリスオーヤマFV-M30Aが約1.0m（アイリスオーヤマの仕様）、Ninja AF080Jが約1.8mです（Ninjaの公式ページ）。コンセントからの距離も、置き場所を決める条件になります。

オーブンとの違いはエアフライヤーとオーブンの違い、選び方はエアフライヤーの選び方ガイドで扱っています。

06よくある読み違い

  • 最初の数字は幅：GEARNOTE掲載9台のうち、幅から書くのは3台だけでした。COSORIは奥行から、Ninja AF080Jは高さから書きます。
  • 奥行はハンドル込み：COSORIは、ハンドルを含まない奥行も並べて書いています。差は4.7Lで6.9cm、6Lで6cmです。
  • 説明文の「幅」と仕様表の「幅」は同じ：Ninja AF080Jは、説明文の幅20cmと、仕様表の幅276mmが合いません。
  • パッケージサイズは本体の大きさ：BRUNO BOE122のパッケージサイズは、箱の寸法です。
  • 置き場所は本体の寸法で足りる：バスケットを引き出す前の空きは、外形寸法に入っていません。

07買う前に測るところ・確かめるところ

  • 置き場所の幅・奥行と、上の棚や吊り戸棚までの高さ。
  • 本体の前に、バスケットを引き出す空きがあるか。
  • 仕様表の寸法の順番と、ハンドルを含むかの注記。
  • 3つの数字のいちばん長い辺が、置き場所のいちばん狭い辺に収まるか。
  • コンセントの位置と、電源コードの長さ。重さは質量の一覧。

08出典と、確認できなかったこと

このページの一次資料の事実は、2026年11月16日時点で、各ページを実際に開いて確認した、メーカーの仕様ページと、消費者庁の資料にもとづきます。商品ごとの寸法は、GEARNOTEの各商品ページの「メーカー公開仕様」の欄に載せた表記（出典と確認日は各ページに記載）を、そのまま読み取って使っています。仕様は改定されることがあります。

  • バスケットを引き出す長さと、周りに空ける距離は、今回開いたメーカーのページに数字がありませんでした。
  • Ninja AF080Jの幅（説明文の20cmと仕様表の276mm）は、どちらが正しいかを確かめられていません。
  • COMFEE' 4LとNinja Crispiは順番の注記がないため、置く面積の集計に使っていません。BRUNO・COMFEE'の寸法は、商品ページのメーカー公開仕様の欄の表記で、今回メーカーのページを開き直してはいません。
  • GEARNOTEに掲載したエアフライヤーのうち4台は、商品ページにメーカー公開仕様の寸法がまだないため、数えていません。

10よくある質問

Q.エアフライヤーの寸法は、どの順番で書かれていますか？

メーカーで違います。GEARNOTE掲載9台では、奥行×幅×高さが3台、幅×奥行×高さが2台、幅×高さ×奥行が1台、高さ×幅×奥行が1台、注記なしが2台でした。

Q.ハンドルは寸法に入っていますか？

機種で違います。COSORI PRO LE 4.7Lは、ハンドルと排気口を含む奥行36.5cmと、ハンドルを含まない奥行29.6cmを両方書いています。

Q.エアフライヤーの高さはどれくらいですか？

GEARNOTE掲載で順番がわかる7台の高さは20.2〜32.4cmでした（GEARNOTE運営の計算）。

Q.置き場所には、本体の寸法だけあれば足りますか？

バスケットを前に引き出す機種は、前に空きが要ります。引き出す長さの数字は、今回確かめたメーカーのページにはなく、取扱説明書で確かめます。
