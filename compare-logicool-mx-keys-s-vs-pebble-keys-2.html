02違いのまとめ

  • 電源は、MX KEYS SがUSB-C充電式（急速充電対応）、PEBBLE KEYS 2が単4形アルカリ乾電池2本（装着済み）と記載されています。
  • バッテリーの持続は、MX KEYS Sがフル充電後にプリセット設定で最長10日間、バックライトをオフにして最長5か月間、PEBBLE KEYS 2が電池寿命36か月（使用環境による）と記載されています。
  • バックライトは、MX KEYS Sのページにスマートバックライトの記載があります。PEBBLE KEYS 2のページには、バックライト機能の記載がありません。
  • Logi Bolt USBレシーバーは、MX KEYS Sのパッケージ内容に含まれると記載され、PEBBLE KEYS 2のページには別売りと記載されています。Easy-Switchで切り替えられる台数は、どちらも最大3台です。
  • 大きさは、MX KEYS Sが高さ131.63×幅430.2×奥行き20.5mmで810g、PEBBLE KEYS 2が415gの薄型・軽量と記載されています。PEBBLE KEYS 2は日本語配列84キー（テンキーなし）、MX KEYS Sは型番KX800sGRが日本語（QWERTY）配列と記載されています。
  • キーの構造は、PEBBLE KEYS 2 K380sのメーカー公開仕様の欄にシザー式（パンタグラフ）、キーピッチ18mm、ストローク1.5mm、荷重60gと記載されています。MX KEYS Sのページには「パーフェクト・ストロークキー」という名称の記載はありますが、キーピッチやストロークなどの数値は掲載されていません。
  • センサーと表示灯は、MX KEYS Sのメーカー公開仕様の欄に、手を感知してバックライトをオンにする近接センサー、周辺光で明るさを調節するライトセンサー、Caps Lockとバッテリーのインジケーターライトが記載されています。PEBBLE KEYS 2 K380sのページには、これらの記載がありません。
  • 対応OS（Bluetooth）は、MX KEYS SがWindows 10・11以降、macOS 10.15以降、Linux、ChromeOS、iPadOS 14以降、Android 8.0以降（Windows・macOS以外は基本機能のみ）、PEBBLE KEYS 2 K380sがWindows 10/11、macOS 11以降、iPadOS 14以降、iOS 14以降、Android 9.0以降、ChromeOS、Linuxと記載されています。対応する最低バージョンが機種ごとに異なります。

  • 毎日長時間タイピングをする人
  • PC・タブレットなど、複数デバイスを切り替えて使いたい人

▸PEBBLE KEYS 2 K380sが向いている人

PEBBLE KEYS 2のページでは、415gの薄型・軽量で、単4形乾電池2本で電池寿命36か月とされる、84キーの日本語配列キーボードと説明されています。

  • タブレットやスマホで文字入力を快適にしたい人
  • PC・Mac・iPadを1台のキーボードで使い分けたい人
  • 充電の手間がない電池式を好む人

04場面別の選び方

使う場面ごとに、各商品ページの記載で見ておきたい点をまとめました。あくまで掲載情報にもとづく目安です。

  • デスクに据え置いて長時間入力するなら：MX KEYS Sは幅430.2mm・重量810gと記載されたアルミニウムとプラスチックの本体で、スマートバックライトとUSB-C充電に対応します。MX KEYS Sのページの「向いている人」欄にも、毎日長時間タイピングをする人が挙げられています。
  • カバンに入れて持ち歩くなら：PEBBLE KEYS 2 K380sは415g（電池含む）の薄型・軽量と記載され、本体サイズは279×16×124mmです。このサイズ表記は幅×奥行×高さの順とされており、厚みは16mmとみられるとページに注記があります。MX KEYS Sは810gで、持ち歩きには大きめの本体です。
  • 暗い部屋で使うことがあるなら：MX KEYS Sのページにはスマートバックライトの記載があります。PEBBLE KEYS 2 K380sのページにはバックライト機能の記載がなく、「向いていない人」欄にも暗所向けの機能を求める人が挙がっています。
  • 充電の手間と電池交換、どちらが気にならないか：MX KEYS SはUSB-C充電式で、フル充電後にプリセット設定で最長10日間、バックライトをオフにして最長5か月間と記載されています。PEBBLE KEYS 2 K380sは単4形アルカリ乾電池2本（装着済み）で電池寿命は36か月とされています。ケーブルでの充電が苦にならないか、電池を買い置きしたいかで選び分けられます。
  • Windows・Mac・iPadを1台で使い分けるなら：どちらも、Easy-Switchで最大3台のデバイスを切り替えられると記載されています。PEBBLE KEYS 2 K380sはcommandキー・optionキーを搭載し、日本語配列84キーです。MX KEYS Sの型番KX800sGRは、メーカー公開仕様の欄に日本語（QWERTY）配列と記載されています。

05スペック用語のかんたん解説

比較表に出てくる用語を、一般的な意味で簡単に説明します。数値や対応の有無は各商品ページ・Amazon商品ページでご確認ください。

▸Easy-Switch

ボタンやキーを押して、登録済みの機器を切り替えるロジクールの機能名です。MX KEYS SとPEBBLE KEYS 2 K380sのどちらのページにも、最大3台と記載されています。使う前に、各機器とのペアリングを済ませておく必要があります。

▸Logi Bolt USBレシーバー

Bluetoothの代わりに使える、専用USBレシーバーによる接続方式です。MX KEYS Sのメーカー公開仕様の欄では、他のロジクールUSBレシーバーとは互換性がないと書かれています。PEBBLE KEYS 2 K380sのページでは、レシーバーは別売りで、Unifyingは非対応と記載されています。

▸パンタグラフ（シザー式）

キーの下にX字状の支えを入れて、キーを均一に押し下げやすくした構造のことです。薄型のキーボードで多く使われます。PEBBLE KEYS 2 K380sのメーカー公開仕様の欄に、シザー式（パンタグラフ）と記載されています。

▸キーピッチとストローク

キーピッチは隣り合うキーの中心の間隔、ストロークはキーを押し込める深さを指します。PEBBLE KEYS 2 K380sは、キーピッチ18mm、ストローク1.5mm、荷重60gと記載されています。数値が違うと打ちやすさの感じ方が変わりますが、感じ方には個人差があります。

▸USB-C充電式

MX KEYS SのUSB-Cは、本体のバッテリーを充電するための端子です。パッケージ内容にUSB-C充電ケーブル（USB-A - USB-C）が含まれると記載されています。PEBBLE KEYS 2 K380sは電池式のため、この端子はありません。

07よくある質問

Q.MX KEYS SとPEBBLE KEYS 2の主な違いは何ですか？

各商品ページの記載では、MX KEYS Sは充電式でスマートバックライトを備え、重量は810gです。PEBBLE KEYS 2は電池式（単4形乾電池2本）で、重量は415g、84キーでテンキーがありません。

Q.Logi Boltレシーバーは付属しますか？

MX KEYS Sのパッケージ内容には、Logi Bolt USBレシーバーが含まれると記載されています。PEBBLE KEYS 2のページには、Logi Bolt USBレシーバーは別売りで、Unifyingには非対応と記載されています。Bluetoothであれば、どちらもレシーバーなしで接続できると記載されています。

Q.複数のデバイスを切り替えられますか？

どちらのページにも、Easy-Switchで最大3台のデバイスを切り替えられると記載されています。

Q.どちらを選べばいいですか？

バックライトとUSB-C充電、大きめの本体での打鍵を重視するならMX KEYS S、軽さと電池式、持ち運びやすい84キーの構成を重視するならPEBBLE KEYS 2のページが候補になります。キーボード選び全般はキーボードの選び方ガイドもご覧ください。

Q.重さと大きさはどれくらい違いますか？

MX KEYS Sは高さ131.63×幅430.2×奥行き20.5mmで810g、PEBBLE KEYS 2 K380sは279×16×124mmで415gと記載されています。PEBBLE KEYS 2 K380sのサイズは発表の表で幅×奥行×高さの順とされ、厚みは16mmとみられるとページに注記があります。

Q.電池やバッテリーの持ちはどれくらいですか？

MX KEYS Sは、フル充電後にプリセット設定で最長10日間、バックライトをオフにして最長5か月間と記載されています。PEBBLE KEYS 2 K380sは単4形乾電池2本で36か月（使用環境による）と記載されています。測る条件が違うため、数値をそのまま同じ基準で比べないでください。

Q.バックライトはありますか？

MX KEYS Sのページにはスマートバックライトの記載があります。PEBBLE KEYS 2 K380sのページには、バックライト機能の記載がありません。ただし、記載がないことが機能がないという意味とは限らないため、購入前にAmazon商品ページもご確認ください。

Q.iPadやスマホでも使えますか？

PEBBLE KEYS 2 K380sは対応OSとしてiPadOS 14以降、iOS 14以降、Android 9.0以降が記載されています。MX KEYS SはiPadOS 14以降とAndroid 8.0以降が挙がっていますが、Windows・macOS以外は基本機能のみとの注記があります。

Q.保証期間はどのくらいですか？

MX KEYS Sのメーカー公開仕様の欄に2年間無償保証、PEBBLE KEYS 2 K380sの仕様表に2年間（メーカー保証）と記載されています。どちらも期間は同じですが、保証の条件は同梱の保証書でご確認ください。

Q.ほかのキーボードも比べたいときは？

選び方の基本はキーボードの選び方ガイドをご覧ください。
