02結論：こんな人に向いている

JBL Endurance Run 3は「バッテリー切れやBluetoothの途切れを気にせず、運動中に使いたい」人に向いた有線・USB-C接続のスポーツイヤホンです。ワイヤレスを求める場合はJBL Wave Beam 2のような完全ワイヤレスイヤホンも選択肢になります。仕様表では接続方式はUSB-C（有線）、防水規格はIP65で、ハイレゾ対応・外れにくい設計とされています。

03選び方のポイント

有線かワイヤレスか

有線イヤホンは、充電が不要で、Bluetoothの接続切れや音の遅延を避けられる点が特徴です。反対に、コードが体に触れる、引っ掛かるといった煩わしさがあります。運動中の使用ではコードを衣服のクリップで固定するなどの工夫が必要です。この商品は有線のUSB-C接続で、バッテリー切れの心配がない一方、機器側の端子が合うかが前提になります。

接続端子（USB-C）と対応機器

USB-C接続のイヤホンは、機器側からデジタル音声を受け取り、イヤホン内蔵のDACで音に変換します。使えるのは、USB-Cの音声出力に対応した機器で、Android端末、iPhone 15以降、iPad、パソコンなどが該当します。イヤホン端子（3.5mm）しかない機器では別途変換が必要です。自分の機器の端子と対応を、購入前に確認します。

防水・防塵等級（IP65）

IP65は、防塵等級6（粉塵の侵入を防ぐ）と、防水等級5（あらゆる方向からの噴流水に耐える）を組み合わせた表記です。汗や雨を想定した目安ですが、水没や長時間の浸水を想定した等級ではありません。使用後は汗を拭き取ることが長持ちにつながります。

装着性（外れにくさ）

運動用イヤホンでは、耳への固定方式が重要です。耳掛け式やウイング付きなど、耳の形に合わせて固定する構造があります。この商品は外れにくい設計とされていますが、耳の形には個人差があるため、イヤーチップやフィンの交換で調整できるか、サイズの付属数を商品ページで確認します。

ハイレゾ対応の意味

ハイレゾは、CD（44.1kHz/16bit）を超える高解像度の音源を指します。イヤホン側が対応していても、ハイレゾ音源と、再生アプリ・機器側の対応が揃って初めて意味を持ちます。ストリーミングの音質設定や、ファイル形式も確認します。この商品はハイレゾ対応とされています。

07使い方・お手入れ・注意点

  • 使用前の接続確認：USB-C端子に差し込んでも音が出ない場合は、機器の設定で音声出力がUSBオーディオになっているかを確認します。
  • コードの取り回し：走るときは、コードをシャツの中に通したり、クリップで留めたりすると、引っ張りや接触ノイズを減らせます。
  • イヤーチップのサイズ合わせ：耳に合うサイズを選ぶと、低音が逃げにくく、外れにくくなります。左右で適したサイズが違うこともあります。
  • 汗をかいた後のお手入れ：使用後は乾いた柔らかい布で汗や水分を拭き取ります。IP65でも、水没や洗濯機での洗濯は避けます。
  • イヤーチップの洗浄：イヤーチップは取り外して、薄めた中性洗剤で洗い、完全に乾かしてから取り付けます。
  • ケーブルの保管：強く折り曲げたり、コネクタ部分を引っ張って抜いたりすると断線しやすくなります。巻いてしまうときはゆるく束ねます。
  • 音量の管理：運動中は周囲の音を聞き取りにくくなるため、屋外では音量を控えめにし、交通の音が聞こえる状態を保ちます。

08こんな組み合わせ・代替案

ワイヤレスを選ぶ場面

コードが気になる、機器がUSB-Cに対応していない場合は、完全ワイヤレスイヤホンが向きます。当サイトではJBL Wave Beam 2やJBL Tour Pro 3を掲載し、ノイズキャンセリングイヤホンの比較記事でも見られます。

あると便利なもの

ケーブルを衣服に固定するクリップ、予備のイヤーチップ、持ち運び用の小さなポーチがあると扱いやすくなります。USB-C非対応の機器では使えないため、購入前に機器側の端子を確認します。

避けたい失敗

USB-C端子を持つ機器でも、機種によって音声出力に対応しない場合があります。購入前に、使う機器の仕様欄で「USB音声出力」の可否を確認してください。

09よくある質問

Q.iPhoneで使えますか？

仕様表の接続方式はUSB-C（有線）です。USB-C端子を備えた機器なら接続できますが、Lightning端子の機種（iPhone 14以前など）にはそのまま接続できません。

Q.IP65とはどういう等級ですか？

防塵等級6（粉塵の侵入を防ぐ）、防水等級5（あらゆる方向からの噴流水に耐える）を表します。水没に耐える等級ではないため、水に浸けないでください。

Q.ハイレゾ再生をするには何が必要ですか？

仕様表にハイレゾ対応と記載されています。ハイレゾ音源そのものと、再生機器側のハイレゾ対応も必要です。

Q.マイクや通話に対応していますか？

この商品のマイク・リモコンの有無は仕様表にありません。通話を使う場合は、Amazonの商品ページで、マイク付きかどうかを確認してください。

Q.Bluetoothで使えますか？

仕様表の接続方式はUSB-C（有線）です。Bluetooth接続には対応していないため、ワイヤレスで使いたい場合は別のタイプを選びます。

Q.ケーブルの長さはどれくらいですか？

ケーブルの長さは仕様表に記載がありません。運動時に使うときは、機器をポケットに入れるか腕に固定するかで必要な長さが変わるため、商品ページで確認してください。
