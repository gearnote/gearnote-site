02違いのまとめ

  • LCDキーは、Stream Deck +が「8個のカスタム可能なLCDキー」、Stream Deck + XLが「カスタマイズ可能なLCDキー×36」とElgato日本公式サイトの仕様として記載されています。
  • ダイヤルは、Stream Deck +が「プッシュ機能付き、4つの360°エンコーダ」、Stream Deck + XLが「プッシュ機能付き360°エンコーダー×6」と記載されています。タッチパネル・タッチストリップは、+が108×14mm、+ XLが161×14mmです。
  • サイズと重量は、Stream Deck +が140×138×110mm・465g、Stream Deck + XLが205×147×175mm・1085gとメーカー仕様の欄に記載されています。
  • 対応OSは、Stream Deck +のページに「Windows 11以降、macOS 13以降（USB-C 3.0ポートが必要）」、Stream Deck + XLのページに「Mac OS 14 Sonoma以降、Windows 11以降」と記載されています。
  • Stream Deck +のページには、本体にXLR入力はなく、XLRマイクには別売のXLR Dock MK.2が必要と記載され、Elgato Wave Linkなどのプラグイン対応も書かれています。Stream Deck + XLのページには、XLR入力やWave Linkの記載はなく、数百の連携機能で主要なアプリや機器と接続できるとされています。保証は、+が2年6カ月、+ XLが2年間です。

03こんな人にはこちら

▸Stream Deck +が向いている人

Stream Deck +のページでは、8個のLCDキー、4つのダイヤル、タッチストリップを備え、オーディオミキサーとしても使えるコントローラーと説明されています。

  • 配信中にオーディオを細かく調整したい人
  • ショートカット操作とミキサー機能を1台にまとめたい人
  • XLRマイクを使う場合に、別売のXLR Dock MK.2を追加できる人

▸Stream Deck + XLが向いている人

Stream Deck + XLのページでは、36個のマクロキー、6つの多機能ダイヤル、タッチストリップディスプレイを備え、多くのショートカットを1台にまとめるプロフェッショナル向けのモデルと説明されています。

  • 多くのショートカットやマクロを1台にまとめて管理したい人
  • ビデオ編集・写真編集・ゲーミングなど、複数の用途で使い分けたい人
  • ダイヤル操作で細かい数値調整をしたい人

04よくある質問

Q.Stream Deck +とStream Deck + XLの主な違いは何ですか？

各商品ページの記載では、LCDキーが+は8個、+ XLは36個、ダイヤルが+は4つ、+ XLは6つです。サイズ・重量は+が140×138×110mm・465g、+ XLが205×147×175mm・1085gで、対応OSの記載も異なります。

Q.XLRマイクを使えるのはどちらですか？

Stream Deck +のページには、本体にXLR入力はなく、XLRマイクを使うには別売のXLR Dock MK.2（Stream Deck +専用）が必要と記載されています。Stream Deck + XLのページには、XLR入力に関する記載がありません。

Q.設置スペースはどれくらい必要ですか？

Stream Deck +は140×138×110mm、Stream Deck + XLは205×147×175mmと、それぞれのメーカー仕様の欄に記載されています。+ XLのページには、Stream Deckシリーズの中でも大型で、設置するデスクのスペースを事前に確認するよう書かれています。

Q.キー数の少ないモデルもありますか？

6個のLCDキーを備えるStream Deck Mini、15個のStream Deck MK.2など、ダイヤルのないモデルのページもあります。それぞれのキー数は、各ページのElgato日本公式サイトの仕様欄をご確認ください。

Q.どちらを選べばいいですか？

ショートカットとオーディオの調整を1台にまとめたい場合は、Stream Deck +のページが参考になります。割り当てるショートカットやマクロの数が多く、ダイヤルも6つ使いたい場合は、Stream Deck + XLのページを確認するとよいでしょう。どちらもUSB-C接続で、設置スペースと対応OSのバージョンは事前にご確認ください。
