02違いのまとめ

  • LCDキーは、Stream Deck +が「8個のカスタム可能なLCDキー」、Stream Deck + XLが「カスタマイズ可能なLCDキー×36」とElgato日本公式サイトの仕様として記載されています。
  • ダイヤルは、Stream Deck +が「プッシュ機能付き、4つの360°エンコーダ」、Stream Deck + XLが「プッシュ機能付き360°エンコーダー×6」と記載されています。タッチパネル・タッチストリップは、+が108×14mm、+ XLが161×14mmです。
  • サイズと重量は、Stream Deck +が140×138×110mm・465g、Stream Deck + XLが205×147×175mm・1085gとメーカー仕様の欄に記載されています。
  • 対応OSは、Stream Deck +のページに「Windows 11以降、macOS 13以降（USB-C 3.0ポートが必要）」、Stream Deck + XLのページに「Mac OS 14 Sonoma以降、Windows 11以降」と記載されています。
  • Stream Deck +のページには、本体にXLR入力はなく、XLRマイクには別売のXLR Dock MK.2が必要と記載され、Elgato Wave Linkなどのプラグイン対応も書かれています。Stream Deck + XLのページには、XLR入力やWave Linkの記載はなく、数百の連携機能で主要なアプリや機器と接続できるとされています。保証は、+が2年6カ月、+ XLが2年間です。
  • 仕様表の記載の粒度が異なります。Stream Deck + XLのページにはキー数（36個）・ダイヤル（6つ）・ディスプレイ・対応OSが項目として並び、Stream Deck +のページは「LCDキー、タッチストリップ、ダイヤル」と構成だけをまとめた記載です。そのため比較表に「掲載情報なし」の欄が多くなっていますが、機能がないという意味ではありません。キー数やダイヤル数は、前の項目にあるElgato日本公式サイトの仕様の記載を見てください。
  • Stream Deck +のページにはオーディオ関連の記載が複数あります。Elgato Wave LinkやCamera Hub、Control Centerへの対応、マルチアクション、スマートプロファイルなどです。Stream Deck + XLのページは「数百の連携機能で主要なアプリや機器と接続できる」とされています。ミキサー機能の有無は、仕様表の記載だけでは比べきれません。
  • 同梱ケーブルは、Stream Deck +のページに「USB-C to USB-C ケーブル150cm同梱」、Stream Deck + XLのページに「USB C-to-Cケーブル150cm同梱」と記載されています。長さはどちらも150cmで、ケーブルの長さを理由に選ぶ必要は小さそうです。

03こんな人にはこちら

▸Stream Deck +が向いている人

Stream Deck +のページでは、8個のLCDキー、4つのダイヤル、タッチストリップを備え、オーディオミキサーとしても使えるコントローラーと説明されています。

  • 配信中にオーディオを細かく調整したい人
  • ショートカット操作とミキサー機能を1台にまとめたい人
  • XLRマイクを使う場合に、別売のXLR Dock MK.2を追加できる人

▸Stream Deck + XLが向いている人

Stream Deck + XLのページでは、36個のマクロキー、6つの多機能ダイヤル、タッチストリップディスプレイを備え、多くのショートカットを1台にまとめるプロフェッショナル向けのモデルと説明されています。

  • 多くのショートカットやマクロを1台にまとめて管理したい人
  • ビデオ編集・写真編集・ゲーミングなど、複数の用途で使い分けたい人
  • ダイヤル操作で細かい数値調整をしたい人

04場面別の選び方

使う場面ごとに、各商品ページの記載で見ておきたい点をまとめました。あくまで掲載情報にもとづく目安です。

  • デスクの奥行きや幅に余裕がないなら：Stream Deck +は約14×13.8×11cm、Stream Deck + XLは約20.5×14.7×17.5cmとAmazon掲載値が記載されています。Stream Deck + XLのページの「向いていない人」欄にも、設置スペースが限られている人が挙がっています。モニター下やキーボード横に置く位置を決めてから、サイズを見比べると確実です。
  • 配信でオーディオの音量を手元で調整したいなら：Stream Deck +のページは、オーディオミキサーとしても使えるコントローラーと説明し、Elgato Wave Linkなどのプラグインに対応と記載しています。Stream Deck + XLのページに同様の記載はないので、Wave Linkなどを使う予定があるなら、まずStream Deck +のページを読むとよいでしょう。
  • XLRマイクをつなぎたいなら：Stream Deck +のページには、本体にXLR入力はなく、別売のXLR Dock MK.2が必要と記載されています。Stream Deck + XLのページにはXLR入力に関する記載自体がないため、マイクの接続方法はAmazon商品ページやElgato日本公式サイトで確認してから選びます。
  • 編集ソフトやゲームで、割り当てたいショートカットが多いなら：Stream Deck + XLのページは36個のマクロキーと6つの多機能ダイヤルを挙げ、ビデオ編集・写真編集・ゲーミングなど複数の用途で使い分けたい人を「向いている人」に挙げています。一般に、キー数が多いほど、画面を切り替えずに並べておける機能が増えます。
  • macOSやWindowsのバージョンが古めなら：Stream Deck + XLのページの対応OSは「Mac OS 14 Sonoma以降、Windows 11以降」、このページの違いのまとめではStream Deck +は「Windows 11以降、macOS 13以降（USB-C 3.0ポートが必要）」と記載されています。お使いのPCのOSが条件を満たすか、購入前に確認してください。

05スペック用語のかんたん解説

比較表に出てくる用語を、一般的な意味で簡単に説明します。数値や対応の有無は各商品ページ・Amazon商品ページでご確認ください。

▸LCDキー

キーの表面に小さな画面があり、アイコンや文字を表示できるボタンのことです。Stream Deck +のページには8個、Stream Deck + XLのページには36個と、Elgato日本公式サイトの仕様として記載されています。割り当てた機能に合わせて見た目を変えられる点が、一般的な物理キーとの違いです。

▸タッチストリップ

横長の細い画面で、触れたりなぞったりして操作できる部分です。両方のページに記載があり、違いのまとめには+が108×14mm、+ XLが161×14mmと書かれています。ダイヤルの近くに置かれ、現在の設定値の表示などに使われるのが一般的です。

▸ダイヤル（エンコーダ）

回して値を増減し、押し込んで決定もできる操作部品です。Stream Deck +のページは4つ、Stream Deck + XLのページは6つと記載しています。音量や明るさなど、少しずつ変えたい項目の操作に向いています。

▸マクロ

複数の操作を1つのボタンにまとめて自動で実行する仕組みのことです。Stream Deck + XLのページでは「36個のマクロキー」と記載されています。割り当てる内容はソフトウェアで自分で設定するため、初期設定やキー配置を考える時間が必要になる、とページの注意点にも書かれています。

▸XLR入力

プロ用のマイクなどで使われる、3本のピンのコネクタの入力端子です。Stream Deck +のページには、本体にXLR入力はなく、XLRマイクを使うには別売のXLR Dock MK.2が必要と記載されています。USBマイクだけを使う場合は、この点は気にならないでしょう。

  • マイクの接続方式：XLRマイクを使う場合、Stream Deck +は別売のXLR Dock MK.2が必要と記載。USBマイクなら関係しない。

07よくある質問

Q.Stream Deck +とStream Deck + XLの主な違いは何ですか？

各商品ページの記載では、LCDキーが+は8個、+ XLは36個、ダイヤルが+は4つ、+ XLは6つです。サイズ・重量は+が140×138×110mm・465g、+ XLが205×147×175mm・1085gで、対応OSの記載も異なります。

Q.XLRマイクを使えるのはどちらですか？

Stream Deck +のページには、本体にXLR入力はなく、XLRマイクを使うには別売のXLR Dock MK.2（Stream Deck +専用）が必要と記載されています。Stream Deck + XLのページには、XLR入力に関する記載がありません。

Q.設置スペースはどれくらい必要ですか？

Stream Deck +は140×138×110mm、Stream Deck + XLは205×147×175mmと、それぞれのメーカー仕様の欄に記載されています。+ XLのページには、Stream Deckシリーズの中でも大型で、設置するデスクのスペースを事前に確認するよう書かれています。

Q.キー数の少ないモデルもありますか？

6個のLCDキーを備えるStream Deck Mini、15個のStream Deck MK.2など、ダイヤルのないモデルのページもあります。それぞれのキー数は、各ページのElgato日本公式サイトの仕様欄をご確認ください。

Q.どちらを選べばいいですか？

ショートカットとオーディオの調整を1台にまとめたい場合は、Stream Deck +のページが参考になります。割り当てるショートカットやマクロの数が多く、ダイヤルも6つ使いたい場合は、Stream Deck + XLのページを確認するとよいでしょう。どちらもUSB-C接続で、設置スペースと対応OSのバージョンは事前にご確認ください。

Q.どちらもMacとWindowsの両方で使えますか？

Stream Deck + XLのページには、対応OSとして「Mac OS 14 Sonoma以降、Windows 11以降」と記載されています。Stream Deck +のページでは、違いのまとめに記載のとおり、Windows 11以降、macOS 13以降でUSB-C 3.0ポートが必要とされています。お使いのOSのバージョンが条件を満たすか、購入前にAmazon商品ページでご確認ください。

Q.ダイヤルの数は用途にどう影響しますか？

Stream Deck +は4つ、Stream Deck + XLは6つのダイヤルと記載されています。一般に、ダイヤルが多いほど、音量やカメラの設定のような連続的に変える項目を同時に割り当てやすくなります。ただし、使う項目が少なければ4つで足りる場合もあります。

Q.タッチストリップは何に使いますか？

どちらのページにも、タッチストリップまたはタッチストリップディスプレイの記載があります。ダイヤルに割り当てた機能の設定値などを表示する場所として使われるのが一般的で、具体的な表示内容はソフトウェアの設定によって変わります。

Q.配信をしないとき、ショートカット用としても使えますか？

Stream Deck + XLのページには、ビデオ編集・写真編集・ゲーミングなど複数の用途で使い分けたい人が「向いている人」として挙がっています。Stream Deck +のページでも、ショートカット操作とミキサー機能を1台にまとめたい人が挙げられています。配信以外にも使えるかは、お使いのソフトのプラグイン対応でご確認ください。

Q.大きいほうを選ぶと、持ち運びは難しいですか？

Stream Deck + XLは約1.09kg、Stream Deck +は約465gとAmazon掲載値が記載されています。Stream Deck + XLのページには、Stream Deckシリーズの中でも大型で、約20.5×14.7×17.5cmと書かれています。頻繁に持ち運ぶ予定なら、サイズと重量を先に確認しましょう。
