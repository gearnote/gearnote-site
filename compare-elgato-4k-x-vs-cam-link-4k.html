02違いのまとめ

  • キャプチャ対応は、4K Xのページに「1080p30〜1080p240／1440p30〜1440p144／4K30〜4K144」、Cam Link 4Kのページに「1080p時60fps、4K時30fps（MJPGのみ4K60にも対応）」と記載されています。
  • 接続規格は、4K Xが「USB 3.2 Gen 2」、Cam Link 4Kが「USB 3.0」と記載されています。
  • 4K Xのページには、HDMIの出力（ラグのないパススルー）と、パススルー対応（1080p60〜1440p240／4K60〜4K144）が記載されています。Cam Link 4Kのページの仕様表には、出力やパススルーの項目がありません。
  • 対応機器は、4K Xが「PlayStation、Xbox、Nintendo Switch 2、PC、Mac、iPad」、Cam Link 4Kが「Elgato Game Capture HDシリーズ、デジタル一眼レフ、ビデオカメラ、アクションカメラ」と記載されています。HDR10は4K Xのページのみに記載があります。
  • サイズと重量は、4K Xのページに「約112×72×18mm」「約91g」、Cam Link 4Kのメーカー公開仕様の欄に「8.1×1.2×3.1cm」「20g」と記載されています。入力は、どちらも非暗号化のHDMIと記載されています。
  • Windowsの要件は、メーカー公開仕様の欄に、Elgato 4K Xが「Windows 10（64ビット）以降、第6世代Intel Core i5 / AMD Ryzen 5 以降、NVIDIA GeForce GTX 10xx 以降、USB 3.2 Gen 2ポート」、Elgato Cam Link 4Kが「Windows 10（64ビット）以降、Intel または AMD CPU、USB 3.0ポート（タイプAまたはタイプC）」と記載されています。
  • Mac・iPadの要件は、Elgato 4K Xが「macOS 11、iPadOS 17 以降」、Elgato Cam Link 4Kが「macOS 13以降、iPadOS 17以降」と記載されています。Elgato 4K Xの欄には、Apple M1 または Intel i5 第4世代クアッドコア以上、メモリ4GBの記載もあります。Elgato Cam Link 4Kのページには、Amazonの表にある「macOS Sierra 10.12以降」などは公式のシステム要件と異なる、との注記があります。
  • 同梱物は、Elgato 4K XがUSB 3.2 C-to-Cケーブル（150cm）と8K HDMIケーブル（200cm）、Elgato Cam Link 4KがUSB 3.0 A-to-C 延長ケーブル（30cm）と記載されています。Elgato Cam Link 4Kのページの注意点には、HDMI出力に対応したカメラやケーブルを別に用意する必要があると書かれています。

03こんな人にはこちら

▸Elgato 4K Xが向いている人

4K Xのページでは、ゲーム機の映像をHDMI 2.1経由で取り込める外部キャプチャカードで、最大4K144のキャプチャとVRR・HDR10のパススルーに対応すると説明されています。

  • 最新世代ゲーム機の映像を高フレームレートでキャプチャ・配信したい人
  • VRR対応モニターの映像をティアリングを抑えて再生したい人
  • HDR10対応の映像を扱いたい人

▸Elgato Cam Link 4Kが向いている人

Cam Link 4Kのページでは、一眼レフやビデオカメラなどのHDMI出力機器をパソコンのWebカメラや配信ソースとして使える、コンパクトなキャプチャカードと説明されています。

  • 一眼レフやビデオカメラを高画質Webカメラとして使いたい人
  • OBSなどでゲーム実況・配信をしている、またはこれから始めたい人
  • ハードドライブへの直接録画で、カメラの録画時間制限を回避したい人

04場面別の選び方

使う場面ごとに、各商品ページの記載で見ておきたい点をまとめました。あくまで掲載情報にもとづく目安です。

  • ゲーム機の画面を見ながら配信や録画をしたいなら：Elgato 4K Xのページに、HDMI出力は「ラグのないパススルー」と記載されています。パススルー対応は「1080p60〜1440p240／4K60〜4K144」です。Elgato Cam Link 4Kのページの仕様表には、出力やパススルーの項目がありません。
  • 一眼レフやビデオカメラを、会議や配信のカメラにしたいなら：Elgato Cam Link 4Kのページに、一眼レフ、ビデオカメラ、アクションカメラが対応デバイスとして記載されています。対応アプリは、OBS、Skype、QuickTime、XSplitなどです。ハードドライブへの直接録画で、カメラの録画時間制限を避けられるとも書かれています。
  • 机の上や持ち運びで、できるだけ小さいものがよいなら：サイズと重量は、Elgato 4K Xが約112×72×18mm・約91g、Elgato Cam Link 4Kが8.1×1.2×3.1cm・20gと記載されています。Elgato Cam Link 4Kは30cmの延長ケーブルが付き、パソコンの背面のポートにつなぐときの取り回しを考えた構成です。
  • MacやiPadで使うことが多いなら：どちらもiPadOS 17以降と記載されています。macOSはElgato 4K XがmacOS 11、Elgato Cam Link 4KがmacOS 13以降です。Elgato 4K Xのページには、HDRキャプチャは現在Windowsのみ対応と記載されています。
  • パソコンのUSBポートが古い規格のものしかないなら：Elgato 4K Xのページは、USB 3.2 Gen 2への接続が前提と記載されています。一方で、解像度を下げればUSB 3.2 Gen 1でも動作する場合があるとも書かれています。Elgato Cam Link 4Kのページは、USB 3.0ポート（タイプAまたはタイプC）が要件です。

05スペック用語のかんたん解説

比較表に出てくる用語を、一般的な意味で簡単に説明します。数値や対応の有無は各商品ページ・Amazon商品ページでご確認ください。

▸パススルー

パソコンに取り込むのと同時に、同じ映像を別のモニターやテレビへそのまま出力する機能です。ゲーム機の画面を、取り込みの遅れなしに見たいときに使います。Elgato 4K Xのページに記載があり、Elgato Cam Link 4Kの仕様表には項目がありません。

▸HDCP

映像の不正コピーを防ぐための暗号化の仕組みです。両ページとも、入力は非暗号化HDMIと記載されています。Elgato Cam Link 4KのFAQには、HDCPで暗号化されたゲーム機やプレーヤーの映像は取り込めない場合があると書かれています。

▸4K144や1080p60の表記

解像度とフレームレートを組み合わせた書き方です。たとえば4K144は、4K解像度で1秒間に144枚の画像を描く設定です。数字が大きいほどなめらかに見えますが、パソコンやつなぐ機器もその設定に対応している必要があります。

▸VRRとHDR10

VRRは、映像の更新のタイミングを機器に合わせる可変リフレッシュレートの仕組みで、画面の乱れを抑える目的で使われます。HDR10は、明暗の幅を広く扱う映像の規格です。どちらもElgato 4K Xのページに記載があります。ただしHDRは、すべての解像度・フレームレートの組み合わせで使えるわけではないと書かれています。

▸USB 3.2 Gen 2とUSB 3.0

パソコンと機器をつなぐUSBの規格です。一般に、Gen 2はUSB 3.0より速くデータを送れる規格とされています。Elgato 4K XはUSB 3.2 Gen 2、Elgato Cam Link 4KはUSB 3.0と記載されています。ポートの規格は、パソコンの仕様書で確認します。

▸MJPG

映像を1コマずつ圧縮して送る形式の名称です。Elgato Cam Link 4Kのページに、4K60にはMJPGでのみ対応と記載されています。アプリによって対応が異なることがあるため、使うソフトの案内もあわせて確認します。

06購入前のチェックリスト

購入前に見ておくと安心な項目です。各商品ページの記載にもとづくため、最終的にはAmazon商品ページの最新情報もご確認ください。

  • 取り込む映像：どちらもHDCPで暗号化された映像は取り込めない。ゲーム機やプレーヤーの出力設定を、事前に確認する。
  • USBポート：Elgato 4K XはUSB 3.2 Gen 2、Elgato Cam Link 4KはUSB 3.0（タイプAまたはタイプC）が要件。パソコン側のポートの規格を確認する。
  • パソコンの性能：Elgato 4K XはCPUとGPUの世代が指定されている。Elgato Cam Link 4KはIntelまたはAMDのCPUとだけ書かれており、世代の指定は記載がない。
  • ケーブル：Elgato 4K XはHDMIケーブルとUSBケーブルが付属する。Elgato Cam Link 4KはHDMIケーブルが付属しないため、カメラ側に合うものを別に用意する。
  • HDRの使い方：Elgato 4K XのHDRキャプチャは、現在Windowsのみ対応と記載されている。Macで使う場合は確認が必要になる。
  • 同時に使うカメラの数：Elgato Cam Link 4Kは1系統のみ。複数のカメラを同時に取り込みたいときは、台数や構成を考えておく。

07よくある質問

Q.Elgato 4K XとCam Link 4Kの主な違いは何ですか？

各商品ページの記載では、4K Xは最大4K144までのキャプチャとHDMIパススルー、USB 3.2 Gen 2接続に対応します。Cam Link 4Kは1080p時60fps、4K時30fpsで、USB 3.0接続と記載されています。対応機器も、4K Xはゲーム機やPC、Cam Link 4Kは一眼レフやビデオカメラなどが中心です。

Q.ゲーム機の映像を取り込むのに向いているのはどちらですか？

4K Xのページに、PlayStation、Xbox、Nintendo Switch 2に対応し、パススルーとVRR、HDR10に対応すると記載されています。Cam Link 4Kのページは、カメラ類のHDMI出力を取り込む用途を中心に説明されています。どちらも非暗号化のHDMIが入力のため、暗号化された映像は取り込めない旨が各ページに記載されています。

Q.パソコン側に必要な環境に違いはありますか？

4K Xのページには、USB 3.2 Gen 2ポートが必要と記載されています。Cam Link 4Kのページには、USB 3.0ポート（タイプAまたはタイプC）と記載されています。対応OSやCPUの条件も各ページに記載があるため、購入前にご自分の環境と照らして確認してください。

Q.どちらを選べばいいですか？

ゲーム機の映像を高いフレームレートで取り込みたい、パススルーやHDR10も使いたいなら、4K Xのページが候補です。一眼レフやビデオカメラをWebカメラや配信ソースとして使いたい、本体の小ささも重視したいなら、Cam Link 4Kのページを確認するとよいでしょう。Webカメラ全般はWebカメラ・マイクの選び方ガイドもご覧ください。

Q.パススルーとは何ですか？

パソコンに取り込む映像を、そのまま別のモニターにも出力する機能です。Elgato 4K Xのページには「HDMI（ラグのないパススルー）」と記載され、パススルー対応は「1080p60〜1440p240／4K60〜4K144」です。Elgato Cam Link 4Kのページの仕様表には、この項目がありません。

Q.MacやiPadでも使えますか？

どちらもiPadOS 17以降と記載されています。macOSは、Elgato 4K XがmacOS 11、Elgato Cam Link 4KがmacOS 13以降です。Elgato Cam Link 4Kのページには、Amazonの表に「macOS Sierra 10.12以降」とあるが、公式のシステム要件と異なるという注記があります。購入前に最新の要件をご確認ください。

Q.HDRはすべての設定で使えますか？

Elgato 4K Xのページに、HDR10はあり、ただしすべての解像度・フレームレートで対応するわけではないと記載されています。HDRキャプチャは現在Windowsのみ対応とも書かれています。Elgato Cam Link 4Kのページには、HDRの記載がありません。

Q.Cam Link 4Kで4K60の映像は取り込めますか？

Elgato Cam Link 4Kのメーカー公開仕様の欄に、4K60（MJPGのみ）、4K30、1080p60、1080p30などの解像度が記載されています。4K60にはMJPGでのみ対応という条件がつきます。録画・配信のフレームレートは、仕様表で1080p時60fps、4K時30fpsと記載されています。

Q.USB 3.2 Gen 1のポートでも使えますか？

Elgato 4K Xのページには、USB 3.2 Gen 2への接続が前提だが、キャプチャ解像度を下げればUSB 3.2 Gen 1環境でも動作する場合があるとされています。Elgato Cam Link 4KのページはUSB 3.0ポートが要件です。動作はお使いの環境で変わるため、メーカーの案内もご確認ください。

Q.Nintendo Switch 2や他のゲーム機に使えますか？

Elgato 4K Xのページには、PlayStation、Xbox、Nintendo Switch 2、PC、Mac、iPadが対応プラットフォームとして記載されています。詳しい動作条件は、Amazon商品ページでご確認ください。Elgato Cam Link 4Kのページには、ゲーム機が対応デバイスとして記載されていません。

Q.配信用のマイクも選びたいときは？

音声まわりはマイクの選び方ガイド、カメラはWebカメラ・マイクの選び方ガイドでご覧いただけます。
