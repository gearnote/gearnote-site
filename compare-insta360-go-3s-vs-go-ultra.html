02違いのまとめ

  • 重量は、メーカー公開情報でGO 3Sがカメラ39.1g・アクションポッド96.3g、GO Ultraがカメラ単体52.9±0.5g・アクションポッド108.5±0.5gと記載されています。カメラのサイズは、GO 3Sが25.6×54.4×24.8mm、GO Ultraが46×45.7×18.3mmです。
  • バッテリー容量は、GO 3Sがカメラ310mAh・アクションポッド1270mAh、GO Ultraがカメラ500mAh・アクションポッド1450mAhと記載されています。撮影時間（ラボ環境）は、GO 3Sがカメラ単体38分・ポッド併用140分（1080p@30fps）、GO Ultraがポッド使用時に1080pで200分・4Kで170分、カメラ単体で1080pが70分・4Kが60分です。
  • 動画は、GO 3Sのページに4K対応、メーカー公開情報に動画コーデックH.264・最大ビットレート120Mbpsと記載されています。GO Ultraのメーカー公開情報には、動画の上限4K60fps（1080pでは最大240fps）、コーデックH.264／H.265、最大ビットレート180Mbps、写真は最大50MPと記載されています。
  • ストレージは、GO 3Sがメーカー公開情報で64GBと128GBの展開があり、このページの商品は内蔵128GBモデルと記載されています。GO Ultraのメーカー公開情報には、microSDカード（最大2TBまで対応）と記載されています。
  • 防水は、どちらもメーカー公開情報でカメラがIPX8等級（水深10mまで）、アクションポッドがIPX4と記載されています。GO 3Sのページには、Apple Find My対応の記載もあります。
  • 手ブレ補正は、Insta360 GO 3S 128GBのページには「その他機能」欄に手ブレ補正と記載があります。Insta360 GO Ultraのページの仕様表には「手ブレ補正：対応」と記載されています。比較表では、どちらも手ブレ補正の記載があるものとして並べています。
  • 充電時間は、メーカー公開情報でInsta360 GO 3S 128GBがカメラ80%まで23分・100%まで35分、アクションポッド80%まで47分・100%まで65分、Insta360 GO Ultraがカメラ80%まで12分・100%まで20分、アクションポッド80%まで18分・100%まで40分と記載されています。Insta360 GO Ultraは「30W USB-C充電器使用」という条件付きで、Insta360 GO 3S 128GBのページには充電器の条件の記載がありません。
  • 通信は、Insta360 GO 3S 128GBがWi-Fi 5GHz 802.11a/n/ac・USB Type-C（USB 2.0）、Insta360 GO UltraがWi-Fi 802.11 b/g/n/ax・USB-C 2.0と記載されています。Insta360 GO Ultraの仕様表には、想定用途としてPOV撮影・サイクリング・ランニング・旅行・ペット撮影の記載もあります。

04場面別の選び方

使う場面ごとに、各商品ページの記載で見ておきたい点をまとめました。あくまで掲載情報にもとづく目安です。

  • 海や川、プールなど水辺で使うなら：どちらも、メーカー公開情報でカメラがIPX8（水深10mまで）、アクションポッドがIPX4と記載されています。Insta360 GO 3S 128GBは水中使用時に同梱のレンズガードを装着する、Insta360 GO Ultraは水中撮影にアクアレンズの使用が推奨されると記載されています。Insta360 GO 3S 128GBの仕様表には「10m防水」、Insta360 GO Ultraの仕様表には「防水対応（Amazon商品名に記載）」とあります。
  • 4Kでなるべく長く撮りたいなら：Insta360 GO Ultraのメーカー公開情報に、ポッド使用時は4Kで170分、カメラ単体は4Kで60分（ラボ環境）と記載されています。Insta360 GO 3S 128GBのページには、1080p@30fpsの値（カメラ単体38分、ポッド併用140分）のみで、4K撮影時の撮影時間は記載がありません。
  • microSDカードで保存容量を増やしたいなら：Insta360 GO Ultraのメーカー公開情報に、microSDカード（最大2TBまで対応）と記載されています。Insta360 GO 3S 128GBのページには、このページの商品は内蔵128GBモデルと記載され、外部メディアの記載はありません。ストレージは64GBと128GBの展開と記載されています。
  • iPhoneで、紛失した場合の捜索機能を重視するなら：Insta360 GO 3S 128GBのページに、Apple Find My対応の記載があります。Insta360 GO 3S 128GBのページには、Androidユーザーは利用できない場合があるという注意書きもあります。Insta360 GO Ultraのページには、Apple Find Myの記載がありません。
  • 服やバッグに付けても目立たないサイズ感を重視するなら：カメラの重量はInsta360 GO 3S 128GBが39.1g、Insta360 GO Ultraが52.9±0.5gと記載されています。サイズは、Insta360 GO 3S 128GBが25.6×54.4×24.8mm、Insta360 GO Ultraが46×45.7×18.3mmで、形状も異なります。数値は、メーカー公開情報の記載です。

05スペック用語のかんたん解説

比較表に出てくる用語を、一般的な意味で簡単に説明します。数値や対応の有無は各商品ページ・Amazon商品ページでご確認ください。

▸IPX8とIPX4

IPコードのうち、水に対する保護等級を示す表記です。一般に、IPX8は水中での使用を想定した等級で、条件は製品ごとに定められます。IPX4は水しぶきへの耐性を示す等級とされます。どちらも、カメラがIPX8、アクションポッドがIPX4と記載されています。

▸アクションポッド

カメラ本体を収めて充電したり、画面で確認したり、撮影時間を延ばしたりするために使う付属の器具です。ポッド併用の撮影時間は、Insta360 GO 3S 128GBが140分（1080p@30fps）、Insta360 GO Ultraが1080pで200分・4Kで170分と記載されています。

▸fps（フレームレート）

1秒間に何枚の画像で動画を作るかを示す単位です。数値が大きいほど動きがなめらかに見え、ファイルも大きくなる傾向があります。Insta360 GO Ultraのメーカー公開情報に4K60fps、1080pでは最大240fpsと記載されています。Insta360 GO 3S 128GBのページには、1080p@30fpsの撮影時間の記載があります。

▸コーデックとビットレート

コーデックは動画を圧縮する方式、ビットレートは1秒あたりのデータ量です。ビットレートが大きいほど細かい情報を残せますが、ファイルも大きくなります。Insta360 GO 3S 128GBはH.264・最大120Mbps、Insta360 GO UltraはH.264／H.265・最大180Mbpsと記載されています。

▸ラボ環境の撮影時間

決まった温度や設定のもとで測った、連続撮影時間の値です。Insta360 GO 3S 128GBは25℃、画面とWi-Fi無効、1080p@30fpsの条件が記載されています。実際には、画面表示や通信、気温などで変わります。

06購入前のチェックリスト

購入前に見ておくと安心な項目です。各商品ページの記載にもとづくため、最終的にはAmazon商品ページの最新情報もご確認ください。

  • 撮影時間の条件：Amazon掲載の「最大140分」はInsta360 GO 3S 128GBのポッド併用時の値、「最大200分」はInsta360 GO Ultraの1080p・ポッド使用時の値。解像度や使い方で変わる。
  • 保存先：Insta360 GO 3S 128GBは内蔵128GB（64GBモデルもある）。Insta360 GO UltraはmicroSDカードに対応と記載。撮影する量から必要な容量を見積もる。
  • セット内容：Insta360 GO Ultraのページには、このページの「通常版」と公式ページのセット内容の対応は、公式の仕様欄に記載がないとある。付属品はAmazon商品ページで確認する。
  • 水中の使い方：Insta360 GO 3S 128GBはレンズガード、Insta360 GO Ultraはアクアレンズが水中撮影に関する記載にある。使用後は真水で洗い、完全に乾かす。
  • 紛失への備え：どちらも本体が小さい。Insta360 GO 3S 128GBはApple Find My対応だが、Androidでは使えない場合がある。マウントでの固定を確認する。
  • 編集環境：編集には、スマートフォンやパソコンのアプリが必要。空き容量に余裕を持たせる。

07よくある質問

Q.Insta360 GO 3SとGO Ultraの主な違いは何ですか？

各商品ページの記載では、カメラの重量がGO 3Sは39.1g、GO Ultraは52.9±0.5gです。バッテリー容量はカメラがGO 3Sは310mAh、GO Ultraは500mAhで、動画の上限はGO Ultraに4K60fps、写真最大50MPの記載があります。防水はどちらもカメラがIPX8（水深10mまで）と記載されています。

Q.撮影時間に違いはありますか？

メーカー公開情報では、GO 3Sがポッド併用で140分（1080p@30fps）、GO Ultraがポッド使用時に1080pで200分・4Kで170分と記載されています。いずれもラボ環境の値のため、実際の撮影時間は撮影モードや環境で変わります。

Q.水中でも使えますか？

どちらのメーカー公開情報にも、カメラはIPX8（水深10mまで）、アクションポッドはIPX4と記載されています。GO 3Sでは水中使用時に同梱のレンズガードを装着し、GO Ultraでは水中撮影にアクアレンズの使用が推奨されていると記載されています。

Q.どちらを選べばいいですか？

カメラ39.1gの小ささと内蔵128GB、Apple Find My対応の記載を重視するならGO 3S、バッテリー容量、4K60fpsまでの動画仕様、microSDカードへの対応を重視するならGO Ultraのページが候補になります。選び方の基準はアクションカメラ・360度カメラの選び方ガイドもご覧ください。

Q.手ブレ補正はどちらにありますか？

Insta360 GO 3S 128GBのページには、「その他機能」欄に手ブレ補正と記載されています。Insta360 GO Ultraのページには、仕様表に「手ブレ補正：対応」と記載されています。補正の方式や効き具合を示す数値は、どちらのページにも記載がありません。

Q.microSDカードは使えますか？

Insta360 GO Ultraのメーカー公開情報に、microSDカード（最大2TBまで対応）と記載されています。Insta360 GO 3S 128GBのページには、外部メディアの追加はメーカーの仕様欄に記載がないとあります。Insta360 GO 3S 128GBは内蔵ストレージが64GBと128GBの展開で、このページの商品は128GBです。

Q.充電にかかる時間を教えてください。

メーカー公開情報では、Insta360 GO 3S 128GBはカメラが100%まで35分、アクションポッドが100%まで65分、Insta360 GO Ultraはカメラが100%まで20分、アクションポッドが100%まで40分と記載されています。Insta360 GO Ultraは30W USB-C充電器を使った値です。

Q.Apple Find Myは使えますか？

Insta360 GO 3S 128GBのページに、Apple Find My対応の記載があります。iPhoneの「探す」機能で本体の位置を確認できる機能とされ、Androidユーザーは利用できない場合があると書かれています。Insta360 GO Ultraのページには記載がありません。

Q.4Kと1080pで、撮影時間は変わりますか？

Insta360 GO Ultraのメーカー公開情報では、ポッド使用時は1080pで200分、4Kで170分、カメラ単体は1080pで70分、4Kで60分と記載されています。Insta360 GO 3S 128GBのページには、1080p@30fpsの値のみが記載されています。

Q.動画の画質に関する数値の違いはありますか？

Insta360 GO 3S 128GBのメーカー公開情報には、動画コーデックH.264・最大ビットレート120Mbpsと記載されています。Insta360 GO Ultraには、動画の上限4K60fps、コーデックH.264／H.265、最大ビットレート180Mbps、写真は最大50MPと記載されています。

Q.撮影スタイルや機種選びの基準を知りたいときは？

選び方の基準はアクションカメラ・360度カメラの選び方ガイドでご覧いただけます。
