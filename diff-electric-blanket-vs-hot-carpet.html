電気毛布とホットカーペットの違い｜W・Wh・表面温度の測り方

電気毛布は布団の中、ホットカーペットは床の上で使う暖房器具です。仕様表の数字は、測り方の条件が違います。取扱説明書の注記をもとに、数字の読み方をまとめました。

執筆・確認：GEARNOTE運営（H＆C）　データの時点：2026年10月31日〜11月24日（集計：2026年11月24日）

01使う場所と、就寝中の扱いが違う

電気毛布は、布団の中で掛けたり敷いたりして使う暖房器具で、ひざ掛けの形もあります。GEARNOTEに載せている電気毛布20台は、掛け・掛敷き・ひざ掛けが9台、敷きが11台です。ホットカーペットは床に敷いて使うもので、6台を載せています。

大きな違いは、就寝中の扱いです。山善のホットカーペットの取扱説明書は、低温やけどや脱水症状を起こすおそれがあるとして、「就寝用暖房器具として使用しない」と書いています（山善 ホットカーペット取扱説明書（PDF））。

山善の電気掛敷毛布の取扱説明書は、「強」の目盛で長時間使わないこと、比較的低い温度（40〜60度）でも、長い時間皮膚の同じ場所に触れていると低温やけどの恐れがあることを書いています（山善 電気掛敷毛布取扱説明書（PDF））。どちらも、使い方の注意は商品ごとの取扱説明書に従ってください。

02表面温度は、測り方が違う

山善のホットカーペットの取扱説明書は、表面温度と消費電力量は日本電機工業会の測定方法に基づく値で、表面温度は「室温20℃で畳の上にカーペット本体を広げ、3kgの荷重を加えた状態」で測った値だと書いています（山善 ホットカーペット取扱説明書（PDF））。

山善の電気掛敷毛布の取扱説明書では、表面温度は「JIS C 9210の平常温度試験方法」に基づいて測った温度です（山善 電気掛敷毛布取扱説明書（PDF））。パナソニックの電気かけしき毛布DB-RM3Mの仕様表は、標準表面温度を室温20℃のときの値（「強」51℃）で書いています（パナソニック DB-RM3M 仕様）。

GEARNOTE掲載の数字では、強の表面温度は電気毛布が44〜53℃（17台）、ホットカーペットが42〜45℃（5台）でした（GEARNOTE運営の計算）。電気毛布のほうが高い数字に見えますが、測り方が違うので、この数字どうしで「どちらが熱いか」は決められません。比べるのは、同じ種類どうしにします。

03消費電力（W）と、1時間の消費電力量（Wh）

仕様表の「消費電力」（W）は定格の値で、「1時間あたりの消費電力量」（Wh）は、決まった条件で使ったときの量です。山善の取扱説明書では、ホットカーペットは「室温15℃で畳の上に広げ、5時間通電したときの平均値」（山善）、電気掛敷毛布は日本電機工業会の測定方法に基づく値で、同じ書類の別の注記には「室温15℃、綿ふとん中で5時間運転したときの平均消費電力量」という条件が書かれています（山善）。

GEARNOTE掲載の数字では、定格消費電力は電気毛布が32〜75W（18台）、ホットカーペットが75〜600W（メーカー情報ブロックで数字のある5台）でした。強で1時間使ったときの消費電力量は、電気毛布が21〜57Wh（8台）、ホットカーペットが70〜460Wh（4台）です（GEARNOTE運営の計算）。広さが違うので、ホットカーペットは桁が一つ大きい数字になります。データ一覧で幅と奥行の両方がある5台のホットカーペットの面積は、約1.44〜4.25㎡でした。

もう一つの注意は、「定格W×1時間」は、1時間の消費電力量と同じではないことです。消費電力量と定格の両方に数字がある商品で、消費電力量を定格で割ると、電気毛布の8台は0.66〜0.77、ホットカーペットの4台は0.65〜0.93でした（GEARNOTE運営の計算）。温度を保つためにヒーターが入ったり切れたりするので、定格の数字より小さくなります。消費電力量は、仕様表の「Wh」の欄で見ます。

なお、パナソニックのDB-RM3Mの仕様表には、「消費電力量」の行はありませんでした。GEARNOTEのデータ一覧で、電気毛布の消費電力量に数字があるのは8台です。数字がない商品は、ほかの商品と比べられません。

04タイマーと、暖める面の切り替え

切り忘れを防ぐ機能も、書き方が違います。電気毛布では、コイズミ 電気掛敷毛布 KDK-60268T 快眠タイマー付きが「快眠タイマー（8時間オフ）／12時間自動オフタイマー」、山善 電気掛敷毛布 188×130cm EMK-T201（グレー）が「2時間OFFの快眠タイマー、8時間自動OFF」と書かれています。

ホットカーペットでは、パナソニック ホットカーペット 2畳 DC-2NKが「切り忘れ防止（8時間）」、山善 ホットカーペット 3畳相当 185×230cm フローリング調 YZD-301FL(LBR)が「切り忘れ防止タイマー（6時間）」です。ホットカーペットには、全面・左面・右面のように、暖める面を切り替える機能が書かれている機種もあります。山善の取扱説明書は、やぐらこたつをカーペットの上に置く場合は、やぐらこたつの電源を切ること、電気ストーブなどほかの暖房器具は1m以上離すことも書いています（山善 ホットカーペット取扱説明書（PDF））。

07よくある読み間違い

  • 電気毛布の表面温度が高いから、ホットカーペットより熱いと思う：測り方の条件が違います（山善の例：毛布はJIS C 9210、カーペットは畳の上で3kgの荷重）。
  • 定格500Wなら、1時間で500Wh使うと思う：GEARNOTE掲載では、1時間の消費電力量は定格の0.65〜0.93倍でした。
  • ホットカーペットで寝てもよいと思う：山善の取扱説明書は、就寝用暖房器具として使用しない、と書いています。
  • Whの数字は、どの部屋でも同じだと思う：室温15℃などの条件で測った値です。部屋の条件で変わります。
  • 電気毛布の「強」は、一晩中使う設定だと思う：山善の取扱説明書は、「強」で長時間使わない、と書いています。

08商品ページで確認すること

  • 定格消費電力（W）と、1時間あたりの消費電力量（Wh）の両方。Whは、どの設定の値か（強・中・[5]など）。
  • 表面温度：どの設定の値か。室温20℃などの条件。
  • 大きさ：電気毛布は掛け・敷きのどちらか、ホットカーペットは何畳相当か。
  • タイマー：何時間で切れるか。
  • 取扱説明書の注意：就寝中の使い方、ほかの暖房器具との距離。

09出典と、確認できなかったこと

このページの事実は、2026年11月15日に、各ページ（PDFは本文）を実際に開いて確認したメーカーの公式ページ・取扱説明書と業界団体の資料にもとづきます（リンクは各項目に付けています）。GEARNOTEの数字は、掲載している商品のデータ一覧（CSV）と商品ページから、GEARNOTE運営が数えたもの（GEARNOTE運営の計算）です。

  • 日本電機工業会の、電気毛布・電気カーペットの測定方法そのものの文書は確認できなかったため、山善の取扱説明書に書かれた条件の範囲で書いています。
  • 山善の電気掛敷毛布の取扱説明書（YMK-F43P・YMK-MF41）は、GEARNOTEに掲載していない型番のものです。測定条件の書き方の例として使っています。
  • JIS C 9210の平常温度試験方法の中身は確認していないため、試験の条件は書いていません。
  • 電気毛布とホットカーペットの、体への影響の違いは、このページでは扱いません。

11よくある質問

Q.電気毛布とホットカーペットは、何が違いますか？

電気毛布は布団の中で掛けたり敷いたりして使い、ホットカーペットは床に敷いて使います。山善のホットカーペットの取扱説明書は、就寝用暖房器具として使わないよう書いています。定格消費電力は、GEARNOTE掲載では電気毛布が32〜75W（データ一覧で数字のある18台）、ホットカーペットが75〜600W（メーカー情報ブロックで数字のある5台）でした。

Q.表面温度の数字は比べられますか？

そのままでは比べられません。山善の例では、電気毛布はJIS C 9210の平常温度試験方法、ホットカーペットは室温20℃で畳の上に広げ3kgの荷重を加えた状態で測っていて、条件が違います。

Q.消費電力のWと、消費電力量のWhは何が違いますか？

Wは定格の値、Whは決まった条件で1時間使ったときの量です。GEARNOTE掲載では、1時間の消費電力量は定格の0.65〜0.93倍で、定格Wの数字より小さくなっていました。

Q.ホットカーペットの上にこたつを置いてもいいですか？

山善の取扱説明書は、やぐらこたつをカーペットの上に置く場合は中央に置き、やぐらこたつの電源は切るよう書いています。ほかの機種は、それぞれの取扱説明書を確かめてください。
