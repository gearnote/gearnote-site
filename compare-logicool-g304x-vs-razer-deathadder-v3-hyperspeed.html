02違いのまとめ

  • 重量は、G304 Xが「59g（前モデルG304から約40gの軽量化と記載）」、DeathAdder V3 HyperSpeedが「55g」（長さ12.2×幅6.5cm）と記載されています。
  • センサーは、G304 Xのページに「HERO 44Kセンサー」と記載されています。DeathAdder V3 HyperSpeedのページでは、仕様表にセンサーの記載はありませんが、メーカー公開仕様の欄に「Focus X 26K オプティカルセンサー、最大26,000 DPI」と記載されています。
  • 接続は、G304 XがLIGHTSPEEDとBluetooth、DeathAdder V3 HyperSpeedがRazer HyperSpeed Wireless（USBドングル）とUSB Type A - Type Cケーブルと記載されています。DeathAdder V3 HyperSpeedのページにBluetoothの記載はありません。
  • バッテリーは、G304 Xが「約130時間持続（連続利用の目安）」でUSB Type-C充電、DeathAdder V3 HyperSpeedが「100時間のバッテリー駆動時間」でリチウムイオン電池×1付属と記載されています。
  • ボタン数は、G304 Xのページに6と記載されています。DeathAdder V3 HyperSpeedのページには、仕様表にボタン数の記載がなく、メーカー公開仕様の欄にも「ボタン数・ポーリングレート・Bluetooth：メーカーのこのページに記載なし」とあります。対応OSは、DeathAdder V3 HyperSpeedがWindows 10／Windows 11、G304 Xのページには対応OSの記載がありません。
  • サイズは、Logicool G304 Xのメーカー公開仕様の欄に「63.9×38.2×117.3mm」（項目名は横×奥行×高さ）、Razer DeathAdder V3 HyperSpeedに「長さ122.2×幅64.8×高さ41.3mm」と記載されています。Razer DeathAdder V3 HyperSpeedの仕様表には「長さ12.2×幅6.5cm」とあり、メーカー公開仕様の欄の値とは小数点以下が異なります。
  • スイッチは、Razer DeathAdder V3 HyperSpeedのメーカー公開仕様の欄に「第3世代Razerオプティカルマウススイッチ（耐クリック回数9,000万回、アクチュエーション0.2ms）」と記載されています。Logicool G304 Xのページには、スイッチの種類の記載がありません。Logicool G304 Xのページには、USBレポートレート1,000Hz・最大加速40G・最大スピード678インチ/秒の記載があります。
  • 保証は、Razer DeathAdder V3 HyperSpeedのメーカー公開仕様の欄が「最長2年間」、Logicool G304 Xが「2年間／1年間」と記載され、Logicool G304 Xの欄には型番との対応が明記されていないとの注記があります。接続は、Logicool G304 Xのメーカー公開仕様の欄が「LIGHTSPEED、Bluetooth」と記載され、付属品にUSB-A-USB-C充電／データケーブルがあります。

04場面別の選び方

使う場面ごとに、各商品ページの記載で見ておきたい点をまとめました。あくまで掲載情報にもとづく目安です。

  • とにかく軽いマウスを選びたいなら：Razer DeathAdder V3 HyperSpeedは55g、Logicool G304 Xは59gと記載されています。差は4gです。Logicool G304 Xのページには、前モデルG304から約40gの軽量化との記載があります。軽さの感じ方には個人差があるため、重量の数字だけで決めず、形や大きさもあわせて確認します。
  • パソコンやタブレットなど、複数の機器をつなぎ替えたいなら：Logicool G304 Xは、LIGHTSPEEDとBluetoothの両方に対応と記載されています。Razer DeathAdder V3 HyperSpeedのページには、Bluetooth接続の記載がありません。Razer DeathAdder V3 HyperSpeedは、HyperSpeed Wirelessのドングル接続で、ドングルを挿すUSBポートが必要と記載されています。
  • バッテリーの持ちを重視するなら：Logicool G304 Xは「約130時間持続（連続利用の目安）」で、内蔵充電式のリチウムイオン電池と記載されています。Razer DeathAdder V3 HyperSpeedは「最大100時間」と記載されています。どちらも使い方で変わる目安のため、実際の持続時間は条件で異なります。
  • 右利きで、握りやすい形を重視するなら：Razer DeathAdder V3 HyperSpeedは、右利き用のエルゴノミックデザインと記載されています。Logicool G304 Xのページには、利き手についての記載がなく、形状や手の大きさとの相性は個人差があるとされています。実機で形を確認できない場合は、サイズの数値を参考にします。
  • センサーの設定やライティングを、ソフトで調整したいなら：Logicool G304 Xは、HERO 44Kセンサー（100〜44,000dpi）で、LIGHTSYNC RGBをLogicool G HUBでカスタマイズできると記載されています。Razer DeathAdder V3 HyperSpeedは、Focus X 26Kセンサー（最大26,000 DPI）と記載されています。Razer DeathAdder V3 HyperSpeedの設定に使うソフトウェアの記載は、ページにありません。

05スペック用語のかんたん解説

比較表に出てくる用語を、一般的な意味で簡単に説明します。数値や対応の有無は各商品ページ・Amazon商品ページでご確認ください。

▸DPI（dpi）

マウスを1インチ動かしたときに、画面上のカーソルが何ドット動くかを表す数値です。数字が大きいほど、少ない動きでカーソルが大きく動く設定にできます。Logicool G304 Xのメーカー公開仕様の欄に「100〜44,000dpi」、Razer DeathAdder V3 HyperSpeedに「最大26,000 DPI」と記載されています。

▸レポートレート（ポーリングレート）

マウスが、1秒間に何回、位置などの情報をパソコンへ送るかを表す数値です。単位はHzです。Logicool G304 Xのメーカー公開仕様の欄に、USBレポートレート1,000Hzと記載されています。Razer DeathAdder V3 HyperSpeedのページには、記載がありません。

▸LIGHTSPEEDとHyperSpeed Wireless

どちらも、メーカー独自のワイヤレス通信方式の名称です。専用の小型レシーバー（ドングル）をパソコンのUSBポートに挿して使います。Logicool G304 XのページはLIGHTSPEED、Razer DeathAdder V3 HyperSpeedのページはRazer HyperSpeed Wirelessと記載されています。Razer DeathAdder V3 HyperSpeedのページには、Bluetoothとは別のドングルが必要と記載されています。

▸オプティカルスイッチ

ボタンの押下を、物理的な接点ではなく光で検知する方式です。一般に、接点の摩耗が起きにくいとされます。Razer DeathAdder V3 HyperSpeedのメーカー公開仕様の欄に「第3世代Razerオプティカルマウススイッチ」と記載されています。Logicool G304 Xのページには、スイッチの種類の記載がありません。

▸最大加速・最大スピード

センサーが追従できる、マウスを動かす加速度（G）と速さ（インチ/秒）の上限を示す数値です。Logicool G304 Xのメーカー公開仕様の欄に「40G、678インチ/秒（使用環境により異なる）」と記載されています。Razer DeathAdder V3 HyperSpeedのページには、記載がありません。

07よくある質問

Q.G304 XとDeathAdder V3 HyperSpeedの主な違いは何ですか？

各商品ページの記載では、重量はG304 Xが59g、DeathAdder V3 HyperSpeedが55gです。接続はG304 XがLIGHTSPEEDとBluetooth、DeathAdder V3 HyperSpeedがドングル接続とケーブルで、バッテリーは約130時間と100時間と記載されています。

Q.Bluetoothで使えますか？

G304 Xのページには、LIGHTSPEEDとBluetoothの接続方式が記載されています。DeathAdder V3 HyperSpeedのページには、HyperSpeed Wirelessのドングルとケーブルの記載はありますが、Bluetooth接続の記載はありません。

Q.ボタン数はいくつですか？

G304 Xのページには6ボタンと記載されています。DeathAdder V3 HyperSpeedのページには、ボタン数の記載がありません。購入前に、メーカー情報やAmazon商品ページでご確認ください。

Q.左利きでも使えますか？

DeathAdder V3 HyperSpeedのページには、右利き用のエルゴノミックデザインと記載されています。G304 Xのページには、利き手についての記載はなく、形状や手の大きさとの相性は個人差があるとされています。

Q.どちらを選べばいいですか？

LIGHTSPEEDとBluetoothの両方に対応する記載と約130時間のバッテリー、HERO 44Kセンサーの記載を重視するならG304 X、55gの重量と右利き用のエルゴノミックな形を重視するならDeathAdder V3 HyperSpeedのページが候補になります。マウス選びの見方はワイヤレスマウスの選び方ガイドもご覧ください。

Q.センサーの違いを教えてください。

Logicool G304 Xは「HERO 44Kセンサー」で、メーカー公開仕様の欄に100〜44,000dpiと記載されています。Razer DeathAdder V3 HyperSpeedは、メーカー公開仕様の欄に「Focus X 26K オプティカルセンサー」・最大26,000 DPIと記載されています。センサーの数字の大小は、使いやすさを直接示すものではありません。

Q.大きさや重さを教えてください。

Logicool G304 Xは、重量59g、メーカー公開仕様の欄のサイズが63.9×38.2×117.3mmと記載されています。Razer DeathAdder V3 HyperSpeedは、重量55g、サイズが長さ122.2×幅64.8×高さ41.3mmと記載されています。Logicool G304 Xの寸法は項目名の並び（横×奥行×高さ）と数値の大きさが対応しているか分かりにくいため、実際の形はメーカー情報でご確認ください。

Q.バッテリーの持続時間を教えてください。

Logicool G304 Xは「約130時間持続（連続利用の目安）」、Razer DeathAdder V3 HyperSpeedは「最大100時間」と記載されています。Logicool G304 Xは、バッテリー時間が条件付きの目安とされています。どちらも、実際の持続時間は使い方によって変わります。

Q.G304 Xは有線でも使えますか？

Logicool G304 Xのメーカー公開仕様の欄の接続は「LIGHTSPEED、Bluetooth」で、付属品にUSB-A-USB-C充電／データケーブルがあります。有線で使えるかは、購入前にメーカー情報でご確認ください。

Q.対応OSはどうなっていますか？

Razer DeathAdder V3 HyperSpeedのページには、パソコン・Windows 10／Windows 11と記載されています。Logicool G304 Xのページには、対応OSの記載がありません。MacやほかのOSで使いたい場合は、メーカー情報で対応を確認してください。

Q.保証期間を教えてください。

Razer DeathAdder V3 HyperSpeedのメーカー公開仕様の欄に「最長2年間」と記載されています。Logicool G304 Xの欄には「2年間／1年間」と記載され、型番との対応はメーカーのページに明記がないとされています。保証の条件は、購入前にメーカーの案内でご確認ください。
