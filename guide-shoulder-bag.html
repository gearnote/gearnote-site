01まず知っておきたい肩掛けバッグの種類

肩掛けや手持ちのバッグは、持ち方とサイズで分けられます。以下は一般的な説明で、実際の機能は商品ごとに異なります。

種類持ち方・かたち一般的な特徴気をつけたい点
ショルダーバッグ肩や斜めに掛けて持つスマートフォンや財布から、タブレットまで入る商品がある中身が重いと片側の肩に負担が集まりやすい
ボディバッグ・ワンショルダー体に沿わせて斜めに掛けるコンパクトなかたち薄く小さく、荷物が少ない外出で使われる容量が小さいため、入れる物を絞る
サコッシュ薄手で、紐を肩に掛けて持つ小型のバッグ荷物が少ない日の外出に使われる容量が小さい。マチ（奥行き）の薄さを確認する
ウエストバッグ腰に巻いて持つ両手が空く。小型の商品が多い体に固定する長さ（ベルトの調節）を確認する
トートバッグ手持ちで持つ、開口部の広いバッグ出し入れがしやすい傾向がある開口部の閉じ方（ファスナーの有無）を確認する
ビジネスバッグ（ブリーフケース）手持ちとショルダーの2WAYなどのタイプがある書類やPCを入れる場面で使われるPCの対応サイズや書類の判型を確認する

どのかたちが優れているかではなく、入れる荷物の量と、持ち歩く時間に合わせて選ぶのが一般的です。

02スペック表で見る6つのポイント

1. 外寸と容量（L／ℓ）

外寸は、入れたい物が入るかの目安になります。容量が記載されていない商品も多いため、外寸と合わせて確認します。仕様表やメーカー公開仕様では、PORTER フレーム ショルダーバッグがW200×H150×D60mm・2ℓ、PORTER リフト ショルダーバッグ ポーチがW245×H145×D45mm・2ℓ、PORTER フォース ショルダーバッグ（S）がW280×H200×D85mm・4ℓ、PORTER ビート ショルダーバッグがW380×H265×D150mm・12ℓ、ace.GENE ホバーライト ショルダーバッグがW28×H20×D10cm・6L、Kanana project ECD-1 ショルダーバッグがW22×H25×D8cm・7L、Columbia プライスストリーム サコッシュが約1.5Lと記載されています。

2. 重量

重量は、荷物を入れる前の本体の重さです。軽いほど、荷物を入れた総重量を抑えやすい傾向があります。仕様表では、PORTER フレームが140g、PORTER フラッシュ（689-05940）が220g、Kanana project ECD-1が270g、ace.GENE ホバーライト ショルダーバッグが310g、PORTER フラッシュ（689-05938）が360g、PORTER リフトが370g、ace.GENE デュラムーブ ビジネスバッグが910gと記載されています。

3. 収納できる物の目安（A4・B4・タブレット・ペットボトル）

書類の判型や、タブレットの画面サイズ、ペットボトルが入るかは、仕様表に記載のある商品で確認できます。仕様表では、ace.GENE フレックスライト フィット ショルダーバッグがA4ファイル収納（収納サイズ W31.3×H23.1cm）と500mlペットボトルが縦に入るサイズ、ace.GENE ホバーライト ショルダーバッグが10インチのタブレット収納、ace.GENE リテントリー ビジネスバッグがB4・15インチPC収納、Kanana project ECD-1が7L（500mlペットボトル収納可）、PORTER フラッシュ トートバッグがA4サイズの書類が収納可能と記載されています。PORTER フレームは、スマートフォンやウォレットに加え文庫本なども収納可能とメーカーが説明しています。

4. 開口部と閉じ方

開口部の閉じ方は、中身のこぼれにくさと、出し入れのしやすさに関わります。仕様表では、PORTER フラッシュ トートバッグの開口部がファスナー仕様（メーカー公式サイト）、PORTER フォース（S）がファスナー、Columbia プライスストリーム サコッシュが面ファスナー、Champion トートバッグ ブライアンがファスナーのクロージャーと記載されています。PORTER フラッシュ（689-05938）は、開口部が大きく開く構造とメーカーが説明しています。

5. ポケットと付属品

ポケットの数や位置は、小物の整理のしやすさに関わります。仕様表では、PORTER フォース（S）がポケット6ヶ所（Amazon掲載値）・取り外し可能なショルダーストラップ、PORTER リフトが正面のマチ付きファスナーポケットと背面のファスナー付きクッションメッシュポケット・取り外し可能なキーフォブ、Kanana project ECD-1が外ポケット（フロントファスナーポケット×2ほか）と内ポケット（メッシュファスナーポケット×1ほか）、ace.GENE ビジネストート スリブライトがオーガナイザーポケットと、ペットボトル・折りたたみ傘を立てて収納できる内側スペースと記載されています。

6. 素材・撥水加工・金具

素材名と加工名は、お手入れや雨の日の扱い方の目安になります。撥水加工やファスナーの記載があっても、完全に水を防ぐとは限りません。仕様表では、PORTER フラッシュ（689-05938）がナイロンオックス（テフロンファブリックプロテクター加工）とYKK Water-Rファスナーで、メーカーは、Water-Rファスナーは簡易的な撥水処理で、完全に水の侵入を防ぐものではないと注記しています。PORTER クリップ 2WAYブリーフケースは、生地の裏面にPVC加工をしているため雨天でも水が染み込みにくいとメーカーが説明しています。ace.GENE デュラムーブは、本商品は完全防水仕様ではありませんと記載されています。Columbia プライスストリーム サコッシュは機能欄にオムニシールド（撥水）と記載されています。

05撥水・防水まわりの記載の読み方（各商品ページの記載から）

肩掛けバッグでは、撥水の記載をよく目にします。当サイトの商品ページでは、次のように記載されています。程度は商品ごとに異なるため、メーカーの案内で確認してください。

  • PORTER フラッシュ（689-05938）・フラッシュ トートバッグ：テフロンファブリックプロテクター加工・YKK Water-Rファスナー・内装は撥水加工のリップストップタフタ。メーカーは、Water-Rファスナーは簡易的な撥水処理で、完全に水の侵入を防ぐものではないと注記
  • PORTER クリップ 2WAYブリーフケース：メーカーは、生地の裏面にPVC加工をしているため、雨天でも水が染み込みにくいと説明
  • PORTER リフト：メーカーは、生地の裏面のPVC加工でハリ感を出し、水滴が染み込みにくいと説明
  • ace.GENE デュラムーブ：備考に、本商品は完全防水仕様ではありませんと記載
  • Columbia プライスストリーム サコッシュ：機能にオムニシールド（撥水）と記載

撥水加工は、水を弾きやすくする加工で、完全に水を防ぐ意味とは限りません。雨の日に大切な物を入れるときは、袋に入れるなどの工夫をしましょう。

06使う場面別の選び方

タブレットやA4の書類を入れたい

手持ちとショルダーを切り替えたい

PORTER クリップ 2WAYブリーフケースは手持ち／ショルダーの2WAYと記載されています。ace.GENE リテントリーはショルダーベルト付き、ace.GENE デュラムーブは特徴にショルダーベルト付きと記載があります。

トートとして、荷物の出し入れをしやすくしたい

開口部の閉じ方を確認します。PORTER フラッシュ トートバッグは開口部がファスナー仕様、Champion トートバッグ ブライアンはファスナーのクロージャー、Kanana project エマ A4トートはA4サイズ対応（W35×H27×D12cm・9L）と記載されています。

13失敗しやすいポイントと、安全に使うための基本

✅ こうすると失敗しにくい

⚠️ 避けたいこと

  • 外寸を確認せず、入れたい物が入る前提で選ぶ
  • 重い荷物を入れて、ストラップや金具に負担をかけ続ける
  • 濡れたまま、バッグを閉じて保管する
  • 直射日光の当たる場所や、高温になる車内に置いたままにする
  • 撥水加工の記載を、完全な防水と思い込む

15よくある質問

Q.ショルダーバッグの容量は、どれくらいを選べばよいですか？

入れたい物の量で考えるのが一般的です。当サイトの仕様表・メーカー公開仕様では、PORTER フレームが2ℓ、PORTER フォース（S）が4ℓ、ace.GENE ホバーライト ショルダーバッグが6L、Kanana project ECD-1が7L、PORTER ビートが12ℓと記載されています。容量の記載がない商品は、外寸で確認してください。

Q.A4の書類は、どのバッグに入りますか？

A4サイズ対応の記載がある商品を確認します。当サイトの仕様表では、ace.GENE フレックスライト フィットがA4ファイル収納（W31.3×H23.1cm）、PORTER フラッシュ トートバッグがA4サイズの書類が収納可能、Kanana project エマ A4トートがA4サイズ対応、ace.GENE スリブライトがA4対応と記載されています。厚みも考えて確認してください。

Q.タブレットは、どのバッグに入りますか？

タブレットの画面サイズ（インチ）の記載を確認します。当サイトの仕様表では、ace.GENE ホバーライト ショルダーバッグが10インチのタブレット収納（背面側のクッション付き）と記載されています。ほかのバッグは、タブレットの記載がない場合があるため、外寸で確認してください。

Q.サコッシュとショルダーバッグは、どう違いますか？

サコッシュは、薄手で小型のバッグを指すことが多い呼び方です。当サイトの商品ページでは、PORTER コッピ サコッシュバッグが、自転車のロードレースで補給食や水筒を渡すためのバッグをモチーフにしたシリーズとメーカーに説明され、W330×H230mm・210gと記載されています。Columbia プライスストリームは約1.5Lです。

Q.撥水加工のバッグは、雨でも使えますか？

撥水加工は、水を弾きやすくする加工で、完全に水を防ぐ意味とは限りません。当サイトの商品ページでは、PORTER フラッシュのYKK Water-Rファスナーは簡易的な撥水処理で完全に水の侵入を防ぐものではないとメーカーが注記し、ace.GENE デュラムーブは完全防水仕様ではないと記載されています。

Q.バッグのサイズが、ページごとに違うのは、なぜですか？

Amazonの掲載値と、メーカー公式サイトの値で、記載が異なる場合があります。当サイトの商品ページでは、メーカー公式サイトの値を載せています。たとえばPORTER クリップ 2WAYブリーフケースの外寸は、メーカー公式サイトでW410×H290×D60mmと記載されています。食い違うときは、メーカー公式の値を優先して確認してください。

Q.ペットボトルが入るかは、どこで確認しますか？

仕様表の『ボトルホルダー』や『ペットボトル収納可』の記載を確認します。当サイトの仕様表では、Kanana project ECD-1が7L（500mlペットボトル収納可）、ace.GENE フレックスライト フィットが500mlペットボトルが縦に入るサイズ、Kanana project シェリがボトルホルダー付きと記載されています。
