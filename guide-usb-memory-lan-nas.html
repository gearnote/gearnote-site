01まず知っておきたい機器の種類

この3つの機器は、「データを持ち運ぶ」「ネットワークにつなぐ」「データを家庭内で共有する」という役割が異なります。以下は一般的な説明で、実際の機能は商品ごとに異なります。

種類しくみ一般的な特徴気をつけたい点
USBメモリUSB端子に挿して、データを保存・持ち運ぶ小さく軽く、キャップ式やノックスライド式など、端子の保護方法に違いがある規格名と速度の表記、ユーザー容量、対応OS、フォーマットの形式を確認する
有線LANアダプターUSB端子から、有線LAN（RJ-45）につなぐLAN端子がないパソコンや、ゲーム機で有線接続したい場面で使われる端子の形（Type-A/Type-C）、通信規格（1000BASE-Tなど）、対応OSを確認する
USB変換アダプターUSB-AとUSB-Cなど、端子の形を変換する手持ちのケーブルや機器の端子を合わせる用途で使われる転送規格（USB3.2 Gen1など）と、表記の意味を確認する
USBハブ（専用品）USBポートを増やす。専用機器向けの構成もあるポート数、カードリーダー、給電の条件が商品ごとに異なる対応する機器、電源アダプターの要否を確認する

どれが優れているかではなく、データを置く場所と、つなぐ機器に合わせて選ぶのが一般的です。

02USBメモリの表記の見方

1. 規格名（USB3.2 Gen1・USB2.0）

USBメモリの規格名は、通信の世代を示します。メーカー公式サイトの記載では、KIOXIA 128GB（KLU366A128G）・KIOXIA 256GB キャップ式（KLU301A256GW）・KIOXIA 256GB ノックスライド式（KLU304A256GR）は、インターフェースがUSB 3.2 Gen 1（USB 2.0互換）と記載されています。KIOXIA 32GB（KLU202A032GL）は、USB 2.0 high-speed対応と記載されています。バッファロー 64GB ノックスライド式（RUF3-KS64GA-WH/N）は、USB 3.2 Gen 1/3.1 Gen 1/3.0/2.0と、複数の世代名が並んで記載されています。商品名や仕様欄にUSB3.2 Gen1と書かれていても、実際の速度は次の2つの項目や、つなぐ機器の対応により異なります。

2. 読出速度・書込速度

速度の記載は、読出（保存したデータを読む）と書込（データを保存する）で数値が別になることがあります。メーカー公式サイトの記載では、KIOXIA 128GBの最大読出速度は200MB/s（128GB。32GB・64GBは100MB/s）、書込速度は数値の記載なしで、読出より遅いと案内されています。バッファロー 64GBは、読出速度がUSB 3.xで約90MB/s、USB 2.0で約36MB/s（規格値）、書込速度は数値の記載なしです。KIOXIA 256GBキャップ式・256GBノックスライド式・32GB（USB 2.0）は、メーカーのページに読出・書込速度の数値の記載がありません。数値の記載がない場合は、速度を知るための情報がないということで、遅いという意味ではありません。

3. 容量とユーザー容量

表示の容量（128GBなど）と、実際に保存に使える容量（ユーザー容量）は、異なる数値で示されることがあります。メーカー公式サイトの記載では、KIOXIA 128GBのユーザー容量は115.2GB、KIOXIA 256GBキャップ式と256GBノックスライド式のユーザー容量は230.4GBと記載されています。一般に、この差は管理領域や容量表記の計算方法などの違いによるとされます。詳しくは商品ごとのメーカー案内で確認します。

4. 形状・サイズ・質量・端子の保護方法

形状は、差し込む端子の保護の方法で分けられます。メーカー公式サイトの記載では、KIOXIA 128GBは外形寸法39.0×12.2×4.5mm・約6g、KIOXIA 256GBキャップ式はキャップ含めて51.4×21.4×8.4mm・約8g、KIOXIA 256GBノックスライド式はコネクタ格納時55.5×20.5×10.4mm・約9g（ストラップ穴あり、ストラップは付属しない）、KIOXIA 32GBは51.4×21.4×8.4mm（キャップを含む）・約8g、バッファロー 64GBノックスライド式は19.8×10×66mm（本体のみ・突起部除く）・約12gと記載されています。寸法の書き方（幅×奥行×高さの順）が商品ごとに異なる点に注意します。

5. 動作温度・出荷時フォーマット・保証・対応OS

メーカー公式サイトの記載では、KIOXIAの4商品は動作温度が0〜50℃（結露なし）、保証が購入日から1年（32GBは保証対象製品リストで1年）、対応OSがWindows 11、macOS Ventura 13〜Tahoe 26（2026年5月11日時点）と記載されています。バッファロー 64GBは、動作環境が0〜40℃・湿度0〜90%、電源がUSBバスパワー5.0V±5%・最大2.5W、出荷時フォーマットがFAT32、保証が1年間と記載されています。商品ページの仕様欄では、FAT32の出荷時の状態では4GB以上のファイルはexFAT等への再フォーマットが必要と記載されています（この4GB以上の記載はAmazon掲載情報（メーカー公式ページには記載がありません））。

04有線LANアダプター・変換アダプター・専用ハブの表記の見方

1. LANの通信規格と端子

有線LANアダプターは、端子の形と通信規格を確認します。メーカー公式サイトの記載では、バッファロー LUA6-U3-AGTE-NBKは、LANが1000/100/10Mbps（1000BASE-T / 100BASE-TX / 10BASE-T）、AUTO-MDIX、RJ-45で、USBはType-A（USB 3.2 Gen 1/3.1 Gen 1/3.0/2.0/1.1）と記載されています。Belkin F2CU040BTBLKは、Belkinの英語版公式ページで、10/100/1000BASE-T（最大1Gbps）、USB-C（オス）からRJ-45（メス）と記載されています。USB-AかUSB-Cかは、パソコンやタブレットの端子に合わせて選びます。

2. ジャンボフレームや対応OS・機器

対応OSや機器は、商品ごとに条件が異なります。メーカー公式サイトの記載では、バッファロー LUA6-U3-AGTE-NBKはジャンボフレームがWindowsのみで、MacとNintendo Switchは対応していないと記載されています。各商品ページの仕様欄の記載では、対応OSはWindows 10以降・macOS 13以降、対応デバイスはゲーム機・デスクトップパソコン・ノートパソコンです（Amazon掲載情報（メーカー公式ページには記載がありません））。Belkinの英語版公式ページでは、Belkin F2CU040BTBLKの対応OSはMac、Windows、Chrome OSと記載されています。商品ページの仕様欄の対応機種には、iPad Pro・MacBook Pro/Air・Surface・Chromebook・iPhone 15が挙げられています（Amazon掲載情報（メーカー公式ページには記載がありません））。

3. 電源・消費電力・給電の有無

メーカー公式サイトの記載では、バッファロー LUA6-U3-AGTE-NBKの電源はUSBバスパワー5V・最大0.75W（最大149mA）と記載されています。Belkinの英語版公式ページでは、Belkin F2CU040BTBLKは給電機能（Power Delivery）がなく、電源ユニットは付属しないと記載されています。充電しながら使いたい場合は、給電に対応する別の機器が必要になります。

4. 変換アダプター（USB-A→USB-C）の表記

端子の形を変えるアダプターは、変換の向きと転送規格を確認します。各商品ページの仕様欄の記載では、UGREEN USB Type C 変換アダプター 2個セットは、規格がUSB-A（メス）to USB-C（オス）変換、転送規格がUSB3.2 Gen1、特徴にOTG対応・Thunderbolt 3互換と記載されています（Amazon掲載情報（メーカー公式ページには記載がありません））。「互換」の意味や、実際に出る速度は、つなぐ機器とケーブルの組み合わせで異なるため、取扱説明書とメーカーの案内で確認します。変換の向き（メス・オス）は、つなぐ端子の形に合わせて見ます。

5. 専用USBハブの確認ポイント

専用のUSBハブは、対応機器と電源の条件を確認します。メーカー公式サイトの記載では、Elgato USBハブ（Stream Deck +用）は、ダウンリンクにUSB 3.2 Gen 1のType-Aが2つとType-Cが2つで合計5Gb/s、SDとmicroSDのカードリーダーを備え、アップリンク給電は65Wと記載されています。動作にはStream Deck +（別売）と、100W・PD 3.0対応の外部USB-C電源アダプター（付属しません）が必要で、対応OSはWindows 11以降、macOS 13以降（Stream Deckアプリが必要）と記載されています。一般的なUSB-Cハブの見方は、USB-Cハブの選び方ガイドをご覧ください。

07使う場面別の選び方

書類や写真を、小さく持ち運びたい

サイズと質量、形状を見ます。メーカー公式サイトの記載では、KIOXIA 128GBは39.0×12.2×4.5mm・約6g、バッファロー 64GBノックスライド式は19.8×10×66mm・約12gと記載されています。端子を保護する方式（キャップなし、キャップ式、ノックスライド式）は、使い方に合わせて選びます。

大きな動画やデータをやり取りしたい

規格名と、読出・書込速度の記載を見ます。KIOXIA 128GBは最大読出速度200MB/s（128GB）と記載されていますが、書込速度は数値の記載がありません。バッファロー 64GBは読出速度がUSB 3.xで約90MB/sと記載されています。容量の大きいデータを扱う場合は、メモリとつなぐ機器の対応規格もあわせて確認します。外付けSSDなどは外付けストレージの選び方ガイドをご覧ください。

ゲーム機やデスクトップで、有線LANにつなぎたい

バッファロー LUA6-U3-AGTE-NBKは、USB Type-AでRJ-45につなぐ有線LANアダプターで、各商品ページの仕様欄に対応デバイスとしてゲーム機・デスクトップパソコン・ノートパソコンが記載されています（Amazon掲載情報（メーカー公式ページには記載がありません））。ジャンボフレームはWindowsのみの対応と、メーカー公式サイトに記載されています。つなぐ機器の端子（USB-A）とOSを、先に確認します。

USB-C端子だけのパソコンやタブレットで、有線LANにつなぎたい

Belkin F2CU040BTBLKは、USB-C（オス）からRJ-45（メス）に変換し、Belkinの英語版公式ページで最大1Gbpsと記載されています。給電機能（PD）はなく、充電しながらの使用は別の機器が必要です。ハブの選び方はUSB-Cハブの選び方ガイドも参考になります。

手持ちのUSB-A機器を、USB-C端子につなぎたい

UGREEN USB Type C 変換アダプターは、各商品ページの仕様欄で、USB-A（メス）to USB-C（オス）変換の2個セットと記載されています（Amazon掲載情報（メーカー公式ページには記載がありません））。変換の向きがつなぐ端子と合っているか、転送規格（USB3.2 Gen1）が機器の対応と合うかを確認します。

Stream Deck +を使っていて、USBポートを増やしたい

11筆者の計算①：読出速度から転送時間を、ユーザー容量から保存量を見積もる

速度の記載（MB/s）から、10GBを読み出すのにかかる時間の目安を計算します。計算式：時間（秒）＝ データ量（MB）÷ 速度（MB/s）。前提：1GB＝1,000MBとして、データ量は10GB（10,000MB）、速度はページの最大値・規格値のまま、読み出しのみ、ファイルの数や機器の処理時間は含めない、という単純な計算です。実際の時間はこれより長くなる場合があります。読出速度の数値がある2台（n＝2、3つの条件）が対象です。

16よくある質問

Q.USB3.2 Gen1と書いてあれば、速度はどれも同じですか？

同じとは限りません。規格名は通信の世代を示すもので、実際の速度は商品ごとの読出・書込速度と、つなぐ機器の対応により異なります。メーカー公式サイトの記載では、KIOXIA 128GBは最大読出速度200MB/s、バッファロー 64GBは読出速度がUSB 3.xで約90MB/s（規格値）と記載されています。

Q.読出速度は載っているのに、書込速度が載っていないのはなぜですか？

メーカーが数値を示していない場合があります。メーカー公式サイトでは、KIOXIA 128GBの書込速度は数値の記載なし（読出より遅いと案内）、バッファロー 64GBの書込速度も数値の記載なしです。数値が記載されていないことは、速度が遅いという意味ではありません。

Q.表示の容量と、ユーザー容量は、どう違いますか？

表示の容量は商品名などに書かれる数値で、ユーザー容量は実際に保存に使える容量です。メーカー公式サイトの記載では、KIOXIA 128GBのユーザー容量は115.2GB、KIOXIA 256GBの2商品は230.4GBと記載されています。

Q.キャップ式とノックスライド式は、どう違いますか？

端子を保護する方式が異なります。キャップ式はキャップで端子を覆い、ノックスライド式はコネクタを出し入れします。メーカー公式サイトの記載では、KIOXIA 256GB（KLU301A256GW）はキャップ含めて51.4×21.4×8.4mm、KIOXIA 256GB（KLU304A256GR）はコネクタ格納時55.5×20.5×10.4mmと記載されています。

Q.バッファロー USBメモリは、すぐに大きなファイルを保存できますか？

出荷時の状態を確認します。メーカー公式サイトの記載では、出荷時フォーマットはFAT32です。商品ページの仕様欄には、4GB以上のファイルはexFAT等への再フォーマットが必要と記載されています（この4GB以上の記載はAmazon掲載情報（メーカー公式ページには記載がありません））。再フォーマットするとデータが消えるため、手順は取扱説明書で確認してください。

Q.有線LANアダプターは、どの端子のものを選べばよいですか？

つなぐ機器の端子で決まります。メーカー公式サイトの記載では、バッファロー LUA6-U3-AGTE-NBKはUSB Type-A、Belkin F2CU040BTBLKはUSB-C（オス）からRJ-45（メス）と記載されています。パソコンやタブレットのUSB端子の形を確認してください。

Q.バッファロー LANアダプターで、ジャンボフレームは使えますか？

メーカー公式サイトの記載では、ジャンボフレームはWindowsでのみ使え、MacとNintendo Switchは対応していません。設定を有効にする場合は、つなぐ機器やネットワーク側の対応も確認してください。

Q.BelkinのUSB-C LANアダプターは、充電しながら使えますか？

Belkinの英語版公式ページでは、給電機能（Power Delivery）はなく、電源ユニットは付属しないと記載されています。充電しながら使いたい場合は、別の機器が必要です。

Q.UGREENの変換アダプターの「Thunderbolt 3互換」は、何を意味しますか？

各商品ページの仕様欄に、特徴としてOTG対応・Thunderbolt 3互換と記載されています（Amazon掲載情報で、メーカー公式ページには記載がありません）。互換の範囲や実際の速度は、つなぐ機器とケーブルにより異なるため、取扱説明書とメーカーの案内で確認してください。

Q.Elgato USBハブは、一般のパソコンでも使えますか？

メーカー公式サイトでは、Stream Deck +用のオプションと記載されています。動作にはStream Deck +（別売）と、100W・PD 3.0対応の外部USB-C電源アダプター（付属しません）が必要で、対応OSはWindows 11以降、macOS 13以降（Stream Deckアプリが必要）と記載されています。

Q.NASは、購入するとすぐにデータを保存できますか？

商品によって異なります。各商品ページの仕様欄の記載では、UGREEN NASync DH2300は、HDD付属なし・最大ストレージ64TB（HDD別売）と記載されています（Amazon掲載情報（メーカー公式ページには記載がありません））。別にドライブを用意し、取扱説明書に沿って設定する必要があります。

Q.10GBのデータを読み出す時間は、読出速度から計算できますか？

目安として計算できます（筆者の計算：時間＝データ量÷速度、1GB＝1,000MB）。KIOXIA 128GBの最大読出速度200MB/sでは10,000÷200＝50.0秒、バッファロー 64GBのUSB 3.xの約90MB/s（規格値）では約111.1秒、USB 2.0の約36MB/s（規格値）では約277.8秒です。最大値・規格値をそのまま使った計算で、実際はより長くなることがあります。書込速度の数値は、当サイトの5台すべてで記載がありません。

Q.MB/sとMbpsは、どう換算しますか？

1バイトは8ビットなので、MB/s＝Mbps÷8です（筆者の計算）。有線LANの1000BASE-T（1,000Mbps）は125MB/s、100BASE-TX（100Mbps）は12.5MB/sに当たります。逆に、KIOXIA 128GBの200MB/sは1,600Mbpsです。LANの数字は理論上の上限で、実際の速度は、ルーターやケーブル、機器により、これより小さくなります。

Q.100GBのデータを保存したいとき、容量はどう見積もればよいですか？

商品名の容量ではなく、ユーザー容量で考えます。当サイトでユーザー容量の記載がある3台では、いずれも表示容量の90.0％でした（筆者の計算：115.2÷128、230.4÷256）。たとえばKIOXIA 128GBはユーザー容量115.2GBなので、100GBとの差は15.2GBです。KIOXIA 32GBとバッファロー 64GBはユーザー容量の記載がないため、同じ割合とは言えず、メーカーの案内で確認してください。
