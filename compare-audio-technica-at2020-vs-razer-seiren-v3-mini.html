オーディオテクニカ AT2020とRazer Seiren V3 Miniの違いを比較

02違いのまとめ

  • 接続は、AT2020が「XLR」（メーカー公開情報では3ピンXLR-Mタイプ）、Seiren V3 Miniが「USB Type-A（USB Type-A−Type-Cケーブル付属）・プラグアンドプレイ（ソフト・ドライバー不要）」と記載されています。
  • 電源は、AT2020が「48V DC、2mA（要ファントム電源対応オーディオインターフェース）」、Seiren V3 Miniがメーカー公開情報で必要な電力5V／350mAと記載されています。AT2020のページには、USB直結には対応していないと記載されています。
  • 型式と指向性は、AT2020が「バックエレクトレットコンデンサー型（サイドアドレス）」「単一指向性」、Seiren V3 Miniが「14mmのカスタムコンデンサーカプセル」「スーパーカーディオイド（単一指向性）」と記載されています。
  • 数値は、周波数特性がどちらも20Hz〜20kHz、感度がAT2020は-37dB（14.1mV）、Seiren V3 Miniは-36dB（1V/Pa（1kHz））、最大音圧レベルがAT2020は144dB SPL（1kHz THD 1%）、Seiren V3 Miniは110dBと記載されています。Seiren V3 Miniにはサンプリングレート96kHz・24bitの記載もあります。測定条件の表記が異なるため、数値は参考としてご覧ください。
  • 付属品とスタンドは、AT2020がスタンドマウント（AT8466）・変換ネジ・ポーチ（メーカー公開情報）、Seiren V3 Miniが角度調整できるショックマウント・デスクスタンドベース・サポートロッド・USBケーブルなどと記載されています。タップトゥミュートセンサーとLEDインジケーターの記載があるのは、Seiren V3 Miniのページです。
  • 質量は、オーディオテクニカ AT2020のメーカー仕様に345gと記載されています。Razer Seiren V3 Miniのページには、質量の記載がありません。手元に置くスタンドやアームの選び方に関わるため、気になる場合はRazer Seiren V3 MiniのAmazon商品ページもご確認ください。
  • 保証については、オーディオテクニカ AT2020のページに「国内正規品で1年間の保証付き」と記載されています。Razer Seiren V3 Miniのページには、保証期間の記載がありません。
  • デジタル音声の仕様は、Razer Seiren V3 Miniのメーカー情報にサンプリングレート96kHz、ビット深度24bitと記載されています。オーディオテクニカ AT2020のページには、これらの記載がありません。XLRマイクはアナログ信号を出力し、デジタルへの変換は接続先の機器で行うのが一般的です。

03こんな人にはこちら

▸オーディオテクニカ AT2020が向いている人

AT2020のページでは、XLR接続のサイドアドレス型コンデンサーマイクで、ファントム電源に対応したオーディオインターフェースが必要なモデルと説明されています。

  • オーディオインターフェイスを持っている、または導入予定の人
  • 自宅録音や動画配信の音質を底上げしたい人
  • 単一指向性でノイズを拾いにくくしたい人

▸Razer Seiren V3 Miniが向いている人

Seiren V3 Miniのページでは、USB接続のプラグアンドプレイに対応し、タップ式のミュートセンサーを備えた小型のコンデンサーマイクと説明されています。

  • ゲーム配信やチャットで、小型のUSBマイクを使いたい人
  • タイピング音などの周囲のノイズを入りにくくしたい人
  • デスクの上を省スペースにしたい人

04場面別の選び方

使う場面ごとに、各商品ページの記載で見ておきたい点をまとめました。あくまで掲載情報にもとづく目安です。

  • パソコンにつないで、すぐ使い始めたいなら：USB接続のプラグアンドプレイ（ソフト・ドライバー不要）と記載のあるRazer Seiren V3 Miniのページが参考になります。USB Type-A−Type-Cケーブルも付属すると記載されています。
  • オーディオインターフェースやミキサーを、すでに持っているなら：XLR接続でファントム電源48Vが必要なオーディオテクニカ AT2020のページが参考になります。手持ちの機器にファントム電源の機能があるか、事前に確認します。
  • 机の上のスペースが限られているなら：デスクスタンドベースが付属し、ブームアームにも取り付けられると記載のあるRazer Seiren V3 Miniのページが参考になります。オーディオテクニカ AT2020は質量345gで、付属のスタンドマウント（AT8466）は固定用の部品です。マイクスタンド本体は、メーカーの付属品欄に記載がありません。
  • 通話や配信中に、すばやくミュートしたいなら：マイク上部をタップするミュートセンサーとLEDインジケーターが記載されているRazer Seiren V3 Miniのページが参考になります。オーディオテクニカ AT2020のページには、ミュート機能の記載がありません。
  • 仕様の数値を見比べてから決めたいなら：オーディオテクニカ AT2020のページには、感度・SN比・最大入力音圧レベル（144dB SPL）・質量が記載されています。Razer Seiren V3 Miniのメーカー情報には、感度（-36dB）と最大音圧レベル（110dB）が記載されています。測定条件の表記が異なるため、数値は参考として見ます。

05スペック用語のかんたん解説

比較表に出てくる用語を、一般的な意味で簡単に説明します。数値や対応の有無は各商品ページ・Amazon商品ページでご確認ください。

▸ファントム電源

XLR接続のコンデンサーマイクを動かすために、オーディオインターフェースやミキサー側から送られる電源です。オーディオテクニカ AT2020のページに「48V DC、2mA」と記載があります。ファントム電源に対応していない機器では、動作しません。

▸XLR

3本のピンを持つ、音響機器で広く使われる接続端子の規格です。オーディオテクニカ AT2020のメーカー仕様に「3ピンXLR-Mタイプ」と記載されています。パソコンのUSB端子には直接つながらないため、オーディオインターフェースなどが必要です。

▸サイドアドレス型

マイクの先端ではなく、側面に向かって話す（音を拾う）構造のマイクを指す名称です。オーディオテクニカ AT2020のページに「バックエレクトレットコンデンサー型（サイドアドレス）」と記載されています。一般に、音を拾う面が決まっているため、取扱説明書で向きを確認します。

▸スーパーカーディオイド

指向特性の名称で、マイクの前方の音を中心に拾う、単一指向性の一種です。一般にカーディオイドよりも前方に絞って拾いますが、真後ろにも少し感度が残ります。Razer Seiren V3 Miniのページに「スーパーカーディオイド（単一指向性）」と記載があります。

▸サンプリングレートとビット深度

デジタルの音声データの細かさを示す数値です。サンプリングレートは1秒間に音を測る回数、ビット深度は1回の音の大きさを表す段階の細かさを指します。Razer Seiren V3 Miniのメーカー情報に96kHz・24bitと記載されています。

購入前に見ておくと安心な項目です。各商品ページの記載にもとづくため、最終的にはAmazon商品ページの最新情報もご確認ください。

  • 接続する機器：オーディオテクニカ AT2020はファントム電源（48V）対応のオーディオインターフェースやミキサーが必要。Razer Seiren V3 Miniはパソコン側にUSB Type-Aの端子が必要。
  • ケーブル：Razer Seiren V3 MiniはUSB Type-A−Type-Cケーブルが付属。オーディオテクニカ AT2020のメーカー仕様ページには、XLRケーブルの記載がない。
  • スタンド：オーディオテクニカ AT2020はスタンドマウント（AT8466）と変換ネジが付属するが、スタンド本体の記載はない。Razer Seiren V3 Miniはデスクスタンドベースとサポートロッドが付属。
  • 使う場所：Razer Seiren V3 Miniのページには、全指向性ではないため複数人の音を同時に拾う用途には向かないと記載がある。会議室のような場面では、用途を確認する。
  • 音の調整：Razer Seiren V3 Miniはソフトやドライバーが不要なため、細かい音の調整機能は少ないとRazer Seiren V3 Miniのページに記載がある。細かく調整したい場合は、接続機器側の機能も確認する。
  • 数値の見方：感度や最大音圧レベルは、測定条件の表記が両ページで異なる。数値の差だけで判断せず、参考として見る。

07よくある質問

Q.AT2020とSeiren V3 Miniの主な違いは何ですか？

各商品ページの記載では、接続がAT2020はXLR（ファントム電源48V）、Seiren V3 MiniはUSB Type-A（プラグアンドプレイ）です。指向特性は、どちらも単一指向性の仕様と記載されています。最大音圧レベルは144dB SPLと110dB、感度は-37dBと-36dBと記載されていますが、測定条件の表記が異なります。

Q.パソコンに直接つなげるのはどちらですか？

Seiren V3 Miniのページには、ソフトウェアやドライバーが不要なプラグアンドプレイと記載されています。AT2020のページには、XLR接続のためファントム電源対応のオーディオインターフェイスやミキサーが必要で、USB直結には対応していないと記載されています。

Q.ファントム電源とは何ですか？

AT2020のページでは、マイクを動作させるために必要な48Vの電源供給のことで、オーディオインターフェイスやミキサー側から供給されると説明されています。Seiren V3 Miniのページには、ファントム電源の記載はありません。

Q.どちらを選べばいいですか？

接続方式を基準にすると整理しやすくなります。手持ちのオーディオインターフェイスやミキサーにXLRで接続したい場合はAT2020、USBでパソコンに直接つなぎたい場合やタップ式ミュートの記載を重視する場合はSeiren V3 Miniのページが候補になります。マイク選びの基本はマイクの選び方ガイドにまとめています。

Q.ファントム電源に対応していない機器でも、AT2020は使えますか？

オーディオテクニカ AT2020のページには、ファントム電源（48V）が必須で、対応機器がないと使えないと記載されています。手持ちの機器の仕様を確認するか、ファントム電源に対応した機器を別に用意する必要があります。

Q.Seiren V3 Miniは、どのソフトに対応していますか？

Razer Seiren V3 Miniの仕様表に、Discord・OBS Studio・XSplitに対応と記載されています。ソフトやドライバーは不要と記載されていますが、お使いのパソコンやOSで使えるかは、メーカーの案内でご確認ください。

Q.周波数特性に違いはありますか？

メーカー情報では、オーディオテクニカ AT2020は20〜20,000Hz、Razer Seiren V3 Miniは20Hz〜20kHzと記載されていて、同じ範囲です。ただし、周波数特性の数値だけでは、実際の聞こえ方は分かりません。

Q.最大音圧レベルは、どちらが大きいですか？

メーカー情報では、オーディオテクニカ AT2020が144dB SPL（1kHz THD 1%）、Razer Seiren V3 Miniが110dBと記載されています。ただし、測定条件の表記が異なるため、そのまま比べることはできません。

Q.ケーブルは付属しますか？

Razer Seiren V3 Miniのページに、USB Type-A−Type-Cケーブルが付属すると記載されています。オーディオテクニカ AT2020は、メーカーの仕様ページに付属品として、スタンドマウント・変換ネジ・ポーチが示され、XLRケーブルの記載はありません。

Q.複数人でひとつのマイクを使うことはできますか？

Razer Seiren V3 Miniのページには、全指向性ではなく、複数人の音を同時に拾うのには向かないと記載されています。オーディオテクニカ AT2020も単一指向性と記載されているため、使う人数や位置は、マイクの向きとあわせて考えます。ほかの機種はイヤホン・オーディオのカテゴリページをご覧ください。
