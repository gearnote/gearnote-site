02違いのまとめ

  • センサーは、Link 2 Proが「1/1.3インチ」、Link 2Cが「1/2インチ」と記載されています。レンズはLink 2 ProがF/1.9（35mm換算24mm）、Link 2CがF1.8（35mm判換算26mm）です。
  • ジンバルは、Link 2 Proが「2軸」、Link 2Cが「なし」と記載されています。Link 2 Proのページには、PTZ（パン・チルト・ズーム）対応とAIトラッキングの記載があります。Link 2Cのページには、オートフレーミング、スマートホワイトボード、デスクビューの記載があります。
  • 固定視野角は、Link 2 Proが83.9° DFOV・71.4° HFOV、Link 2Cが79.5° DFOV・67° HFOVと記載されています。
  • サイズと重量は、Link 2 Proが71.3×58.9×38mm、磁気マウントなしで102.5g（磁気マウント付きで167.5g）、Link 2Cが62.7×30.2×26mm、磁気マウントなしで46.5g（磁気マウント付きで111.5g）と記載されています。
  • 動画は、どちらも4K@30/25/24fpsと記載されています。カラーは、Link 2 Proがグラファイトブラック、Link 2Cがグラファイトブラックとアークティックホワイトです。
  • オートフォーカスの範囲は、Insta360 Link 2 Proのページに「焦点距離：12cm～∞」、Insta360 Link 2Cのページに「撮影可能距離 10cm〜無限遠」と記載されています。Insta360 Link 2Cのページには、デジタルズーム最大4倍の記載もあります。Insta360 Link 2 Proのページのメーカー公開情報の欄には、デジタルズームの記載がありません。
  • 動画解像度は、Insta360 Link 2 Proが4K@30/25/24fps、1080p@60/50/30/25/24fps、720p@60/50/30/25/24fpsと記載されています。Insta360 Link 2Cはランドスケープが4K@30/25/24fps、1080pと720pは60fpsまでで、ポートレートは4K@30/25/24fpsと記載されています。動画コーデックは、Insta360 Link 2CのページにH.264とMJPEGの記載があり、Insta360 Link 2 Proのページには記載がありません。
  • システム要件は、Insta360 Link 2CのページにWindows 10以降（ARM版Windowsは非対応）、macOS 11.0以降（バーチャルカメラはmacOS 13.0以降）、CPU i5-5世代以降、RAM 8GB以上と記載されています。Insta360 Link 2 Proのページには「PC/Windows/Mac用」とあるのみで、バージョンやCPUの要件は記載がありません。

04場面別の選び方

使う場面ごとに、各商品ページの記載で見ておきたい点をまとめました。あくまで掲載情報にもとづく目安です。

  • 会議中に席を立ったり、体を動かしたりするなら：Insta360 Link 2 Proのページに、2軸ジンバルとPTZ対応、AIトラッキングの記載があります。Insta360 Link 2Cのページはジンバル「なし」で、オートフレーミングの記載です。カメラ自体が向きを変えられるかどうかが、2機種の大きな違いです。
  • 手元の資料やホワイトボードを映したいなら：Insta360 Link 2Cのページに、スマートホワイトボードとデスクビューの記載があり、撮影モードとして「デスクビュー、プライバシー、ホワイトボード、ポートレート」が挙げられています。Insta360 Link 2 Proのページには、これらのモードの記載がありません。
  • ノートパソコンと一緒に持ち歩くなら：サイズと重量は、Insta360 Link 2Cが62.7×30.2×26mmで磁気マウントなし46.5g、Insta360 Link 2 Proが71.3×58.9×38mmで磁気マウントなし102.5gと記載されています。磁気マウント付きでは、Insta360 Link 2Cが111.5g、Insta360 Link 2 Proが167.5gです。
  • 三脚やスタンドに載せて使うなら：Insta360 Link 2 Proのページに、外部三脚取り付け用の1/4インチねじ穴付き磁気マウントと記載されています。Insta360 Link 2Cのページには磁気マウント付きの重量の記載はありますが、ねじ穴などの形状の記載はありません。三脚の使用を考える場合は、Insta360 Link 2CのAmazon商品ページで確認してください。
  • 画面に近い距離で手元を映すことがあるなら：オートフォーカスの最短距離は、Insta360 Link 2 Proが12cm、Insta360 Link 2Cが10cmと記載されています。条件は異なるため、実際の映り方はAmazon商品ページとメーカーの案内でご確認ください。

05スペック用語のかんたん解説

比較表に出てくる用語を、一般的な意味で簡単に説明します。数値や対応の有無は各商品ページ・Amazon商品ページでご確認ください。

▸PTZと2軸ジンバル

PTZはパン（左右）・チルト（上下）・ズームをモーターなどで制御する機能の総称です。ジンバルは、カメラの向きを機械的に変える部品です。Insta360 Link 2 Proのページには「2軸」と記載があり、Insta360 Link 2Cのページは「なし」とされています。ジンバルがない場合の画角の追従は、画像を切り出して調整する方式（オートフレーミング）になります。

▸DFOVとHFOV

視野角を表す略称です。DFOVは対角方向、HFOVは水平方向の視野角とされます。数値が大きいほど、一度に映る範囲が広くなります。Insta360 Link 2 Proが83.9° DFOV・71.4° HFOV、Insta360 Link 2Cが79.5° DFOV・67°HFOVと記載されています。

▸F値と35mm換算焦点距離

F値は、レンズが取り込む光の量の目安で、数字が小さいほど多くの光を取り込めるとされます。35mm換算焦点距離は、画角を一般的なカメラの基準にそろえて表した値です。Insta360 Link 2 ProはF/1.9・24mm、Insta360 Link 2CはF1.8・26mmと記載されています。

▸fps

1秒間に表示するコマ数を示す単位です。会議では30fpsが一般的に使われます。60fpsは動きがなめらかになる反面、会議アプリ側の対応が必要な場合があります。両ページとも4Kは最大30fpsと記載されています。

▸H.264とMJPEG

映像を圧縮して送る形式の名称です。H.264は圧縮率が高く、MJPEGは1コマずつ圧縮する形式とされます。使われる形式は、接続するアプリの設定によって決まります。Insta360 Link 2Cのページに、4Kおよび1080p60fpsのポートレートモードはH.264をサポートしないとも記載されています。

  • 置き場所：Insta360 Link 2 Proは1/4インチねじ穴付き磁気マウント。Insta360 Link 2Cはねじ穴などの形状が記載なし。モニター上に置くか三脚を使うかを先に決める。

07よくある質問

Q.Insta360 Link 2 ProとLink 2Cの主な違いは何ですか？

各商品ページの記載では、センサーサイズ（Link 2 Proは1/1.3インチ、Link 2Cは1/2インチ）とジンバル（Link 2 Proは2軸、Link 2Cはなし）が異なります。本体の重量も、磁気マウントなしでLink 2 Proが102.5g、Link 2Cが46.5gと記載されています。

Q.カメラが自動で動く機能があるのはどちらですか？

Link 2 Proのページには、2軸ジンバルとPTZ（パン・チルト・ズーム）対応、AIトラッキングの記載があります。Link 2Cのページはジンバルが「なし」で、オートフレーミングの記載があります。動作の詳細は、購入前にAmazon商品ページとメーカーの案内でご確認ください。

Q.マイクの仕様に違いはありますか？

Link 2 Proのメーカー公開情報の欄には「2基（AIノイズキャンセリング）」と記載されています。Link 2Cのページには、AIノイズキャンセリング対応の記載がありますが、マイクの基数は記載されていません。

Q.どちらを選べばいいですか？

大きめのセンサーと2軸ジンバル、PTZ、AIトラッキングの記載を重視するならLink 2 Proのページが候補になります。軽さと小ささ、2色展開、オートフレーミングやデスクビューなどのモードを重視するならLink 2Cのページを確認するとよいでしょう。Webカメラ選び全般はWebカメラの選び方ガイドもご覧ください。

Q.視野角に違いはありますか？

固定視野角は、Insta360 Link 2 Proのページに83.9° DFOV・71.4° HFOV、Insta360 Link 2Cのページに79.5° DFOV・67°HFOVと記載されています。数値上はInsta360 Link 2 Proの方が広い範囲を映せる記載です。

Q.対応OSやパソコンの条件は同じですか？

Insta360 Link 2Cのページには、Windows 10以降（ARM版Windowsは非対応）、macOS 11.0以降（バーチャルカメラはmacOS 13.0以降）、CPU i5-5世代以降、RAM 8GB以上と記載されています。Insta360 Link 2 Proのページには、対応OSが「PC/Windows/Mac用」と記載されているのみです。

Q.ピントを合わせられる距離は同じですか？

Insta360 Link 2 Proのページに「対応（焦点距離：12cm～∞）」、Insta360 Link 2Cのページに「撮影可能距離 10cm〜無限遠」と記載されています。表記の項目名が異なるため、同じ条件の数値とは限りません。

Q.フレームレートは同じですか？

4Kは、どちらも30/25/24fpsまでと記載されています。1080pは、Insta360 Link 2 Proが60/50/30/25/24fps、Insta360 Link 2Cが60fpsまでと記載されています。720pも同様に、Insta360 Link 2 Proが60/50/30/25/24fps、Insta360 Link 2Cが60fpsまでです。

Q.手ブレ補正はありますか？

Insta360 Link 2Cのメーカー仕様欄には手ブレ補正の項目がなく、ジンバルは「なし」とされています。Insta360 Link 2 Proのページの仕様表には、手ブレ補正の記載がありません。2軸ジンバルの記載はあります。

Q.本体の電源は別に必要ですか？

Insta360 Link 2Cのページに、消費電力5V/1Aと記載され、接続はUSB-C（USB 2.0）とされています。Insta360 Link 2 Proのページには、消費電力の記載がありません。接続方法は両ページとも、USB-C - USB-Cケーブルまたは変換アダプターと記載されています。

Q.ウェブカメラの選び方を知りたいときは？

ウェブカメラの画角やマイクの見方はWebカメラの選び方ガイド、同じブランドの商品はInsta360の商品一覧でご覧いただけます。
