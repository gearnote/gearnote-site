  • 毎日バッグに入れて持ち歩きたいなら：重量は、Idea Tab Pro 12.7インチが約620g、Idea Tab 11インチが480g±10gと記載されています。Idea Tab Pro 12.7インチのページには、画面が大きい分、持ち運びに向かない場合があると書かれています。
  • ペンで手書きのメモを取りたいなら：Idea Tab Pro 12.7インチのメーカー公開仕様の欄に、Lenovo Tab Pen Plus（ペン）付属と記載されています。Idea Tab 11インチの欄には、付属品なしでペンは別売（Pen Upgradable）と記載されています。キーボードはIdea Tab Pro 12.7インチのページに付属しないと記載されています。
  • 外部ディスプレイにつないで使いたいなら：Idea Tab Pro 12.7インチのページにUSB 3.2 Type-C（DP-Out対応）と記載されています。Idea Tab 11インチのページはUSB 2.0 Type-Cの記載で、DP-Outについての記載はありません。
  • 有線のイヤホンをつなぎたいなら：Idea Tab 11インチのページに、マイク/ヘッドホンコンボジャックと記載されています。Idea Tab Pro 12.7インチのページの端子の記載には、ヘッドホンジャックは含まれていません。Idea Tab Pro 12.7インチのメーカー公開仕様の欄には、USB-Cがオーディオ対応と書かれています。

05スペック用語のかんたん解説

比較表に出てくる用語を、一般的な意味で簡単に説明します。数値や対応の有無は各商品ページ・Amazon商品ページでご確認ください。

▸DP-Out

USB-Cの端子から映像を出力して、外部ディスプレイに表示する機能です。使うには、ディスプレイ側とケーブル側の対応も必要です。Idea Tab Pro 12.7インチのページにDP-Out対応と記載があり、Idea Tab 11インチのページには記載がありません。

▸リフレッシュレート（Hz）

画面が1秒間に書き換わる回数を示す単位です。数値が大きいほど、スクロールや動きの表示がなめらかになるとされます。Idea Tab Pro 12.7インチのページに144Hz、Idea Tab 11インチのページに90Hzと記載されています。

▸nits（ニト）

画面の明るさを示す単位です。一般に、数値が大きいほど明るい場所でも見やすくなるとされますが、実際の見え方は環境や表面の仕上げでも変わります。Idea Tab Pro 12.7インチは400nits（グレア）、Idea Tab 11インチは500nits（防指紋）と記載されています。

▸メモリーとストレージの規格

LPDDR5XやLPDDR4Xはメモリー、UFS 4.0やUFS 2.2はストレージの規格名です。一般に、世代の新しい規格のほうが読み書きが速いとされます。Idea Tab Pro 12.7インチは8GB LPDDR5X／256GB UFS 4.0、Idea Tab 11インチは4GB LPDDR4X／128GB UFS 2.2と記載されています。

▸IP52

IPコードは、防塵と防水の等級を示す国際規格の表記です。最初の数字が防塵、次の数字が防水の等級を表します。どちらのページにも、メーカー公開仕様の欄に「IP52」と記載されています。水没や水洗いを想定した等級ではありません。

06購入前のチェックリスト

購入前に見ておくと安心な項目です。各商品ページの記載にもとづくため、最終的にはAmazon商品ページの最新情報もご確認ください。

  • 本体の大きさと重さ：Idea Tab Pro 12.7インチは約620g、Idea Tab 11インチは480g±10g。持ち運ぶ頻度で考える。
  • ペン：Idea Tab Pro 12.7インチはTab Pen Plus付属、Idea Tab 11インチはペン別売。手書きを使うなら、ペンの有無を確認する。
  • 充電器：メーカー公開仕様の欄に、Idea Tab Pro 12.7インチは最大45W、Idea Tab 11インチは20Wの電源アダプターと記載。Idea Tab 11インチは付属品なしとの記載もあるため、同梱物はAmazon商品ページで確認する。
  • microSDカード：どちらも別売り。対応容量はIdea Tab Pro 12.7インチが最大1TB、Idea Tab 11インチが最大2TB。
  • メモリー：Idea Tab 11インチのページには、4GBで重い作業には向かない可能性があると記載されている。使うアプリの要件を確認する。
  • OSの更新：メーカー公開仕様の欄の表記は、Idea Tab Pro 12.7インチがAndroid 14以降、Idea Tab 11インチがAndroid 15以降。更新状況は購入後に確認する。
  • Wi-Fi：Idea Tab Pro 12.7インチはWi-Fi 6E、Idea Tab 11インチはWi-Fi 5と記載。自宅のルーターの対応も見ておく。

07よくある質問

Q.Idea Tab ProとIdea Tabの主な違いは何ですか？

各商品ページの記載では、画面サイズが12.7インチと11インチ、メモリーが8GBと4GB、ストレージが256GBと128GBで異なります。CPUはDimensity 8300とDimensity 6300、USB端子はUSB 3.2 Type-C（DP-Out対応）とUSB 2.0 Type-Cと記載されています。

Q.microSDカードは使えますか？

どちらのページにもmicroSDカードリーダーの記載があり、対応容量はIdea Tab Proが最大1TB、Idea Tabが最大2TBです。microSDカードは別売りと記載されています。

Q.外部ディスプレイにつなげますか？

Idea Tab Proのページには、USB 3.2 Type-C（DP-Out対応）と記載されています。Idea TabのページはUSB 2.0 Type-Cの記載で、DP-Outについての記載はありません。

Q.どちらを選べばいいですか？

12.7インチの大きな画面、8GBメモリー、256GBストレージ、DP-Out対応の端子を重視するなら、Idea Tab Proのページが候補になります。11インチの画面、Android 15、2TBまで対応のmicroSDカードリーダーを重視するなら、Idea Tabのページを確認するとよいでしょう。選び方全般はタブレットの選び方ガイドもご覧ください。

Q.ペンは付属していますか？

Idea Tab Pro 12.7インチのメーカー公開仕様の欄に、Lenovo Tab Pen Plus（ペン）付属と記載されています。Idea Tab 11インチの欄には、付属品なしでペンは別売と記載されています。購入前に、Amazon商品ページで同梱物をご確認ください。

Q.本体の重さを教えてください。

メーカー公開仕様の欄に、Idea Tab Pro 12.7インチが約620g、Idea Tab 11インチが480g±10gと記載されています。寸法はIdea Tab Pro 12.7インチが291.8×189.1×6.9mm（カメラ部分を除く）、Idea Tab 11インチが254.59×166.15×6.99mmです。

Q.画面の明るさと書き換え速度に違いはありますか？

Idea Tab Pro 12.7インチは400nits・144Hz・グレア、Idea Tab 11インチは500nits・90Hz・防指紋と、メーカー公開仕様の欄に記載されています。どちらも10点マルチタッチです。Idea Tab 11インチは72% NTSCの記載もあります。

Q.バッテリーの持ち時間を教えてください。

どちらのページにも、駆動時間の記載がありません。メーカー公開仕様の欄には、Idea Tab Pro 12.7インチが10200mAh（標準値）、Idea Tab 11インチが7040mAh（標準値）と、容量のみが記載されています。

Q.防塵防水の性能はありますか？

どちらのページにも、メーカー公開仕様の欄に「金属筐体／IP52」と記載されています。水没は想定されていないため、使用時は水濡れにご注意ください。

Q.無線の規格に違いはありますか？

メーカー公開仕様の欄に、Idea Tab Pro 12.7インチがWi-Fi 6E（802.11ax 2x2）とBluetooth 5.3、Idea Tab 11インチがWi-Fi 5（802.11ac 1x1）とBluetooth 5.2と記載されています。
