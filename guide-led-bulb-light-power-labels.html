01まず知っておきたい商品の種類

光や電源にかかわる小物は、役割ごとに見る項目が異なります。以下は一般的な整理で、実際の特徴は商品ごとに異なります。

種類しくみ一般的な特徴気をつけたい点
LED電球（E17・E26など）器具のソケット（口金）に取り付ける交換用の電球取り付け先の口金に合うものを選ぶ。明るさは「形相当」やlmで表される口金の種類と、器具の対応が合わないと使えない。調光器具は対応を確認する
電池式のセンサーライト人などの動きを感知して点灯する。電源は乾電池配線工事なしで、玄関先などに取り付けて使われる取り付け金具の対応寸法と、電池の本数・寿命の記載を確認する
ソーラー式のガーデンライト太陽光で内蔵の電池を充電し、暗くなると点灯する配線不要で、庭や通路に置く・挿して使われる点灯時間は設置場所や天候で変わる。防水の等級は記載の条件を確認する
ビデオ通話・配信用ライト（USB給電）モニターなどに取り付け、顔を照らす明るさと色温度を調整できる機種がある給電方法（USB・アダプタ）で、明るさの上限が変わる商品がある
ACアダプター（DC出力）コンセントの交流を、機器が使う直流に変換する電圧・電流・極性・プラグ径が機器に合う必要がある機器側の表示と一致しないと使えない。一致しない使い方は避ける
USB充電器（多ポート）USB-C・USB-Aのポートを複数備え、スマートフォンなどを充電する合計出力やポートごとの出力の記載を見る同時に使うと各ポートの出力が変わる場合がある。取扱説明書で確認する

どれが優れているかではなく、取り付け先・使う場所・電源の取り方に合わせて確認するのが一般的です。

02スペック表で見る7つのポイント

1. 口金（E17・E26）と形状

口金は、電球をソケットに取り付ける部分の規格です。数字は直径（mm）に対応するのが一般的で、ソケットと同じ口金でないと取り付けられません。仕様表では、パナソニック ミニクリプトン型 パルック LED電球が「E17(ミニクリプトン型)」で形状は「小形電球タイプ」、TOSHIBA(東芝) LED電球 A形が「E26」で形状は「A形(一般電球形)・広配光」と記載されています。

2. 明るさ（「40W形相当」と全光束lm）

「40W形相当」は、従来の白熱電球の明るさに近い、という目安の呼び方です。実際の明るさは、全光束（lm＝ルーメン）で確認します。仕様表では、パナソニック ミニクリプトン型が「40W形相当」で全光束440lm、東芝 A形が「40W形相当」で全光束485lmと記載されています。同じ「40W形相当」でも、lmの値は商品ごとに異なります。

3. 光色・色温度（K）

光色は、光の色合いです。一般に、電球色は温かみのある黄みがかった光、昼光色は青みがかった光とされます。数字（K＝ケルビン）が小さいほど暖色寄りになるのが一般的です。仕様表では、パナソニック ミニクリプトン型が「電球色相当(2700K)」、東芝 A形が「電球色(2700K)」、Elgato Key Light Neoが色温度範囲「2900〜7000K」、GIGALUMI ソーラーガーデンライトが商品名で「電球色」と記載されています。

4. 演色性（Ra・CRI）と配光

演色性は、物の色の見え方を示す指標です。数字が大きいほど、自然光に近い見え方を目指した設計とされます。仕様表では、東芝 A形が演色性「Ra 80」、配光角「180°」、Elgato Key Light Neoが演色性「CRI 94%超」と記載されています。顔を映す用途のビデオ通話では色の見え方が気になりやすく、数値の記載があると確認しやすくなります。

5. 電源方式（電池・内蔵電池・USB・AC）

電源の取り方で、置ける場所や手間が変わります。仕様表では、ムサシ LEDセンサーライト LED-270が「単1形アルカリ乾電池×3本（別売）」、GIGALUMI ソーラーガーデンライトが「内蔵Ni-MHバッテリー」でソーラー式、Elgato Key Light Neoが「USB」接続でUSB-A給電・USB-C給電・3A電源アダプタの使い分けに関する記載、Logitech Litra Glowが「USB」接続・「コード付き電気」と記載されています。電池は「別売」かどうかも見落としやすい項目です。

6. センサーの範囲と点灯設定（センサーライト）

センサーライトでは、検知する範囲と点灯の設定を確認します。仕様表では、ムサシ LED-270が「焦電型赤外線センサー・探知範囲180°・最遠8m（取付高さ2m）」、点灯設定が「点灯時間10秒・100%／50%／フラッシュ・昼／夜の切替」、取付が「クランプ（厚み15〜100mm・パイプ径30〜85mm）」と記載されています。取付高さなど、数字には条件がついています。

7. 電源アダプターの出力・極性・プラグ径

DC出力のACアダプターは、電圧（V）・電流（A）・極性・プラグの外径と内径が機器に合っている必要があります。仕様表では、SUCCUL ACアダプターが「DC12V 1A（最大12W）」「センタープラス」「外径5.5mm・内径2.1mm」「スイッチング式」「PSE取得品」と記載されています（Amazon掲載情報（メーカー公式ページには記載がありません））。極性の記号と数値は、機器側の表示と一致しているかを必ず確認します。

07使う場面別の選び方

切れた電球を、同じものに替えたい

まず、ソケットの口金（E17・E26など）と、元の電球の形状を確認します。パナソニック ミニクリプトン型（E17）は小形電球タイプ、東芝 A形（E26）は一般電球形と記載されています。器具に表示された「使用できる電球の最大ワット数・口金」を、取扱説明書で確認してください。

玄関先や駐輪場に、配線なしで防犯用の灯りを付けたい

電池式のセンサーライトが候補です。ムサシ LEDセンサーライト LED-270は単1形アルカリ乾電池×3本（別売）で、取付はクランプ式（厚み15〜100mm・パイプ径30〜85mm）と記載されています。取り付ける場所のパイプや板の寸法を、先に測っておくと確認しやすくなります。

庭やベランダの通路に、配線なしで灯りを置きたい

ソーラー式のライトが候補です。GIGALUMI ソーラーガーデンライト 4個セットは杭式で、点灯時間の目安は約8〜12時間（自動点灯・明け方自動消灯）と記載されています。日当たりの条件で、点灯の長さは変わる目安です。

ビデオ通話で、顔を明るく映したい

Elgato Key Light Neoは色温度範囲2900〜7000K・CRI 94%超、Logitech Litra Glowは明るさ・色温度の調整とデスクトップアプリ制御と記載されています。給電方法で明るさの上限が変わる商品もあるため、USB-A・USB-C・電源アダプタのどれで使うかも確認します。

海外旅行・出張で、コンセントの形を合わせたい

Anker Nano トラベルアダプタ（5-in-1, 20W）は、A・C・Gタイプのプラグに対応と記載されています。ただし、変圧機能はなく、100〜240V対応機器で使用する旨も記載されています。渡航先のプラグの形と、機器の対応電圧を、事前に確認してください。

机まわりで、複数の機器を1つの充電器でまとめたい

CIO NovaPort SLIM QUAD for DESKは、USB-C×3・USB-A×1で最大67W、ケーブル長1.5m（本体一体型）と記載されています。同時に使うときの出力の配分は、取扱説明書で確認します。ケーブルや充電器の規格はUSB充電器・充電ケーブルの選び方ガイドやUSB-Cケーブルの選び方ガイドも参考になります。

ACアダプターを買い替えたい

SUCCUL ACアダプター 12V 1Aは、センタープラス・外径5.5mm／内径2.1mmと記載されています（Amazon掲載情報（メーカー公式ページには記載がありません））。機器本体やもとのアダプターに書かれた電圧・電流・極性・プラグ径をすべて確認し、一致するかを見ます。一部でも異なる場合は、使わないのが基本です。

色温度（K）光色を数字で表したもの。小さいほど暖色寄り、大きいほど青白い光電球色は2700Kと記載される商品が多い。調整式は範囲（2900〜7000Kなど）で示される
演色性（Ra・CRI）物の色の見え方を示す指標数字が大きいほど、自然光に近い見え方を目指した設計とされる
配光角光が広がる角度広配光の電球は、周囲に光が広がる設計。センサーでは探知範囲の角度（180°など）とは別の項目
ソーラー（太陽光）充電式太陽光で内蔵電池を充電し、暗くなると点灯する方式点灯時間は、設置場所の日当たりや天候で変わる目安
極性（センタープラス）DCプラグの中心側が、プラス（＋）の接続であること機器側の極性表示と一致している必要がある。記号は取扱説明書で確認
スイッチング式ACアダプターの電力変換方式の一つ出力の条件や使える機器は、取扱説明書で確認する
PSE電気用品安全法にもとづく表示。電気製品の販売に関わる表示表示の有無の記載はあくまで一つの情報。使う前に本体表示と取扱説明書を確認する

10購入前のチェックリスト

次の順で確認すると、迷いにくくなります。

  • 電球は、ソケットの口金（E17・E26など）と、元の電球の形状を確認する
  • 明るさは、形相当だけでなく、全光束（lm）と配光もあわせて確認する
  • 光色（電球色・昼光色）や色温度（K）が、使う場所に合っているかを確認する
  • センサーライトは、電池の本数・別売かどうか・取付寸法・検知範囲を確認する
  • ソーラーライトは、設置場所の日当たりと、点灯時間が目安であることを確認する
  • ACアダプターは、機器側の電圧・電流・極性・プラグ径をすべて照らし合わせる
  • 海外で使う機器は、対応電圧（100〜240Vなど）とプラグの形を確認する
  • 調光器具・密閉型器具などで使う場合は、器具の取扱説明書で対応を確認する

電気に関する数値は、商品本体のラベルと取扱説明書が最終的な基準になります。不明な点は、メーカーに問い合わせるのが確実です。

11失敗しやすいポイントと、安全に使うための基本

✅ こうすると失敗しにくい

  • 取り付け先の口金・器具の表示を、先に確認してから選ぶ
  • 電圧・電流・極性・プラグ径が機器と一致するアダプターを使う
  • 電池式のライトは、電池が別売かどうかを確認する
  • 屋外で使う商品は、設置場所の条件を取扱説明書で確認する
  • USB機器は、対応する給電方法（USB-A・USB-C・アダプタ）を確認する

⚠️ 避けたいこと

  • 口金や器具の対応を確認せずに電球を取り付ける
  • 機器と電圧・極性が一致しないACアダプターを使う
  • 濡れた手でコンセントやアダプターに触れる
  • タコ足配線などで、1つのコンセントに負荷をかけすぎる
  • 器具の最大ワット数・対応を確認せずに、密閉器具などで電球を使う

13よくある質問

Q.LED電球の口金（E17・E26）は、どう選べばよいですか？

ソケットと同じ口金のものを選びます。数字はおおよその直径（mm）に対応するのが一般的です。当サイトの仕様表では、パナソニック ミニクリプトン型 パルック LED電球が「E17(ミニクリプトン型)」、TOSHIBA(東芝) LED電球が「E26」と記載されています。照明器具やもとの電球の表示で確認してください。

Q.「40W形相当」とは何ですか？

従来の白熱電球40Wに近い明るさ、という目安の呼び方です。実際の明るさは全光束（lm）で確認します。当サイトの仕様表では、パナソニック ミニクリプトン型が40W形相当・440lm、東芝 A形が40W形相当・485lmと記載されています。同じ形相当でも、lmは商品ごとに異なります。

Q.電球色2700Kとは、どんな光ですか？

一般に、温かみのある黄みがかった光とされます。数字（K）が小さいほど暖色寄りになるのが一般的です。当サイトの仕様表では、パナソニック ミニクリプトン型が「電球色相当(2700K)」、東芝 A形が「電球色(2700K)」と記載されています。使う部屋の雰囲気に合わせて選びます。

Q.演色性（Ra・CRI）は、何を表していますか？

物の色の見え方を示す指標です。数字が大きいほど、自然光に近い見え方を目指した設計とされます。当サイトの仕様表では、東芝 A形が演色性Ra 80、Elgato Key Light NeoがCRI 94%超と記載されています。測り方の表記が異なる場合があるため、数字だけで単純には比べられません。

Q.電池式のセンサーライトは、電池がどのくらいもちますか？

条件つきの目安として記載されています。当サイトの仕様表では、ムサシ LEDセンサーライト LED-270が、100%点灯時で約4.5か月、50%点灯時で約8か月（1日10回点灯・使用環境で異なる）と記載されています。電池は単1形アルカリ乾電池×3本（別売）です。使う場所や回数で変わります。

Q.センサーライトの検知範囲は、どう読めばよいですか？

角度と距離、取付高さで示されます。当サイトの仕様表では、ムサシ LED-270が「焦電型赤外線センサー・探知範囲180°・最遠8m（取付高さ2m）」と記載されています。距離の数字は、取付高さなどの条件つきの値です。実際の検知は、設置環境によって変わります。

Q.ソーラーライトは、夜にどのくらい点灯しますか？

目安の時間が記載されますが、設置場所や天候で変わります。当サイトの仕様表では、GIGALUMI ソーラーガーデンライトが、点灯時間の目安を約8〜12時間（自動点灯・明け方自動消灯、光センサー式）、電源を内蔵Ni-MHバッテリーと記載しています。日当たりの悪い場所では、点灯時間が短くなる場合があります。

Q.ビデオ通話用のライトは、何を見て選べばよいですか？

明るさ、色温度の範囲、演色性、取り付け方法を確認します。当サイトの仕様表では、Elgato Key Light Neoが、USB-A給電4.5W時400lm・USB-C給電7.5W時700lm・3A電源アダプタ使用時最大1000lm、色温度2900〜7000K、CRI 94%超と記載されています（Amazon掲載情報で、メーカー公式ページには記載がありません）。給電方法で明るさが変わる点が特徴です。

Q.ACアダプターを選ぶときは、何を確認しますか？

電圧・電流・極性・プラグ径を、機器の表示と照らし合わせます。当サイトの仕様表では、SUCCUL ACアダプターが、DC12V 1A（最大12W）・センタープラス・外径5.5mm／内径2.1mm・スイッチング式・PSE取得品と記載されています（Amazon掲載情報で、メーカー公式ページには記載がありません）。一致しないものは使わないのが基本です。

Q.トラベルアダプタは、海外のどこでも使えますか？

対応するプラグの種類と、変圧機能の有無を確認します。当サイトの仕様表では、Anker Nano トラベルアダプタ（5-in-1, 20W）が、A・C・Gタイプに対応し、200以上の国と地域で使用可能とAmazonに掲載されています。変圧機能はなく、100〜240V対応機器で使用する旨が記載されています。渡航先のプラグと、機器の対応電圧を確認してください。

Q.多ポートの充電器は、全ポートで最大出力が出ますか？

同時に使うと、各ポートの出力が変わる場合があります。当サイトの仕様表では、CIO NovaPort SLIM QUAD for DESKが、最大67W（USB-C×3、USB-A×1）、ケーブル長1.5m（本体一体型）と記載されています。ポートごとの出力の配分は仕様欄に記載がないため、取扱説明書で確認してください。 なお、NovaPort SLIM QUAD for DESKの数値は、Amazon掲載情報（メーカー公式ページには記載がありません）です。
