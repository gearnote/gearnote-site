02充電式の掃除機は、掃除機の表示ルールの対象外

家庭用品品質表示法の電気機械器具品質表示規程では、電気掃除機の対象は「真空式で、電源として電池を使用しないもの」で、電源に電池（充電池を含む）を使うものは対象外です（消費者庁 電気掃除機の表示）。

対象の掃除機には、JIS C 9108に規定する吸込仕事率（W）と、質量（本体と、ホース・延長管・床用吸込口・コードの合計）を表示する決まりがあります（同）。コードレス掃除機は、この決まりの対象ではないため、質量に何を含めるか、運転時間をどの条件で書くかは、メーカーごとに違います。

06読み間違えやすいこと

  • 「最大60分」はいちばん弱い条件の数字のことが多い：エコモードや、モーターの付いていないツールを使ったときの数字かどうかを確かめます。
  • 「バッテリー2個使用時」の数字：付属のバッテリーを交換しながら使ったときの合計で、1個あたりの時間ではありません。
  • スティック時の質量に何が入っているか：ヘッドやパイプを含むかどうかで、同じ機種でも数字が変わります。
  • コード式とコードレスを同じ物差しで見ない：コード式は時間の制限がなく、消費電力（W）が書かれます。

07商品ページで確認すること

  1. 質量が、何を付けた状態の数字か（本体のみ・パイプとヘッドを含む・ハンディ時）。
  2. 運転時間が、どのモード・どのヘッドの数字か。温度などの測定条件の注記があるか。
  3. バッテリーの数（交換用が付属するか）と、充電時間。
  4. スティック型なら、ハンディとして使えるか。布団クリーナーなら、コード式かコードレスか。
  5. 集じん容量と、ごみの捨て方（自動ゴミ収集ドックの有無）。

08出典と、確認できなかったこと

このページの公的な資料・規格団体・メーカーの事実は、2026年11月15日時点で、各ページを実際に開いて確認したものです（リンク先は、各項目に付けています）。GEARNOTEの数字は、GEARNOTEに掲載している商品のメーカー公開仕様の記載を数えたもので、市場全体の割合を示すものではありません。

  • 家電公取協の公正競争規約に、充電式掃除機の使用時間の表示条件があるかは、規約の原文を確認できなかったため、書いていません。
  • JIS C 9108（電気掃除機）の本文は有料のため、GEARNOTE運営は未閲覧です。
  • 吸込仕事率やPa（パスカル）など、吸引の強さの数字は、条件がそろわないため、このページでは比べていません。

10よくある質問

Q.コードレス掃除機とハンディクリーナーは、何が違いますか？

スティック型のコードレス掃除機は、延長管と床用ヘッドを付けて床を掃除する形で、延長管を外してハンディとして使える機種も多くあります。GEARNOTEの掲載品では、スティック型のうち、ハンディ時の質量や寸法も書いている機種があります。

Q.コードレス掃除機の質量は、法律で測り方が決まっていますか？

消費者庁の解説では、家庭用品品質表示法の電気掃除機の表示ルールは、電源に電池（充電池を含む）を使うものを対象外としています。そのため、コードレス掃除機の質量に何を含めるかは、メーカーの書き方で確認します。

Q.運転時間「最大60分」は、ふつうに使って60分ですか？

そうとは限りません。GEARNOTEの掲載品でも、60分はエコモードでモーター駆動のないツールを使ったときの数字、と書かれている例があります。モードとヘッドの条件を確認してください。

Q.布団クリーナーの数字は、何を見ればいいですか？

コード式なら消費電力とコードの長さ、コードレスならモード別の連続使用時間と充電時間です。GEARNOTEの掲載品にも、両方の方式があります。
