  • ダイヤルや表示で、設定を手元で操作したいなら：G512 X 75のページにデュアルダイヤル、G316 X 98のページにインタラクティブ ドットマトリックス ディスプレイの記載があります。それぞれで何を操作できるかの詳しい説明は、どちらのページにもありません。
  • 夜の部屋で、光り方を整えたいなら：G512 X 75のページに「LIGHTSYNC RGB、本体下部のLIGHT BAR」、G316 X 98のページに「LIGHTSYNC RGB（Logicool G HUBでカスタマイズ）」と記載されています。G512 X 75は、本体下部に光る帯があると読み取れます。

05スペック用語のかんたん解説

比較表に出てくる用語を、一般的な意味で簡単に説明します。数値や対応の有無は各商品ページ・Amazon商品ページでご確認ください。

▸リニアスイッチ

押し込む途中にクリック感や引っかかりがなく、まっすぐ沈む感触のスイッチです。一般に、素早く連続して押すゲームで使われることが多いとされます。両方のページに、リニアの記載があります。

▸ホットスワップ

はんだ付けをせずに、スイッチを差し替えられる構造です。打鍵感の異なるスイッチに交換して、好みに合わせやすいとされます。G316 X 98は「ホットスワップ対応」、G512 X 75は「メカニカルのホットスワップ」と記載されています。

▸磁気式アナログスイッチ・ラピッドトリガー

磁気式アナログスイッチは、磁石の位置の変化でキーの押し込み量を連続的に検出するスイッチです。ラピッドトリガーは、一般にキーを少し戻すと入力が解除され、押し直すとすぐ入力される機能とされます。G512 X 75のページに、ラピッドトリガーは磁気式アナログスイッチ側のみ対応と書かれています。

▸レポートレート（8,000Hz）

キーボードが入力の情報をパソコンへ送る頻度を示す値です。8,000Hzは、1秒に8,000回送る数値です。数値が大きいほど送信の間隔が短くなりますが、実際の体感はパソコンや環境にも左右されます。G512 X 75は「8,000Hz」、G316 X 98は「最大8,000Hz」と記載されています。

▸ガスケットマウント

基板やプレートを、ゴムなどの緩衝材で支える構造です。一般に、打鍵感や打鍵音に影響するとされます。両方のページに記載があり、G316 X 98のページには制振層を備えると書かれています。

07よくある質問

Q.G512 X 75とG316 X 98の主な違いは何ですか？

各商品ページの記載では、スイッチがG512 X 75はデュアルスワップ機能（メカニカルと磁気式アナログ）、G316 X 98はホットスワップ対応のメカニカルリニアです。G512 X 75のページにはラピッドトリガーなどの機能とテンキーレスの記載、G316 X 98のページにはドットマトリックス ディスプレイと寸法の記載があります。有線接続、最大8,000Hzのレポートレート、ガスケットマウント構造は両ページで共通です。

Q.ワイヤレスで使えますか？

どちらのページでも、接続は有線と記載されています。G316 X 98のページには、USB-A to USB-Cケーブルが付属すると記載されています。

Q.ラピッドトリガーに対応しているのはどちらですか？

G512 X 75のページに、ラピッドトリガーとアクチュエーションポイント調整への対応が記載されています。ただし、ラピッドトリガーは磁気式アナログスイッチ側のみ対応と、ページの注意点に書かれています。G316 X 98のページには、ラピッドトリガーの記載がありません。

Q.Macで使えますか？

G512 X 75のページの対応OS欄は「Windows」、G316 X 98のページの必要OS欄は「Windows 10以降」と記載されています。どちらのページにも、Macへの対応の記載はありません。

Q.どちらを選べばいいですか？

磁気式アナログスイッチとの組み合わせ、ラピッドトリガー、テンキーレス配列の記載を確認したい場合はG512 X 75、ドットマトリックス ディスプレイと寸法（長さ38.4×幅14×高さ4cm）の記載を確認したい場合はG316 X 98のページが候補になります。どちらも高度な機能にはロジクール G HUBが必要と案内されています。キーボード選び全般はキーボードの選び方ガイドもご覧ください。

Q.キー配列は日本語配列ですか？

G512 X 75のページに「日本語配列、テンキーレス」、G316 X 98のページに「日本語配列」と記載されています。G316 X 98のページには、テンキーの有無やキー数の記載がありません。

Q.スイッチは自分で交換できますか？

G316 X 98のページに「ホットスワップ対応」と記載されています。G512 X 75のページには、メカニカルのホットスワップに加え、特定の41個のキーで磁気式アナログスイッチも組み合わせ可能と書かれています。交換できるスイッチの種類は、メーカーの案内でご確認ください。

Q.レポートレートに違いはありますか？

G512 X 75のページに「8,000Hz」、G316 X 98のページに「最大8,000Hzの有線レポートレート」と記載されています。表記は少し異なりますが、数値は同じです。実際の動作は、接続するパソコンの環境にも左右されます。

Q.光り方（ライティング）はどう違いますか？

どちらのページにも、LIGHTSYNC RGBが記載されています。G512 X 75のページには、本体下部のLIGHT BARの記載もあります。G316 X 98のページには、Logicool G HUBでカスタマイズできると書かれています。

Q.USBケーブルは付属していますか？

G316 X 98のページに「USB-A to USB-Cケーブル付属」と記載されています。G512 X 75のページには、ケーブルの付属についての記載がありません。Amazon商品ページの同梱物の欄でご確認ください。

Q.キーボード選びの基本を知りたいときは？

接続方式や配列、スイッチの種類の見方は、キーボードの選び方ガイドでご覧いただけます。
