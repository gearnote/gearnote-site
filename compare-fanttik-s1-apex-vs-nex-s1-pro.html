05スペック用語のかんたん解説

比較表に出てくる用語を、一般的な意味で簡単に説明します。数値や対応の有無は各商品ページ・Amazon商品ページでご確認ください。

▸トルク（N·m）

ねじを回す力の大きさを示す単位です。数値が大きいほど、硬い素材や太いねじに向くとされます。小さすぎると締めきれず、大きすぎるとねじや素材を傷めることがあります。Fanttik S1 APEXは0.5-7N·mの8段階、Fanttik NEX S1 Proは1.5/3/4.2N.mの3段階で、手動トルク最大6N.mとも記載されています。

▸RPM（回転速度）

1分間あたりの回転数を示す単位です。数値が大きいほど速く回ります。Fanttik S1 APEXのページに、低速100RPM、高速250RPMの2段階が記載されています。Fanttik NEX S1 Proのページには、回転速度の記載がありません。

▸mAh（バッテリー容量）

電池が出せる電気の量を示す単位です。数値が大きいほど長く使える目安とされますが、トルクや作業内容によって持ち時間は変わります。Fanttik S1 APEXは2500mAh、Fanttik NEX S1 Proは2000mAhと記載されています。連続使用時間は、どちらのページにも記載がありません。

▸角度調整（折りたたみハンドル）

本体の持ち手を折りたたみ、作業する向きに合わせて角度を変える仕組みです。Fanttik S1 APEXのページに、0°／24°／48°／72°の4段階折りたたみと記載されています。Fanttik NEX S1 Proのページには、角度調整の記載がありません。

▸S2鋼材ビット

S2は、ビットなどの工具に使われる鋼材の種類の名称とされます。Fanttik NEX S1 Proのページに、S2鋼材ビット16本の付属が記載されています。Fanttik S1 APEXのページは、日常用ビット20本と記載され、ビットの鋼材の記載はありません。

07よくある質問

Q.Fanttik S1 APEXとNEX S1 Proの主な違いは何ですか？

各商品ページの記載では、トルクの段階がS1 APEXは8段階（0.5-7N·m、液晶表示）、NEX S1 Proは3段階です。バッテリーはS1 APEXが2500mAh、NEX S1 Proが2000mAhで、重量はS1 APEXが約1.27kg、NEX S1 Proが845gと記載されています。

Q.充電方式に違いはありますか？

S1 APEXはUSB-C充電、NEX S1 ProはType-C充電と記載されています。どちらもUSBのType-Cで充電する方式です。

Q.角度調整ができるのはどちらですか？

S1 APEXのページに、0°／24°／48°／72°の4段階折りたたみと記載されています。NEX S1 Proのページには、角度調整についての記載がありません。

Q.付属品の違いは何ですか？

S1 APEXは日常用ビット20本とLED環状ライト、NEX S1 ProはS2鋼材ビット16本とマグネット収納ケース、USB Type-Cケーブルと記載されています。ビットの対応範囲は、購入前に各商品ページで確認してください。

Q.どちらを選べばいいですか？

角度調整や液晶表示、細かいトルク設定の記載を重視するならS1 APEX、重量845gという軽さと、収納ケースが付属する構成を重視するならNEX S1 Proのページが参考になります。選び方の基準は電動ドライバーの選び方ガイドもご覧ください。

Q.回転速度を切り替えられるのはどちらですか？

Fanttik S1 APEXのページに、低速100RPMと高速250RPMの2段階が記載されています。Fanttik NEX S1 Proのページには、回転速度の記載がありません。

Q.ライトは付いていますか？

Fanttik S1 APEXの仕様表に、付属品として「LED環状ライト」が記載されています。Fanttik NEX S1 Proのページには、ライトの記載がありません。

Q.ビットは何本付属しますか？

Fanttik S1 APEXは日常用ビット20本、Fanttik NEX S1 ProはS2鋼材ビット16本とマグネット収納ケースが付属と記載されています。ビットの種類や対応するねじの範囲は、各商品ページでご確認ください。

Q.バッテリーの持ち時間は分かりますか？

Fanttik S1 APEXは2500mAh、Fanttik NEX S1 Proは2000mAhと記載されています。どちらのページにも、連続使用時間や締め付けられる本数の記載はありません。持ち時間は作業内容で変わるため、容量は目安として見ます。

Q.サイズはどのくらい違いますか？

Fanttik S1 APEXは28×5×5cm、Fanttik NEX S1 Proは長さ22×幅6.7×高さ6.7cmと記載されています。Fanttik S1 APEXは角度調整をした状態の寸法かどうかの記載がありません。重量はFanttik S1 APEXが約1.27kg、Fanttik NEX S1 Proが845gです。

Q.電動ドライバーの選び方を基本から知りたいときは？

トルク・回転数・バッテリーの見方は電動ドライバーの選び方ガイド、ほかの商品は生活家電のカテゴリページでご覧いただけます。
