Levoit空気清浄機 Core P350とVital 100Sの違いを比較

02違いのまとめ

  • 適用畳数は、Core P350が「20畳まで」、Vital 100Sが「21畳」と記載されています。メーカー公開情報の欄では、Core P350が20畳（33㎡）で清浄時間は8畳/13分（CADR値260m³/h）、Vital 100Sが21畳（35㎡）で清浄時間は8畳/12分です。
  • 形状と吸気は、Core P350が「円筒型で360°全方位から吸気」、Vital 100Sのページには「四方向からの吸気」と記載されています。本体寸法は、Core P350が幅22×奥行22×高さ36cm、Vital 100Sが幅32.1×奥行16.0×高さ40.6cm（メーカー公開情報の欄）です。
  • 質量は、Core P350がメーカー公開情報の欄に3.5kg、Vital 100Sが商品ページの仕様表に4.49kgと記載されています。
  • フィルターは、Core P350がARC式脱臭フィルターと不織布プレフィルターの1層目・静電HEPAフィルターの2層目からなる2層構成（メーカー公式ページ）、Vital 100Sが3層フィルター（静電HEPA）と水洗いできるプレフィルターと記載されています。
  • 機能面は、Core P350のページにタイマーとチャイルドロック（チャイルドロックはAmazon掲載情報（メーカー公式ページには記載がありません）の記載）、Vital 100Sのページにホコリセンサー・光センサー・自動モード・ペットモード・専用アプリVeSync・スマートスピーカー連携が記載されています。どちらも加湿機能は付いていません。
  • 消費電力は、Levoit Core P350のページにおやすみモードで14W（Amazon掲載情報（メーカー公式ページには記載がありません）の記載）とあり、Levoit Vital 100Sのメーカー公開情報の欄に「3.6W（睡眠）〜6.5W〜10.9W〜18.9W〜32W」とあります。モードの呼び方が「おやすみモード」と「睡眠」で異なるため、同じ条件の数値かどうかは両ページから判断できません。
  • フィルターのお手入れは、Levoit Vital 100Sのメーカー公開情報の欄に、プレフィルターは掃除機で手入れでき水洗いも可能で、通常は2〜4週間に1度の清掃を案内とあります。Levoit Core P350は、仕様表に交換の目安として推奨6〜12か月が記載されています。
  • 交換用フィルターは、Levoit Core P350が「Levoit Core 300/300S/P350空気清浄機 交換用フィルター」、Levoit Vital 100Sが「Levoit Vital 100S空気清浄機 交換用フィルター」と、メーカー公開情報の欄に記載されています。どちらも品番の記載は確認できず、純正フィルターのみを使うよう案内されています。

  • 広めのリビングで使う空気清浄機を探している人
  • ホコリセンサーの自動運転とアプリ操作を使いたい人
  • ペットのいる家庭で、ペットモードのある機種を選びたい人

04場面別の選び方

使う場面ごとに、各商品ページの記載で見ておきたい点をまとめました。あくまで掲載情報にもとづく目安です。

  • 寝室で夜に使いたいなら：Levoit Core P350は、おやすみモードと運転音の記載（メーカー仕様で24dB〜46dB、Amazonの説明は「24dB以下」）が参考になります。Levoit Vital 100Sは、お休みモードで運転音23dB、部屋の明るさに応じて表示の明るさを調整する光センサーが記載されています。
  • ペットのいる家庭で使うなら：Levoit Vital 100Sのページにはペットモードの記載があり、アプリに搭載されたモードで強と弱の間で切り替える運転と説明されています。Levoit Core P350のページでは、プレフィルターのある機種として紹介されています。毛やホコリはプレフィルターにたまりやすいため、手入れのしやすさも見ておきます。
  • 置き場所の床面積を抑えたいなら：Levoit Core P350は幅22×奥行22×高さ36cmの円筒形で、Levoit Vital 100Sは幅32.1×奥行16.0×高さ40.6cm（メーカー公開情報の欄）です。質量はLevoit Core P350が3.5kg、Levoit Vital 100Sが4.49kgと記載されています。
  • スマホやスマートスピーカーで操作したいなら：Levoit Vital 100Sのページに、専用アプリVeSyncとスマートスピーカーで、電源・モード・タイマー・スケジュールを操作できる旨の記載があります。Levoit Core P350のページには、アプリ連携の記載がありません。
  • 手入れや部品の入れ替えの頻度を考えて選ぶなら：Levoit Core P350は推奨6〜12か月、フィルター寿命は2年と記載されています。Levoit Vital 100Sはプレフィルターの清掃が2〜4週間に1度の案内で、交換の年数は公式ページ間で記載がそろわないため掲載されていません。どちらも使用環境で変わります。

05スペック用語のかんたん解説

比較表に出てくる用語を、一般的な意味で簡単に説明します。数値や対応の有無は各商品ページ・Amazon商品ページでご確認ください。

▸CADR値と清浄時間

清浄時間は、決まった条件で一定の広さの部屋を清浄にするのにかかる時間の目安です。Levoit Core P350のメーカー公開情報の欄に「8畳/13分（CADR値：260m³/h）」、Levoit Vital 100Sには「8畳/12分」と記載されています。CADRは、清浄な空気を供給する能力を表す指標として使われます。

▸静電HEPAフィルター

細かな粒子をとらえるためのフィルターの種類で、静電気の力を利用するものを静電HEPAと呼ぶのが一般的です。Levoit Core P350とLevoit Vital 100Sの仕様表に記載がありますが、除去率の数値はどちらのページにもありません。

▸ARC式活性炭フィルター

Levoit Core P350のフィルター構成に記載されている名称です。一般に、活性炭はにおいの成分を吸着させるために使われます。「ARC式」の中身についての説明は、このページにはありません。

▸ホコリセンサーと光センサー

Levoit Vital 100Sのページに記載のあるセンサーです。ホコリセンサーは空気の汚れの状態を検知して自動運転に使われ、光センサーは部屋の明るさに応じて表示の明るさを調整すると説明されています。Levoit Core P350のページには、これらのセンサーの記載がありません。

▸運転音（dB）

音の大きさを表す単位で、数値が小さいほど静かな目安です。Levoit Core P350は24dB〜46dB（メーカー仕様）、Levoit Vital 100Sはお休みモードで23dBと記載されています。測定の条件や運転モードがそろっていないと、単純には比べられません。

06購入前のチェックリスト

購入前に見ておくと安心な項目です。各商品ページの記載にもとづくため、最終的にはAmazon商品ページの最新情報もご確認ください。

  • 運転音：Levoit Core P350はメーカー仕様で24dB〜46dB、Amazonの説明では「24dB以下」。最小側の値であることを踏まえて読む。
  • フィルター：Levoit Core P350の仕様表には4種類のフィルターが並び、メーカー公開情報の欄では2層構成（1層目にARC式脱臭フィルターと不織布プレフィルター、2層目に静電HEPAフィルターと専用コート）と説明されている。数え方が異なるため、名称で見比べる。
  • 交換の周期：Levoit Core P350は推奨6〜12か月・寿命2年と記載があるが、メーカーの公式ページ間で記載が一様でない。ランプやサインでの判断も確認する。
  • リセット操作：フィルターの掃除や交換のあと、Levoit Core P350はフィルターチェックボタンの長押し、Levoit Vital 100Sはスリープモードの長押しが必要と記載されている。
  • 操作方法：Levoit Vital 100Sはアプリとスマートスピーカーに対応する。使わない場合でも運転できるかは取扱説明書で確認する。
  • 保証：どちらも2年間のメーカー保証が付帯と、公式ページのFAQに記載されている。保証条件の詳細はメーカーの案内で確認する。

07よくある質問

Q.Core P350とVital 100Sの主な違いは何ですか？

各商品ページの記載では、対応畳数は20畳と21畳でほぼ近く、違いは形状と機能にあります。Core P350は円筒型で360°全方位から吸気し、タイマーとチャイルドロックを備えます。チャイルドロックの記載はAmazon掲載情報（メーカー公式ページには記載がありません）のものです。Vital 100Sはホコリセンサーと光センサー、ペットモード、専用アプリVeSync、スマートスピーカー連携が記載されています。

Q.運転音の記載に違いはありますか？

Core P350のページには、メーカーの仕様として24dB〜46dBと記載されています。Vital 100Sのページには、お休みモードで運転音23dBと記載されています。測定条件が異なる可能性があるため、数値の単純な比較は避け、各ページの注記もご確認ください。

Q.商品ページの数値に注意点はありますか？

数値の出どころに違いがある項目があります。Core P350のページでは、運転音がメーカーの仕様では24dB〜46dB、Amazonの商品説明では「24dB以下」と、表記が分かれています。Vital 100Sの運転音23dBは、お休みモードでの値として記載されています。購入前にAmazon商品ページの最新の記載をご確認ください。

Q.どちらを選べばいいですか？

置く場所の広さと、使いたい機能を基準にすると整理しやすくなります。小型でタイマーとチャイルドロック（チャイルドロックはAmazon掲載情報（メーカー公式ページには記載がありません）の記載）があればよいならCore P350、センサーによる自動運転やペットモード、アプリ操作を使いたいならVital 100Sのページが候補になります。どちらも加湿機能はないため、加湿も求める場合は別の機種を確認してください。基本の見方は空気清浄機の選び方ガイドにまとめています。

Q.消費電力に違いはありますか？

Levoit Core P350のページには、おやすみモードで14Wと、Amazon掲載情報（メーカー公式ページには記載がありません）に記載されています。Levoit Vital 100Sのメーカー公開情報の欄には、3.6W（睡眠）から最大32Wまで運転モードごとの値が示されています。モードの名称がそろっていないため、直接の比較は避け、各ページの記載をご覧ください。

Q.フィルターの手入れ頻度に違いはありますか？

Levoit Vital 100Sのメーカー公開情報の欄では、プレフィルターは掃除機で手入れでき水洗いも可能で、通常は2〜4週間に1度の清掃が案内されています。Levoit Core P350のページでは、プレフィルターなどのホコリを取扱説明書の周期で取り除くと記載されています。

Q.交換用フィルターは両機種で共通ですか？

メーカー公開情報の欄では、Levoit Core P350は「Core 300/300S/P350」向け、Levoit Vital 100Sは「Vital 100S」向けの交換用フィルターが、それぞれ別の名称で案内されています。共通品ではありません。品番は確認できなかったため、購入前に適合をご確認ください。

Q.フィルターを掃除や交換したあと、何かすることはありますか？

Levoit Core P350のメーカー公開情報の欄に、フィルターチェックボタンを3秒以上長押ししてリセットするよう記載されています。Levoit Vital 100Sは、スリープモードを3秒以上長押しするリセット操作が必要と記載されています。

Q.保証期間は何年ですか？

どちらも、2年間のメーカー保証が付帯すると記載されています。Levoit Vital 100Sのページには、保証の条件の詳細は確認できなかったという注記があるため、最新の案内をメーカーの公式ページでご確認ください。

Q.同じLevoitの別機種も比べたいときは？

小型の別モデルはLevoit Core 300のページ、空気清浄機全般の見方は空気清浄機の選び方ガイドでご覧いただけます。
