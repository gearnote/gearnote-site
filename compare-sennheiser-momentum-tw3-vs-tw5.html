02違いのまとめ

  • バッテリーは、True Wireless 3が「イヤホン単体最大7時間／ケース併用最大28時間、Qiワイヤレス充電対応」、True Wireless 5が「ケース併用最大40時間再生、バッテリー交換可能」と記載されています。
  • ノイズ制御は、True Wireless 3が「アダプティブノイズキャンセリング（ハイブリッド型）＋外音取り込みモード」、True Wireless 5が「アダプティブノイズキャンセリング＋外音取り込みモード」と記載されています。
  • True Wireless 5のページには、空間オーディオとして「Dolby Atmos対応、ヘッドトラッキング機能」、通話機能として「骨伝導ボイスセンサー搭載」が記載されています。True Wireless 3のページには、これらの項目がありません。
  • 音質・接続は、True Wireless 3が「Bluetooth、マルチポイント対応、aptX Adaptive」、True Wireless 5が「ハイレゾ対応」と記載されています。ドライバーは、True Wireless 3が商品説明でシングルダイナミックドライバー、True Wireless 5が「自社開発TrueResponseドライバー（広帯域シングルドライバー）」と記載されています。
  • 防滴は、True Wireless 3のページに「IPX4」と記載されています。True Wireless 5のページには、防滴・防水等級の記載がありません。
  • 再生時間は、MOMENTUM True Wireless 3がイヤホン単体で最大7時間、ケース併用で最大28時間、MOMENTUM True Wireless 5がケース併用で最大40時間と記載されています。MOMENTUM True Wireless 5のページには、イヤホン単体の再生時間の記載がなく、商品ページで確認するよう書かれています。
  • MOMENTUM True Wireless 3のページには、aptX Adaptive、IPX4、同梱品（イヤーピース、ケーブル、取扱説明書）、2年間のメーカー保証の記載があります。MOMENTUM True Wireless 5のページには、これらの記載がありません。
  • MOMENTUM True Wireless 5のページには、前モデル（True Wireless 4）との比較として、中域の押し出し感を抑えたチューニングとされる説明があります。カラーは、グラファイトのほかにクリーム、コッパー、デニムの展開があると記載されています。

04場面別の選び方

使う場面ごとに、各商品ページの記載で見ておきたい点をまとめました。あくまで掲載情報にもとづく目安です。

  • PCとスマートフォンを切り替えて使いたいなら：MOMENTUM True Wireless 3のページに、マルチポイント対応と記載されています。MOMENTUM True Wireless 5のページの仕様欄には、マルチポイントの記載がありません。
  • ワイヤレス充電器を日常的に使っているなら：MOMENTUM True Wireless 3のページに、Qiワイヤレス充電対応と記載されています。MOMENTUM True Wireless 5のページの仕様欄には、ワイヤレス充電の記載がありません。
  • 汗や軽い雨が気になる場面で使うなら：MOMENTUM True Wireless 3のページにIPX4の防滴仕様と記載されています。ただし完全防水ではなく、水没や水洗いは避けるよう書かれています。MOMENTUM True Wireless 5のページには、防滴・防水等級の記載がありません。
  • 映画や配信の立体的な音場を楽しみたいなら：MOMENTUM True Wireless 5のページに、Dolby Atmos対応の3Dオーディオとヘッドトラッキング機能が記載されています。Dolby Atmos非対応のコンテンツでは、通常のステレオ再生になると書かれています。
  • 通話や長時間の再生を重視するなら：MOMENTUM True Wireless 5のページに、骨伝導ボイスセンサー搭載と、ケース併用で最大40時間再生、バッテリー交換可能と記載されています。通話の聞こえ方を示す数値は、どちらのページにもありません。

05スペック用語のかんたん解説

比較表に出てくる用語を、一般的な意味で簡単に説明します。数値や対応の有無は各商品ページ・Amazon商品ページでご確認ください。

▸アダプティブノイズキャンセリング

周囲の騒音の状況に合わせて、ノイズキャンセリングの度合いを自動で調整する機能です。MOMENTUM True Wireless 3は「ハイブリッド型」、MOMENTUM True Wireless 5は「外音取り込みモード」とあわせた記載です。効き具合を示す数値は、どちらのページにもありません。

▸マルチポイント接続

2台以上の機器に同時につないでおき、切り替えながら使える機能です。MOMENTUM True Wireless 3のページに「マルチポイント対応」と記載されています。

▸IPX4（防滴）

水の飛沫に対する保護等級の表記です。完全な防水ではありません。MOMENTUM True Wireless 3のページにIPX4と記載されています。

▸Dolby Atmos・ヘッドトラッキング

Dolby Atmosは立体的な音響の規格、ヘッドトラッキングは頭の動きに合わせて音の向きを調整する機能です。どちらもMOMENTUM True Wireless 5のページに記載されています。

▸aptX Adaptiveとハイレゾ対応

aptX AdaptiveはBluetoothで音声を送る方式の名称です。ハイレゾ対応は、通常より情報量の多い音源を扱えるという意味です。MOMENTUM True Wireless 3のページにaptX Adaptive、MOMENTUM True Wireless 5のページにハイレゾ対応と記載されています。

07よくある質問

Q.MOMENTUM True Wireless 3と5の主な違いは何ですか？

各商品ページの記載では、True Wireless 5のページにDolby Atmos対応、ヘッドトラッキング、骨伝導ボイスセンサー、ハイレゾ対応、バッテリー交換可能の記載があります。ケース併用の再生時間は、True Wireless 3が最大28時間、True Wireless 5が最大40時間です。

Q.マルチポイントに対応していますか？

True Wireless 3のページに「マルチポイント対応」と記載されています。True Wireless 5のページの仕様欄には、マルチポイントの記載がありません。

Q.ワイヤレス充電に対応していますか？

True Wireless 3のページに「Qiワイヤレス充電対応」と記載されています。True Wireless 5のページの仕様欄には、ワイヤレス充電の記載がありません。購入前にAmazon商品ページで仕様をご確認ください。

Q.どちらを選べばいいですか？

マルチポイント接続やQiワイヤレス充電、IPX4の防滴を重視するなら、True Wireless 3のページが候補になります。Dolby Atmos対応の3Dオーディオやヘッドトラッキング、骨伝導ボイスセンサー、40時間の再生時間、バッテリー交換を重視するなら、True Wireless 5のページを確認するとよいでしょう。イヤホン選び全般はワイヤレスイヤホンの選び方ガイドもご覧ください。

Q.どちらもノイズキャンセリングと外音取り込みがありますか？

MOMENTUM True Wireless 3のページに「アダプティブノイズキャンセリング（ハイブリッド型）＋外音取り込みモード」、MOMENTUM True Wireless 5のページに「アダプティブノイズキャンセリング＋外音取り込みモード」と記載されています。

Q.ドライバーの違いは分かりますか？

MOMENTUM True Wireless 3のページには、商品説明にシングルダイナミックドライバーと記載されています。MOMENTUM True Wireless 5のページには「自社開発TrueResponseドライバー（広帯域シングルドライバー）」と記載されています。

Q.イヤホン単体の再生時間は分かりますか？

MOMENTUM True Wireless 3のページに、イヤホン単体で最大7時間と記載されています。MOMENTUM True Wireless 5のページには、イヤホン単体の再生時間の記載がありません。

Q.バッテリーを交換できるのはどちらですか？

MOMENTUM True Wireless 5のページに、バッテリー交換可能と記載されています。交換方法や窓口は、メーカーの案内で確認するよう書かれています。MOMENTUM True Wireless 3のページには、バッテリー交換についての記載がありません。

Q.同梱品には何が含まれますか？

MOMENTUM True Wireless 3のページに「イヤーピース、ケーブル、取扱説明書」と記載されています。MOMENTUM True Wireless 5のページには、同梱品の記載がありません。

Q.通話に関する記載はありますか？

MOMENTUM True Wireless 5のページに、骨伝導ボイスセンサー搭載と記載されています。MOMENTUM True Wireless 3のページには、通話機能の項目の記載がありません。

Q.ワイヤレスイヤホン選びの目安を知りたいときは？

接続方式やノイズキャンセリングの見方はワイヤレスイヤホンの選び方ガイドで、一覧はノイズキャンセリングイヤホンの比較でご覧いただけます。
