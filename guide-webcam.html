Webカメラ・マイクの選び方ガイド｜解像度・画角・マイク性能・接続の見方

オンライン会議や配信、授業などで使うWebカメラやマイクは、仕様表の「4K」「画角」「指向性」といった用語の意味が分かりにくい機器です。画質は解像度だけでなく、画角・光補正・レンズやセンサーの性能で変わり、音声はマイクの指向性や設置距離で聞こえ方が変わるとされます。このページでは、当サイトに掲載しているWebカメラ、USBマイク、スピーカーフォンの記載値を例に、仕様表の読み方と、使う場面ごとの考え方を整理しました。対応OSや付属品は機種ごとに異なるため、購入前にAmazon商品ページとメーカー情報でご確認ください。

01まず知っておきたい機器の種類

オンライン会議や配信に使う機器は、役割によっていくつかの種類に分けられます。以下は一般的な説明です。

種類役割一般的な特徴気をつけたい点
Webカメラ映像を撮影してパソコンに送るUSBで接続する機種が多い。マイクを内蔵した機種もある内蔵マイクの性能は、機種により異なる。設置位置や、パソコンの画面との位置関係も確認する
USBマイク（コンデンサーマイクなど）音声を録音し、USB経由でパソコンに送るドライバーの設定なしで使える機種がある。デスクの上に置いて使うタイプが多い指向性（どの方向の音を拾いやすいか）を確認する
XLRマイクオーディオインターフェースなどを介して接続する本格的なマイク音質を細かく調整したい用途で使われるファントム電源などに対応した機器が別途必要になる場合がある
スピーカーフォンスピーカーとマイクが一体になった会議向けの機器少人数の会議で、音声を拾いやすい設計の機種があるエコーキャンセラーなどの機能の有無を確認する

パソコンの内蔵カメラやマイクで足りるか、別に用意したほうがよいかは、使う場面（会議・配信・録音など）によって変わります。

02スペック表で見る6つのポイント

1. 解像度とフレームレート

解像度は映像の細かさ、フレームレート（fps）は1秒あたりの映像の枚数を示します。一般的に、数字が大きいほど細かく、動きがなめらかになる傾向がありますが、会議アプリ側の設定や、回線の状況によって、実際に送られる映像は変わります。当サイトの仕様表では、Insta360 Link 2Cが4K・最大30fps、UGREEN FineCam Liteが4K@30FPS／1080P 60FPS、Anker PowerConf C200が2K、ロジクール C920nがフルHD 1080p／30fps・720p／30fps、ロジクール C922nがフルHD 1080p 30FPS／720p 60FPS、Razer Kiyo Xが1080p 30fps／720p 60fps（207万画素）と記載されています。

2. 画角（視野角）

画角は、映る範囲の広さを示します。数字が大きいほど広く映り、複数人で映るときや、背景を広く見せたいときに向く一方、顔が小さく見える傾向があります。仕様表では、ロジクール C920nが78度、ロジクール C922nが78°（2人までフレームに入れられると記載）、Razer Kiyo Xが82°（広角）、UGREEN FineCam Liteが70°、Anker PowerConf C200が専用Anker Workソフトウェアで最大95°まで調整可能と記載されています。

3. オートフォーカス・光補正・特殊機能

オートフォーカスは、被写体にピントを合わせる機能、光補正は、暗い部屋などで映像を見やすく補正する機能です。仕様表では、ロジクール C920nがオートフォーカス（5エレメントのガラスレンズ）・自動HD光補正（RightLight 2テクノロジー）、ロジクール Brio 100がRightLightによる自動光補正、Insta360 Link 2Cがオートフォーカス・光学式の手ブレ補正・撮影モード（デスクビュー、プライバシー、ホワイトボード、ポートレート）と記載されています。機能の名称はメーカーの呼び名で、実際の効果は使う環境によって変わります。

4. 内蔵マイクと外付けマイクの違い

Webカメラに内蔵されたマイクは、手軽に使える反面、置き場所が画面の近くになり、口元から距離が離れる傾向があります。仕様表では、ロジクール C920nが「ステレオ（レンズの両側に無指向性マイク×2、最長1m範囲の音声を想定）」、ロジクール C922nがステレオマイク（カメラの左右に1台ずつ、計2台）、UGREEN FineCam LiteとAnker PowerConf C200がデュアルマイク内蔵と記載されています。音声をはっきり届けたい場合は、外付けのUSBマイクを併用する考え方があります。

5. マイクの指向性（どの方向の音を拾うか）

指向性は、マイクがどの方向の音を拾いやすいかを示します。一般的に、単一指向性は正面の音を拾いやすく、無指向性は周囲の音を満遍なく拾う傾向があります。仕様表では、FIFINE K683Bが単一指向性（カーディオイド）、Razer Seiren V3 Miniがスーパーカーディオイド（単一指向性）、SHURE MV7+が単一指向性、オーディオテクニカ AT-CSP1が360°無指向性エレクトレットマイクロホンと記載されています。Logicool G Blue Yetiは、商品説明では4種類の指向特性を備えると記載され、スペック欄の指向パターンは「単一指向性」と表示されています。1人で話すなら単一指向性、複数人で囲んで話すなら無指向性、という考え方が一般的です。

6. 接続方式・対応OS・プライバシー機能

多くのWebカメラやUSBマイクは、USBでパソコンにつなぎます。AT-CSP1はUSB（有線）・プラグ＆プレイ（ソフトのインストール不要）、Razer Seiren V3 MiniはUSB Type-A・プラグアンドプレイ（ソフト・ドライバー不要）、SHURE MV7+はUSBとXLR両対応と記載されています。オーディオテクニカ AT2020はXLRコネクタで、ファントム電源48V DC（要ファントム電源対応オーディオインターフェース）と記載されています。対応OSは、ロジクール C920nがWindows 7、8、10、11以降・macOS 10.10以降・Chrome OS、ロジクール Brio 100がWindows 10/11以降・macOS 10.15以降・ChromeOSなどと記載されています。プライバシー面では、Brio 100の一体型プライバシーシャッター（スライド式）や、Anker PowerConf C200のプライバシーシールド、UGREEN FineCam Liteのプライバシーカバーが記載されています。

04使い方別の考え方

オンライン会議・テレワークで使う

フルHD程度の解像度でも、会議アプリ側の設定や回線の状況により、実際に送られる映像は変わります。画角は、1人で映るなら狭め、複数人で映るなら広めを検討する考え方があります。顔認証でのログインを使いたい場合は、エレコム UCAM-CF20FBBKのようにWindows Hello顔認証対応と記載された機種を、仕様表で確認します。

配信・動画撮影に使う

フレームレートの選択肢や、画質を調整するソフトウェアの有無を確認します。ロジクール C922nは「ストリーミング向け」のWebカメラとして、720p 60FPSの表記と卓上用3脚の付属が記載されています。音声の質にこだわるなら、SHURE MV7+のような外付けマイクを組み合わせる考え方もあります。

少人数で集まって会議をする

1つの機器で複数人の音声を拾いたい場合は、無指向性のスピーカーフォンを検討します。AT-CSP1は、360°無指向性のマイクと、エコーキャンセラー、キャリングケースが記載されています。ただし、音声の聞こえ方は部屋の広さや、人の位置によって変わります。

ゲーム実況・ボイスチャットに使う

デスクの上に置けるUSBマイクを検討します。FIFINE K683BやRazer Seiren V3 Miniは、USB接続・ミュート機能が記載されています。マイクとの距離や角度で、音声の入り方は変わります。

プライバシーを重視したい

使わないときにレンズを覆えるかを確認します。シャッターやカバーの有無は、仕様表に記載されています。ただし、物理的なカバーの有無にかかわらず、会議に参加するときは、背景に映るものや、画面共有の内容に注意が必要です。

05使うときの注意点

✅ 気持ちよく使うためのポイント

  • 会議の前に、カメラの映り方とマイクの入力レベルをアプリで確認する
  • 背景に映るものや、画面共有の内容に気を配る
  • 使わないときは、レンズカバーを閉じるか、ケーブルを抜く
  • スピーカーとマイクが近いときは、音が回り込みやすいため、ヘッドホンの併用を検討する
  • ソフトウェアやドライバーは、メーカーの案内に従って更新する

⚠️ 避けたいこと

  • 相手の同意なく、会議や会話を録画・録音する（利用する場面のルールや、法令を確認する）
  • ケーブルを強く引っ張る、無理に曲げる
  • XLRマイクを、対応を確認せずにファントム電源のない機器につなぐ（接続前に取扱説明書を確認する）
  • レンズ面を、硬いものや強い溶剤で拭く（メーカーの手入れ方法に従う）

07よくある質問

Q.Webカメラは、4Kのほうがよいですか？

一概には言えません。4Kは映像の細かさを示す数字ですが、会議アプリ側の設定や、回線の状況によって、実際に相手に届く映像の細かさは変わります。使う場面（会議・配信・撮影など）と、パソコンの対応状況に合わせて選ぶのが一般的です。

Q.画角は、広いほうがよいですか？

用途によって異なります。広いと、複数人や背景を映せる一方、顔が小さく見える傾向があります。1人で映るなら狭めの画角、複数人で映るなら広めの画角を検討する考え方があります。当サイトの仕様表では、70°、78°、82°などの記載があります。

Q.Webカメラの内蔵マイクで足りますか？

使う場面によって異なります。内蔵マイクは手軽に使えますが、口元から離れた位置にあるため、音声の聞こえ方は設置状況に左右される傾向があります。音声をはっきり届けたい場合は、外付けのUSBマイクやスピーカーフォンを併用する考え方があります。

Q.マイクの「単一指向性」と「無指向性」は何が違いますか？

一般的に、単一指向性は正面の音を拾いやすく、無指向性は周囲の音を満遍なく拾う傾向があります。1人で話すなら単一指向性、複数人で囲んで話すなら無指向性が使われることが多いです。当サイトでは、FIFINE K683Bなどが単一指向性、オーディオテクニカ AT-CSP1が360°無指向性と記載されています。

Q.XLRマイクは、そのままパソコンにつなげますか？

つなげない場合が多いです。XLR接続のマイクは、一般的に、オーディオインターフェースなどの機器を介して接続します。当サイトの仕様表では、オーディオテクニカ AT2020がXLRコネクタ・ファントム電源48V DC（要ファントム電源対応オーディオインターフェース）と記載されています。接続できる機器は、取扱説明書で確認してください。
