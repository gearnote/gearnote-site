02違いのまとめ

  • 形状は、Live Beam 4が「完全ワイヤレス・インイヤー（ショートスティック型）」、Wave Buds 3が「完全ワイヤレス（バッズスタイル）」と記載されています。
  • ノイズ制御は、Live Beam 4のページに「アダプティブノイズキャンセリング2.0」、Wave Buds 3のページに「アクティブノイズキャンセリング、外音取り込みモード」と記載されています。通話用のマイクは、メーカー公開仕様の欄でLive Beam 4が6個、Wave Buds 3が4個です。
  • 再生時間は、Live Beam 4が「最大約48時間（ケース併用）」、Wave Buds 3が「合計最大40時間」です。メーカー公開仕様の欄では、イヤホン単体の再生時間はLive Beam 4がANCオフ12時間・ANCオン10時間、Wave Buds 3がANCオフ10時間・ANCオン8時間と記載されています。
  • 防塵防水はLive Beam 4が「IP55」、Wave Buds 3が「IP54」と記載されています。
  • Live Beam 4のページには、ワイヤレス充電対応とスマートディスプレイ付きの充電ケースが記載されています。Wave Buds 3のページには、10分の充電で3時間再生できる急速充電が記載されており、ワイヤレス充電についてはメーカーのページに記載がありません。Bluetoothはどちらもバージョン6.0です。
  • 比較表ではJBL Live Beam 4のマルチポイントが「掲載情報なし」ですが、JBL Live Beam 4のページのメーカー公開仕様の欄には、マルチポイントが「有」と記載されています。JBL Wave Buds 3のページにも「有」と記載されており、同時に接続できる台数はJBL Wave Buds 3のページに記載がありません。
  • ドライバーは、JBL Live Beam 4のメーカー欄に「10mmドライバー」、JBL Wave Buds 3に「8mm」と記載されています。再生周波数帯域はJBL Live Beam 4が20Hz〜40kHz、JBL Wave Buds 3が20Hz〜20kHz、感度はJBL Live Beam 4が98dB、JBL Wave Buds 3が100dB、インピーダンスはどちらも16Ωです。
  • 同梱のイヤーチップは、JBL Live Beam 4のメーカー欄に4サイズ（左右各1）、JBL Wave Buds 3のメーカー欄に3サイズ（1セット）と記載されています。連続通話時間は、JBL Live Beam 4が6.5時間、JBL Wave Buds 3が6時間です。

03こんな人にはこちら

▸JBL Live Beam 4が向いている人

Live Beam 4のページでは、ショートスティック型で、アダプティブノイズキャンセリング2.0、6つのマイクによる通話、スマートディスプレイ付きの充電ケースを備えたモデルと説明されています。

  • ケースの画面で操作したい人
  • 通話もよくするノイキャン対応イヤホンを探している人
  • ワイヤレス充電に対応したイヤホンがよい人

▸JBL Wave Buds 3が向いている人

Wave Buds 3のページでは、バッズスタイルで、外音取り込み付きのアクティブノイズキャンセリング、8mmドライバー、10分の充電で3時間再生できる急速充電を備えたモデルと説明されています。

  • 通勤や在宅作業で、ノイズキャンセリング付きのイヤホンを使いたい人
  • 10分の充電で3時間再生できる急速充電の記載を重視する人
  • ケース込みで長く使える再生時間の記載を重視する人

04場面別の選び方

使う場面ごとに、各商品ページの記載で見ておきたい点をまとめました。あくまで掲載情報にもとづく目安です。

  • 通話やオンライン会議が多いなら：通話用のマイクは、メーカー欄にJBL Live Beam 4が6個、JBL Wave Buds 3が4個（各イヤホンにデュアルビームフォーミングマイク）と記載されています。JBL Live Beam 4のページには「Perfect Calls 2.0」という通話機能の記載もあります。連続通話時間はJBL Live Beam 4が6.5時間、JBL Wave Buds 3が6時間です。
  • イヤホン単体で長く使いたいなら：イヤホン本体の最大再生時間は、JBL Live Beam 4がANCオフ時12時間・ANCオン時10時間、JBL Wave Buds 3がANCオフ時10時間・ANCオン時8時間と記載されています。ケース込みの合計はJBL Live Beam 4が48時間（ケースのバッテリーは最大36時間）、JBL Wave Buds 3が40時間（同、最大30時間）です。
  • 充電の手間を減らしたいなら：充電時間は、どちらも2時間と記載されています。JBL Wave Buds 3のページには、10分の充電で3時間再生できる急速充電の記載があります。JBL Live Beam 4のページには急速充電が「有」とありますが、分数の記載はありません。ワイヤレス充電は、JBL Live Beam 4が「有」、JBL Wave Buds 3はメーカーのページに記載がありません。
  • 周囲の音を聞き取りながら使いたいなら：JBL Live Beam 4のメーカー欄に「アンビエントアウェア」「トークスルー」、JBL Wave Buds 3のメーカー欄に「アンビエントアウェア」「トークスルー」「Voice Aware」と記載されています。名称は似ていますが、動作の違いは各ページに説明がないため、メーカーの案内でご確認ください。
  • 汗や雨の中で使う場面があるなら：防塵防水は、JBL Live Beam 4がIP55、JBL Wave Buds 3がIP54と記載されています。JBL Wave Buds 3のページには、水に浸けて使うことは想定されていないこと、充電ケースの防水等級が記載されていないことが書かれています。

05スペック用語のかんたん解説

比較表に出てくる用語を、一般的な意味で簡単に説明します。数値や対応の有無は各商品ページ・Amazon商品ページでご確認ください。

▸アダプティブノイズキャンセリング

周囲の騒音の状況に合わせて、騒音を小さくする強さを自動で調整する方式とされています。JBL Live Beam 4のページに「アダプティブノイズキャンセリング2.0」、メーカー欄に「トゥルー・アダプティブ・ノイズ・キャンセリング 2.0」と記載されています。JBL Wave Buds 3のページは「アクティブノイズキャンセリング」と記載されています。

▸マルチポイント

1つのイヤホンを、スマートフォンとパソコンなど複数の機器につないでおける機能です。切り替えの手間を減らせるとされています。両ページのメーカー欄に「有」と記載されています。

▸IP55／IP54

IPコードは、防塵と防水の等級を示す国際規格の表記です。最初の数字が防塵、次の数字が防水の等級を表します。JBL Live Beam 4はIP55、JBL Wave Buds 3はIP54と記載されています。数字の意味は、規格の定義をご確認ください。

▸LEオーディオ／Auracast

LEオーディオはBluetoothの新しい音声の仕組みで、Auracastは1つの音源を近くの複数の機器へ配信する機能です。JBL Live Beam 4のページに「LEオーディオ搭載（Auracast対応）」と記載されています。JBL Live Beam 4のページには、新機能は対応機器が必要という注意書きがあります。

▸感度・インピーダンス・再生周波数帯域

感度は一定の入力に対して出せる音の大きさの目安、インピーダンスは電気抵抗にあたる値、周波数帯域は再生できる音の範囲を示す数字です。数字だけで音の傾向が決まるわけではありません。両ページのメーカー欄に記載されています。

06購入前のチェックリスト

購入前に見ておくと安心な項目です。各商品ページの記載にもとづくため、最終的にはAmazon商品ページの最新情報もご確認ください。

  • 装着タイプ：JBL Live Beam 4はショートスティック型、JBL Wave Buds 3はバッズスタイルと記載されている。耳との相性は個人差があるため、イヤーチップのサイズが合うか確認する。
  • 対応機器：JBL Live Beam 4のページに、LEオーディオなどの新機能は対応機器が必要と書かれている。お使いのスマートフォンが対応しているか確認する。
  • コーデック：JBL Live Beam 4の仕様表には、Amazon商品ページの記載としてLDAC・LC3Plusなどが載っているが、同じページのメーカー欄には記載がないと書かれている。JBL Wave Buds 3のページにも記載がない。重視する場合は購入前に確認する。
  • ケースの操作：JBL Live Beam 4はスマートディスプレイ付きの充電ケースで操作でき、慣れが必要な場合があると書かれている。JBL Wave Buds 3のページには、ケースの操作についての記載がない。
  • 再生時間の条件：ケース込みの数字は、ケースのバッテリーを含む合計時間。イヤホン単体の時間とは別の数字として見る。
  • 色と型番：JBL Live Beam 4のページはサンド、JBL Wave Buds 3のページはティール（JBLWBUDS3TEL）。JBL Wave Buds 3のメーカー欄はホワイトのページを参照しており、カラー違いの同型番と書かれている。購入する色を確かめる。

07よくある質問

Q.JBL Live Beam 4とWave Buds 3の主な違いは何ですか？

各商品ページの記載では、形状（Live Beam 4はショートスティック型、Wave Buds 3はバッズスタイル）、ノイズキャンセリングの名称、ケース併用の再生時間（Live Beam 4は最大約48時間、Wave Buds 3は合計最大40時間）、防塵防水（IP55とIP54）が異なります。

Q.ワイヤレス充電に対応していますか？

Live Beam 4のページには、ワイヤレス充電に対応と記載されています。Wave Buds 3は、ワイヤレス充電についてメーカーのページに記載がありません。購入前にAmazon商品ページとメーカーの最新情報でご確認ください。

Q.対応コーデックは分かりますか？

どちらのページも、対応コーデックの種類はメーカーのページに記載がないと説明されています。コーデックを重視する場合は、購入前にメーカーの最新情報でご確認ください。

Q.どちらを選べばいいですか？

ショートスティック型の装着や、ケースの画面での操作、ワイヤレス充電の記載を重視するならLive Beam 4が候補です。外音取り込みモード、10分の充電で3時間再生できる急速充電、バッズスタイルの形状を重視するならWave Buds 3のページを確認するとよいでしょう。イヤホン選び全般はワイヤレスイヤホンの選び方ガイドもご覧ください。

Q.通話用のマイクの数に違いはありますか？

メーカー公開仕様の欄に、JBL Live Beam 4はマイク6個、JBL Wave Buds 3はマイク4個（各イヤホンにデュアルビームフォーミングマイク）と記載されています。JBL Live Beam 4のページには、6つのマイクとAIアルゴリズムによる「Perfect Calls 2.0」の記載もあります。

Q.イヤホン単体の再生時間はどれくらいですか？

メーカー欄に、JBL Live Beam 4はANCオフ時12時間・ANCオン時10時間、JBL Wave Buds 3はANCオフ時10時間・ANCオン時8時間と記載されています。ケース込みの合計はJBL Live Beam 4が48時間、JBL Wave Buds 3が40時間で、使用環境によって変わります。

Q.マルチポイントは使えますか？

メーカー欄に、どちらも「有」と記載されています。JBL Wave Buds 3のページには、同時に接続できる台数の記載がありません。接続の手順は、取扱説明書やJBL Headphonesアプリの案内でご確認ください。

Q.Bluetoothのバージョンは同じですか？

メーカー欄に、どちらもバージョン6.0と記載されています。対応プロファイルは、どちらもA2DP V1.4、AVRCP V1.6.3、HFP V1.8です。JBL Live Beam 4のページにはLEオーディオ搭載（Auracast対応）という記載もあります。

Q.付属のイヤーチップは何サイズですか？

メーカー欄に、JBL Live Beam 4はイヤーチップ4サイズ（左右各1）、JBL Wave Buds 3はイヤーチップ3サイズ（1セット）と記載されています。そのほか、JBL Live Beam 4は保証書や警告カード、クイックスタートの同梱も記載されています。

Q.本体の重さは比べられますか？

メーカー欄に、JBL Live Beam 4は重量欄82.7g・ケース73g・イヤーピース9.7g、JBL Wave Buds 3はケース30.33g・イヤーピース4.87g・重量40.07gと記載されています。項目名がメーカー表記のままで、何を指す数字かが明記されていないため、このページでは単純に比べていません。
