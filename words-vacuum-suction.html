掃除機の「吸引力」の数字の読み方｜吸込仕事率（W）・Pa・AWの違い

W・Pa・AWは、単位も条件も違う数字です。どの数字が、どの決まりで書かれているのかを、公的な資料とメーカーの資料で確かめました。

執筆・確認：GEARNOTE運営（H＆C）　データの時点：2026年10月31日〜11月11日（集計：2026年11月15日）

013つの数字は、別のものを表しています

掃除機の「吸引力」として商品に書かれる数字には、主に吸込仕事率（W：ワット）、Pa（パスカル）、AW（エアワット）の3つがあります。名前は似ていても、測っているものが違います。

表記単位の意味主に見かける場所決まり方
吸込仕事率（W）ワットは工率（仕事率）の単位で、1秒間に1ジュールの工率ですコード付きの掃除機の仕様表JIS C 9108に試験の方法があり、家庭用品品質表示法でワット単位の表示が決められています（コード付きなどが対象）
Paパスカルは圧力の単位で、1平方メートルにつき1ニュートンの圧力ですロボット掃除機の商品ページ公的な規格の数字としては確認できませんでした。メーカーが「社内試験」「試験環境下」などと注記して書いています
AW圧力と空気の流れの量の両方を考えた値だと、メーカーが説明しています一部のメーカーの説明公的な規格の数字としては確認できませんでした

単位の定義は、計量単位令の別表第一にもとづきます。ワットとパスカルは、そもそも物理量の種類が違うので、「○Wは○Paに当たる」という換算はできません。

ダイソン（シンガポール）の記事も、ロボット掃除機の吸引をAWで示すメーカーとPaで示すメーカーがあり、両者は別の要素を表すため並べて比べられない、と説明しています。同じ記事では、Paは内側と外側の圧力の差を測るもの、AWは圧力（Pa）と空気の流量の両方を考えた値、としています（Dyson Singaporeの記事（英語））。

02吸込仕事率（W）とは：JIS C 9108と家庭用品品質表示法

JIS C 9108は「電気掃除機」の日本産業規格で、現在の版は2017年8月21日の改正版です（2022年10月20日に確認、状態は有効。JSAの規格ページ）。目次には「吸込仕事率」「吸込仕事率試験」「附属書A（規定）吸込仕事率の測定方法」があり、ほかに「騒音」「最大集じん容積」「じゅうたん床面における性能測定方法（参考）」などの項目が並びます（JSAが公開している規格の冒頭部分（PDF））。

家庭用品品質表示法の決まりでは、電気掃除機は、JIS C 9108に規定する吸込仕事率を、ワット単位で表示します。表示の許容範囲は、表示値の−10%以内です（消費者庁の電気掃除機の表示）。

メーカーの仕様表では、吸込仕事率を「最大〜最小」の幅で書くことがあります。パナソニックの紙パック式掃除機MC-SK15Jは、吸込仕事率を320W〜約80Wと書き、注記で「JIS規格に定められている吸込力の目安」としたうえで、使用時の吸じん力は、吸込具の種類・ゴミのたまり具合・床材の違いなどによって異なる、と説明しています（パナソニックMC-SK15Jの仕様）。

つまり、吸込仕事率は決められた試験の条件での数字です。床の上で実際にどれだけゴミを取れるかを、そのまま表す数字ではありません。測定の式や細かい条件は、規格の本文（有料）に書かれているため、GEARNOTE運営は未閲覧で、このページには書いていません。

03コードレス・ロボット掃除機に、吸込仕事率（W）が少ない理由

確認できた資料では、充電式の掃除機は、どちらの決まりの範囲にも入っていません。

  • JIS C 9108の適用範囲は、送風機の背圧を使う、定格消費電力100〜1,500Wの家庭用電気掃除機で、「充電式掃除機及び業務用掃除機」には適用しないと書かれています（JSAが公開している規格の冒頭部分（PDF））。
  • 家庭用品品質表示法の電気掃除機では、電源に電池（充電池を含む）を使用するものは対象外です（消費者庁）。

実際に、パナソニックのコードレススティック掃除機MC-NX700Kの仕様表には、集じん容積・使用時間の目安（HIGHで約10分など）・運転音は載っていますが、吸込仕事率の行はありません。運転音の表示は、JIS C 9108に準拠と注記されています（パナソニックMC-NX700Kの仕様）。

このため、コードレスやロボット掃除機では、メーカーが独自の条件で測ったPaなどの数字を書くか、吸引の数字を書かないかのどちらかになりがちです。ロボット掃除機のPaについて、Narwal Japanは「試験環境下による数値。実際の数値は利用環境によって異なる場合があります」と注記しています（Narwal Japanの製品ページ）。

ロボット掃除機でPaを書いていた16台の数字は、1,300〜30,000Paでした。数字の前後に「最大」とあるものが8台、「社内試験」「試験環境下」とあるものが2台、「モード」「段階」とあるものが4台です（重なりあり）。ダイソンのロボット掃除機（R2 Nurovi）は、メーカー情報欄で「吸引仕事率（強モード） 21,000Pa」と書かれていて、「仕事率」という名前でも単位はPaです。

商品名（販売ページの名前）にPaの数字が入っているロボット掃除機は3台ありました。そのうちXiaomiのロボット掃除機6は、商品名に「30,000Pa」とありますが、GEARNOTEが確認したメーカー公開情報の欄には、Paの数字がありません。商品名の数字と、メーカーの仕様の欄は、別々に確かめてください。

この集計は、GEARNOTEに載せている商品の範囲の数字です。市場全体の割合ではありません。元のデータは、コードレス掃除機の仕様一覧とロボット掃除機の仕様一覧にあります。

05よくある読み違い

  • 「Paが大きいほど、よく吸う」：Paは、メーカーごとの試験の条件で測った圧力の数字です。条件が書かれていない数字どうしは、同じ物差しで測ったとは限りません。ダイソン（シンガポール）の記事も、Paが高いことは掃除の性能を約束しない、と説明しています。
  • 「320Wの掃除機は、消費電力が320W」：吸込仕事率は、JIS C 9108の試験で決まる数字で、消費電力（コンセントから使う電力）とは別の項目です。JIS C 9108の対象は、定格消費電力100〜1,500Wの掃除機です。
  • 「W表示のない掃除機は、数字を隠している」：充電式は、JIS C 9108と家庭用品品質表示法の吸込仕事率の表示の範囲に入っていません。書かれていないことは、それ自体では性能の上下を示しません。
  • 「最大○Pa」をいつもの数字として読む：「最大」は、いちばん大きい値を示す書き方です。GEARNOTEに掲載したロボット掃除機でPaを書いていた16台のうち8台は、数字の前後に「最大」とありました。ふだんのモードの数字や、そのときの運転時間は、別の欄で確かめます。

06商品ページで確かめること

  • 数字の名前と単位（吸込仕事率のWか、Paか、AWか）。
  • どのモードの数字か（強・標準・最大など）。モードごとに運転時間も変わります。
  • 注記の条件（「社内試験」「試験環境下」「JIS C 9108による」など）。
  • 吸引の数字以外の、同じ物差しで比べやすい項目（質量・集じん容積・充電時間・運転時間など）。GEARNOTEのコードレス掃除機の仕様一覧は、こうした項目を並べています。

選ぶときの考え方は、コードレス掃除機の選び方とロボット掃除機の選び方にまとめています。

09よくある質問

Q.吸込仕事率のWと、ロボット掃除機のPaは、どちらが大きいか比べられますか？

比べられません。ワットは工率（仕事率）、パスカルは圧力の単位で、物理量の種類が違います。決まり方も違い、吸込仕事率はJIS C 9108の試験で決まる数字、ロボット掃除機のPaはメーカーが社内試験などの条件で書く数字です。

Q.コードレス掃除機に、吸込仕事率が書かれていないのはなぜですか？

JIS C 9108は充電式掃除機に適用しないと定め、家庭用品品質表示法の電気掃除機の表示も、電池（充電池を含む）を使うものを対象外としています。そのため、書くかどうか・何で書くかはメーカーごとに違います。GEARNOTEに掲載したコードレス掃除機22台では、メーカー情報欄に吸込仕事率をWで書いていたのは1台でした。

Q.「最大30,000Pa」は、ふだんの掃除のときの数字ですか？

「最大」は、いちばん大きい値を示す書き方で、ふだんの運転の数字とは限りません。GEARNOTEに掲載したロボット掃除機でPaを書いていた16台のうち、数字の前後に「最大」とあるものは8台でした。ふだんのモードの数字は、商品ページの仕様や取扱説明書で確かめてください。

Q.吸込仕事率が大きい掃除機ほど、ゴミをよく取りますか？

数字だけでは決まりません。パナソニックは仕様の注記で、使用時の吸じん力は、吸込仕事率以外に吸込具の種類・ゴミのたまり具合・床材の違いなどによって異なる、と説明しています。
