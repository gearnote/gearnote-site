02違いのまとめ

  • タイプは、バッファローが「5-in-1」のドッキングステーション（ケーブル長は約30cm）、Ankerが「USB-Cハブ（モニタースタンド一体型）」と記載されています。
  • 給電は、バッファローが「最大100W（USB PD対応）」、AnkerがUSB PD入力対応のUSB-C（最大100W入力）とUSB-C出力（内蔵ケーブル付き・最大出力85W）と記載されています。
  • HDMIは、バッファローが1ポートで「4K出力対応」、Ankerが×1で「最大4K/60Hz」と記載されています。
  • その他のポートは、バッファローが「HDMI、USB 3.0、イーサネット」でUSBポート総数3、AnkerがUSB 3.2 Gen1 USB-C×1、USB 3.2 Gen1 USB-A×1、USB 2.0 USB-A×2、イーサネット（最大1Gbps）、microSD＆SDカードスロット、3.5mmオーディオジャックと記載されています。SDカードスロットと3.5mmオーディオジャックの記載があるのはAnkerのページのみです。
  • サイズと重さは、バッファローが10.2×4.1×1.6cm・62g、Ankerが約540×220×90mm・約1592gと記載されています。保証は、バッファローが1年間、Ankerが「最大24ヶ月保証」と記載されています。
  • HDMIの映像出力は、Anker 10-in-1 モニタースタンドのページに「最大4K・60Hz」と記載されています。バッファロー LUD-U3-CGHDBKのページの仕様表は「4K出力対応」で、メーカー公開仕様の欄に「最大3840×2160 30Hz」と記載されています。同じ4Kでも、記載されているHzの数値が異なります。
  • パソコンへの給電は、バッファロー LUD-U3-CGHDBKのメーカー公開仕様の欄に「ホストPCへ最大85W。本製品の消費は15W」と記載され、仕様表の「最大100W」は電源入力側の値と説明されています。Anker 10-in-1 モニタースタンドのページにも、USB PD入力は最大100W、USB-C出力は最大85Wと記載されています。どちらも、ACアダプターは付属しないと書かれています。
  • USBポートの速度は、バッファロー LUD-U3-CGHDBKのメーカー公開仕様の欄に「USB 3.2 Gen 1：5Gbps」、各ポート最大900mAと記載されています。Anker 10-in-1 モニタースタンドは、USB 3.2 Gen1のUSB-CとUSB-Aが最大5Gbps、USB-A×2がUSB 2.0（最大480Mbps）と記載されています。保証は、バッファロー LUD-U3-CGHDBKが1年間、Anker 10-in-1 モニタースタンドが「18ヶ月保証＋6ヶ月（Ankerで会員登録後）」と記載されています。

04場面別の選び方

使う場面ごとに、各商品ページの記載で見ておきたい点をまとめました。あくまで掲載情報にもとづく目安です。

  • 出張や外出先でノートパソコンと一緒に持ち運ぶなら：バッファロー LUD-U3-CGHDBKは、62gでケーブル長約30cmと記載されています。寸法は約102×16×41mmです。Anker 10-in-1 モニタースタンドは、約1592gで、持ち運び用の小さなハブを探している人には向かないという注意が記載されています。
  • 机の上にモニターを置いて据え置きで使うなら：Anker 10-in-1 モニタースタンドのページには、モニタースタンドとして使え、約14kgの重さまで耐えられると記載されています。幅540mmの置き場所が必要で、スタンドの高さは調節できないという注意もあります。載せるモニターの重さと大きさを先に確認してください。
  • 映像をなめらかに表示したいなら：HDMIの映像出力は、Anker 10-in-1 モニタースタンドのページに「最大4K・60Hz」、バッファロー LUD-U3-CGHDBKのメーカー公開仕様の欄に「最大3840×2160 30Hz」と記載されています。一般にHzの数値が大きいほど、1秒間に画面を書き換える回数が多くなります。作業内容に合わせて、この数値と、モニター側の対応を確認してください。
  • カメラのSDカードを取り込みたいなら：Anker 10-in-1 モニタースタンドのページには、microSD＆SDカードスロットがあると記載されています。バッファロー LUD-U3-CGHDBKのページには、SDカードスロットの記載がありません。USB経由でカードリーダーを使う場合は、USBポートの空きを確認してください。
  • 有線LANで安定した通信をしたいなら：Anker 10-in-1 モニタースタンドは「イーサネット（最大1Gbps）」と記載されています。バッファロー LUD-U3-CGHDBKは、メーカー公開仕様の欄に「1000BASE-T / 100BASE-TX / 10BASE-T」と記載されています。どちらもLANポートがあります。つなぐネットワーク機器の対応も確認してください。

05スペック用語のかんたん解説

比較表に出てくる用語を、一般的な意味で簡単に説明します。数値や対応の有無は各商品ページ・Amazon商品ページでご確認ください。

▸USB PDのパススルー給電

充電器からの電力を、ハブを通してパソコンに届ける仕組みです。ハブ自体も電力を使うため、入力より出力は小さくなります。バッファロー LUD-U3-CGHDBKとAnker 10-in-1 モニタースタンドのページには、入力は最大100W、パソコンへの出力は最大85W（ハブ自体が15W分を使う）と記載されています。

▸DisplayPort Alternate Mode

USB Type-Cのポートから、映像を出力するための方式です。パソコン側のUSB Type-Cポートが対応していないと、HDMIに映像が出ません。バッファロー LUD-U3-CGHDBKのページとAnker 10-in-1 モニタースタンドのページのどちらにも、パソコン側が対応している必要があると書かれています。

▸Hz（リフレッシュレート）

1秒間に画面を書き換える回数を示す単位です。数値が大きいほど、動きのある表示がなめらかになるとされています。Anker 10-in-1 モニタースタンドは最大4K・60Hz、バッファロー LUD-U3-CGHDBKは最大3840×2160 30Hzと記載されています。

▸USB 3.2 Gen1と USB 2.0

USBの通信速度の規格です。USB 3.2 Gen1は最大5Gbps、USB 2.0は最大480Mbpsです。Anker 10-in-1 モニタースタンドのページには、USB 3.2 Gen1のポートは充電・映像出力に非対応と記載されています。ポートごとに速度や用途が異なるため、つなぐ機器に合わせて使い分けます。

▸1000BASE-T

有線LANの通信規格の名称で、最大1Gbpsに相当します。バッファロー LUD-U3-CGHDBKのメーカー公開仕様の欄に「1000BASE-T / 100BASE-TX / 10BASE-T」、Anker 10-in-1 モニタースタンドのページに「イーサネット（最大1Gbps）」と記載されています。実際の通信速度は、つなぐルーターや回線によって変わります。

06購入前のチェックリスト

購入前に見ておくと安心な項目です。各商品ページの記載にもとづくため、最終的にはAmazon商品ページの最新情報もご確認ください。

  • パソコンのUSB Type-Cポート：映像出力（DisplayPort Alternate Mode）に対応しているか確認する。非対応の場合は、HDMIに映像が出ない。
  • 充電器：バッファロー LUD-U3-CGHDBKもAnker 10-in-1 モニタースタンドも、ACアダプターは付属しない。USB PD対応の充電器を、別に用意する必要がある。
  • パソコンの必要電力：どちらも、パソコンへの出力は最大85W。ノートパソコンの必要電力がこの範囲内かどうか確認する。
  • HDMIの数：どちらもHDMIは1つ。2台のモニターに映す使い方は想定されていない。
  • 置き場所：Anker 10-in-1 モニタースタンドは約540×220×90mmで、モニターを載せて使うスタンド一体型。バッファロー LUD-U3-CGHDBKは約102×16×41mmのコンパクトな形で、ケーブルは約30cm。
  • 接続の方法：Anker 10-in-1 モニタースタンドのページには、ほかのUSBハブ経由の接続では動作しない場合があると書かれている。パソコン本体のUSB Type-Cポートに直接つなぐ。

07よくある質問

Q.バッファロー LUD-U3-CGHDBKとAnker 10-in-1の主な違いは何ですか？

各商品ページの記載では、バッファローは62gの小型の5-in-1ドッキングステーション、Ankerは約1592gのモニタースタンド一体型ハブです。ポートの種類と数、給電（バッファロー最大100W、Anker入力最大100W・出力最大85W）、サイズと重さが大きく異なります。HDMIは、どちらも4K出力に対応と記載されています。

Q.どちらもHDMIは1ポートですか？

バッファローのページには「HDMIポート総数 1（4K出力対応）」、Ankerのページには「HDMI ×1（最大4K/60Hz）」と記載されています。バッファローのページには、デュアルディスプレイ出力はできないという注意書きもあります。

Q.有線LANやSDカードは使えますか？

バッファローのページにはインターフェースとして「イーサネット」の記載があり、Ankerのページにはイーサネット（最大1Gbps）とmicroSD＆SDカードスロットの記載があります。SDカードスロットの記載があるのはAnkerのページのみです。

Q.どちらを選べばいいですか？

持ち運びを前提に、62gの小型でケーブル長約30cmの形を探す場合は、バッファローのページが候補です。デスクのモニター位置を上げながら、SDカードスロットやオーディオジャックまで1台にまとめたい場合は、Ankerのページを確認するとよいでしょう。Ankerのページには、持ち運び用の小さなハブを探す人には向かないという注意もあります。接続規格の見方はUSB-Cハブ・ドックの選び方ガイドもご覧ください。

Q.HDMIの映像出力は、どちらも同じ解像度とHzですか？

Anker 10-in-1 モニタースタンドのページには、最大4K・60Hzと記載されています。バッファロー LUD-U3-CGHDBKのページの仕様表は「4K出力対応」で、メーカー公開仕様の欄に「最大3840×2160 30Hz」と記載されています。使うモニターとパソコンの対応も、あわせてご確認ください。

Q.パソコンへの給電は何ワットまでですか？

バッファロー LUD-U3-CGHDBKのメーカー公開仕様の欄には、電源入力はUSB PD最大100W、パソコンへの出力は最大85W（本製品の消費は15W）と記載されています。Anker 10-in-1 モニタースタンドのページにも、USB PD入力は最大100W、USB-C出力は最大85Wと記載されています。

Q.ACアダプターは付属しますか？

バッファロー LUD-U3-CGHDBKのメーカー公開仕様の欄にも、Anker 10-in-1 モニタースタンドのページにも、ACアダプターは付属しないと記載されています。充電しながら使う場合は、USB PD対応の充電器を別に用意してください。

Q.対応するOSや端末を教えてください。

バッファロー LUD-U3-CGHDBKの仕様表には「Chromebook、Mac、Windowsパソコン、スマートフォン、タブレット」と記載されています。Anker 10-in-1 モニタースタンドのページには「Windows 10/11、macOS 10.14以降、ChromeOS」と記載されています。どちらも、パソコン側の映像出力と給電の対応が前提です。

Q.モニターを載せられますか？スタンドの高さは変えられますか？

Anker 10-in-1 モニタースタンドのページには、約14kgの重さまで耐えられ、モニターを載せて使えると記載されています。メーカーの注意書きには、モニタースタンドの高さは調節できないとあります。バッファロー LUD-U3-CGHDBKはスタンド一体型ではないため、モニターは載せられません。

Q.USBポートの速度は同じですか？

バッファロー LUD-U3-CGHDBKのメーカー公開仕様の欄には「USB 3.2 Gen 1：5Gbps」と記載されています。Anker 10-in-1 モニタースタンドのページには、USB 3.2 Gen1のポートが最大5Gbps、USB 2.0のUSB-A×2が最大480Mbpsと記載されています。Anker 10-in-1 モニタースタンドのUSB 3.2 Gen1ポートは、充電・映像出力に非対応です。

Q.ハブやドックの選び方を知りたいときは？

ポートの種類や映像出力、給電の見方はUSB-Cハブ・ドッキングステーションの選び方ガイドでご覧いただけます。
