キーボードの選び方ガイド｜接続方式・配列・キースイッチ・サイズの見方

キーボードは、毎日長く触れる道具だからこそ、接続方式・配列・キーの構造・サイズといった仕様表の違いが、使い勝手を左右します。ただし、キーを押したときの感触や、打ちやすさは個人差が大きく、仕様表の数字だけでは判断できない面もあります。このページでは、当サイトに掲載しているキーボードの記載値を例に、仕様表の読み方と、使い方別の考え方を整理しました。実際の対応OSや付属品は機種ごとに異なるため、購入前にAmazon商品ページとメーカー情報でご確認ください。

執筆・確認：GEARNOTE運営（H＆C）　最終更新：2026-10-05

01まず知っておきたい接続方式の違い

キーボードの接続方式は、大きく分けて3つです。以下は一般的な説明で、実際の対応は機種ごとに異なります。

接続方式仕組み一般的な特徴気をつけたい点
Bluetoothパソコン・タブレット・スマートフォンと、無線で直接つなぐUSBポートを使わずに接続でき、複数の機器と切り替えて使える機種がある対応するBluetoothの規格やOSを確認する。つなぎ直しや切り替えの操作は機種ごとに異なる
USBレシーバー（2.4GHz）付属の小型レシーバーをUSBポートに挿して、無線でつなぐパソコン側にBluetoothがなくても使える。ペアリング作業が少ない機種が多いUSBポートを1つ使う。レシーバーを紛失すると使えなくなる場合がある
有線（USB）ケーブルでパソコンと直接つなぐ電池や充電の管理が不要で、ゲーミング用途の機種に多いケーブルの長さと、机の上の取り回しを確認する

複数の方式に対応した機種もあります。使う機器の台数や、置き場所に合わせて、どの接続方式が使えるかを確認するのが一般的です。

02スペック表で見る6つのポイント

1. 接続方式と、対応する機器

当サイトの仕様表では、Apple Magic Keyboard 日本語(JIS)が接続方式Bluetooth・充電端子USB-C・対応OS「Mac（Apple Vision Proにも対応）」、バッファロー BSKBW355BKが「USB-A（2.4GHzワイヤレスレシーバー）」、Keychron B1 Proが「2.4GHzワイヤレス／Bluetooth 5.2／有線」、ロジクール G213rが有線と記載されています。複数の方式に対応した機種は、使う機器に合わせて切り替えられる点を確認しましょう。

2. 配列（JIS配列・US配列）

配列は、キーの数や並びの規格です。一般的に、日本語配列（JIS配列）は、かな入力を印字したキーや、変換キーなどを備え、US配列は、キーの数が少なくシンプルな並びです。仕様表では、Keychron B1 ProがJISレイアウト（かな印字なし）、ロジクール PEBBLE KEYS 2が日本語配列・84キー、PFU HHKB Professional HYBRID Type-Sが日本語配列、Keychron B6 ProとKeychron K2 Version2がUSレイアウトと記載されています。普段使っている配列と異なる配列を選ぶと、慣れるまでに時間がかかる場合があります。

3. サイズ（フルサイズ・テンキーレス・コンパクト）

数字入力用のテンキーが付いているものが「フルサイズ」、テンキーを省いたものが「テンキーレス」で、さらに小型化したコンパクトなものもあります。仕様表では、Keychron B6 Proとロジクール K295GPがフルサイズ・テンキー付き、エレコム TK-FBM120KBK/ECがテンキー付き、Keychron K2 Version2が84キー（テンキーレス）と記載されています。寸法は、バッファロー BSKBW355BKが28.6×12.1×2cm、エレコム Precisionistが約31.3×11.9×1.6cm、HHKB Professional HYBRID Type-Sが約29.4×12×4cmと記載されています。机のスペースや、持ち運ぶ頻度で選びましょう。

4. キースイッチ・キー構造

キーの構造によって、押したときの感触や音が変わる傾向があります。仕様表では、Keychron K2 Version2が「Gateron G Pro 赤軸（ホットスワップ対応）」、Keychron B1 Proが「シザースイッチ」、エレコム Precisionistが「V型パンタグラフ・キーストローク1.5mm」、エレコム TK-FBM120KBK/ECが「メンブレン」、HHKB Professional HYBRID Type-Sが「静電容量無接点方式（Type-Sのキー構造）」、ロジクール G213rが「独自のMech-domeスイッチ（メンブレン）」と記載されています。感触の好みには個人差が大きいため、構造の名称は目安として見てください。

5. マルチペアリング・電源

複数の機器を切り替えて使う場合は、登録できる台数が目安になります。ロジクール PEBBLE KEYS 2は「Easy-Switchで最大3台のデバイスをキーで切り替え」、エレコム Precisionistは「最大4台（Bluetooth 3台・USBレシーバー1台）」、HHKB Professional HYBRID Type-Sは「4台まで」と記載されています。電源は、乾電池式と充電式があり、ロジクール K295GPは単4形乾電池×2（電池寿命最大24ヶ月）、バッファロー BSKBW355BKは単4電池2本で約3年使用可能（メーカー公表値）、ロジクール MX KEYS SはUSB-C充電式と記載されています。電池寿命は使い方によって変わる目安の値です。

6. 対応OS・独自機能

対応OSは、機種ごとに異なります。ロジクール PEBBLE KEYS 2はBluetooth接続時の対応OSとして、Windows 10、11以降、macOS 11以降、iPadOS 14以降、Android OS 9.0以降、Chrome OSなどが記載されています。Keychron B1 ProはWindows 10／macOS 10.12 Sierra／Ubuntu 20.04が最小バージョンとして記載されています。Keychron K2 Version2はMacとWindows用のキーキャップが付属します。また、ロジクール MX KEYS Sにはスマートバックライト、HHKB Professional HYBRID Type-Sにはキーマップ変更機能が記載されています。

04使い方別の考え方

パソコンとタブレットを切り替えて使いたい

Bluetoothに対応し、複数台を登録できる機種を確認します。ロジクール PEBBLE KEYS 2やエレコム TK-FBM120KBK/ECのように、マルチペアリングに対応した機種があります。対応OSも、機器ごとに確認してください。

数字入力が多い

テンキー付きのフルサイズを検討する考え方があります。ロジクール K295GP、エレコム TK-FBM120KBK/EC、Keychron B6 Proがテンキー付きと記載されています。机が狭い場合は、本体の寸法も確認しましょう。

持ち運んで使いたい

薄型・軽量の機種を検討します。ロジクール PEBBLE KEYS 2は重量415g、エレコム Precisionistは最薄部約9mmと記載されています。持ち運ぶ頻度が高い場合は、電源方式（乾電池式か充電式か）もあわせて確認します。

キーの感触にこだわりたい

キーの構造（メンブレン、パンタグラフ、シザー、メカニカル、静電容量無接点など）の違いを、仕様表で確認します。Keychron K2 Version2のようにホットスワップ対応の機種は、スイッチの交換に対応していると記載されていますが、交換できるスイッチの種類や手順は、取扱説明書の案内に従う必要があります。

ゲームで使いたい

有線接続や、ライティング機能を備えた機種があります。ロジクール ゲーミングキーボード G213rは有線接続・LIGHTSYNC RGB・着脱式パームレスト付属と記載されています。接続の遅れが気になる場合は、無線より有線を検討する考え方があります。

05使うときの注意点

✅ 長く快適に使うためのポイント

  • 手首や肩に負担がかからないよう、机と椅子の高さ、キーボードの角度を調整する
  • 長時間の入力では、適度に休憩をとり、手や指を休める
  • 乾電池式は、使用機器の取扱説明書に従って、電池の向きと種類を確認する
  • 充電式は、付属または対応を確認したケーブルで充電する
  • 耐水設計などの記載がある機種でも、使用条件は取扱説明書で確認する

⚠️ 避けたいこと

  • 飲み物をキーボードの近くに置いたまま作業する（こぼれた場合は、取扱説明書に従って電源を切る）
  • 電池の種類を混ぜて使う、使い切った電池を入れたままにする
  • 充電中に異常な熱や、膨らみなどを感じたまま使い続ける（使用を中止し、メーカーに問い合わせる）
  • ホットスワップなどの分解を伴う作業を、取扱説明書の確認なしに行う

07よくある質問

Q.BluetoothとUSBレシーバーは、どちらがよいですか？

どちらが優れているとは一概に言えません。Bluetoothは、USBポートを使わずに接続でき、複数の機器を切り替えられる機種があります。USBレシーバー（2.4GHz）は、パソコン側にBluetoothがなくても使えます。使う機器の台数や、USBポートの空きに合わせて選ぶのが一般的です。

Q.JIS配列とUS配列は、どう選べばよいですか？

普段使っているキーボードの配列に合わせるのが一般的です。日本語配列（JIS配列）は、かな入力や変換キーを備え、US配列は、キーの数が少なくシンプルな並びです。慣れていない配列を選ぶと、打ち間違いが増える場合があるため、商品名や仕様表の「レイアウト」「配列」の記載を購入前に確認してください。

Q.メカニカルと、メンブレン・パンタグラフ式の違いは何ですか？

キーの構造の違いで、押したときの感触や音、厚みが変わる傾向があります。一般的に、メカニカルはキーごとに独立したスイッチを持ち、パンタグラフ式やシザー式は薄型の機種に多く、メンブレンはゴムの膜を押して入力する構造とされます。感触の好みは個人差が大きいため、用途や置き場所と合わせて判断してください。

Q.電池式と充電式は、どちらを選べばよいですか？

電池式は、電池を交換すれば使い続けられる点、充電式は電池を買い足さずに済む点が特徴です。当サイトの仕様表では、バッファロー BSKBW355BKが単4電池2本で約3年使用可能（メーカー公表値）、ロジクール MX KEYS SがUSB-C充電式と記載されています。電池寿命は使い方によって変わる目安の値です。

Q.ホットスワップ対応とは何ですか？

一般的に、はんだ付けをせずに、キースイッチを交換できる構造のことです。当サイトの仕様表では、Keychron K2 Version2が「Gateron G Pro 赤軸（ホットスワップ対応）」と記載されています。交換できるスイッチの種類や、交換の手順は、取扱説明書やメーカー情報に従ってください。
