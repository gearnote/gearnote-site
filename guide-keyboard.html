キーボードの選び方ガイド｜接続方式・配列・キースイッチ・サイズの見方

キーボードは、毎日長く触れる道具だからこそ、接続方式・配列・キーの構造・サイズといった仕様表の違いが、使い勝手を左右します。ただし、キーを押したときの感触や、打ちやすさは個人差が大きく、仕様表の数字だけでは判断できない面もあります。このページでは、当サイトに掲載しているキーボードの記載値を例に、仕様表の読み方と、使い方別の考え方を整理しました。実際の対応OSや付属品は機種ごとに異なるため、購入前にAmazon商品ページとメーカー情報でご確認ください。

01まず知っておきたい接続方式の違い

キーボードの接続方式は、大きく分けて3つです。以下は一般的な説明で、実際の対応は機種ごとに異なります。

接続方式仕組み一般的な特徴気をつけたい点
Bluetoothパソコン・タブレット・スマートフォンと、無線で直接つなぐUSBポートを使わずに接続でき、複数の機器と切り替えて使える機種がある対応するBluetoothの規格やOSを確認する。つなぎ直しや切り替えの操作は機種ごとに異なる
USBレシーバー（2.4GHz）付属の小型レシーバーをUSBポートに挿して、無線でつなぐパソコン側にBluetoothがなくても使える。ペアリング作業が少ない機種が多いUSBポートを1つ使う。レシーバーを紛失すると使えなくなる場合がある
有線（USB）ケーブルでパソコンと直接つなぐ電池や充電の管理が不要で、ゲーミング用途の機種に多いケーブルの長さと、机の上の取り回しを確認する

複数の方式に対応した機種もあります。使う機器の台数や、置き場所に合わせて、どの接続方式が使えるかを確認するのが一般的です。

02スペック表で見る6つのポイント

1. 接続方式と、対応する機器

当サイトの仕様表では、Apple Magic Keyboard 日本語(JIS)が接続方式Bluetooth・充電端子USB-C・対応OS「Mac（Apple Vision Proにも対応）」、バッファロー BSKBW355BKが「USB-A（2.4GHzワイヤレスレシーバー）」、Keychron B1 Proが「2.4GHzワイヤレス／Bluetooth 5.2／有線」、ロジクール G213rが有線と記載されています。複数の方式に対応した機種は、使う機器に合わせて切り替えられる点を確認しましょう。

2. 配列（JIS配列・US配列）

配列は、キーの数や並びの規格です。一般的に、日本語配列（JIS配列）は、かな入力を印字したキーや、変換キーなどを備え、US配列は、キーの数が少なくシンプルな並びです。仕様表では、Keychron B1 Proがレイアウト「JIS／ANSIの表記が混在」（かな印字なし）、ロジクール PEBBLE KEYS 2が日本語配列・84キー、PFU HHKB Professional HYBRID Type-Sが日本語配列、Keychron B6 ProとKeychron K2 Version2がUSレイアウトと記載されています。普段使っている配列と異なる配列を選ぶと、慣れるまでに時間がかかる場合があります。

3. サイズ（フルサイズ・テンキーレス・コンパクト）

数字入力用のテンキーが付いているものが「フルサイズ」、テンキーを省いたものが「テンキーレス」で、さらに小型化したコンパクトなものもあります。仕様表では、Keychron B6 Proとロジクール K295GPがフルサイズ・テンキー付き、エレコム TK-FBM120KBK/ECがテンキー付き、Keychron K2 Version2が84キー（テンキーレス）と記載されています。寸法は、バッファロー BSKBW355BKが28.6×12.1×2cm、エレコム Precisionistが約31.3×11.9×1.6cm、HHKB Professional HYBRID Type-Sが約29.4×12×4cmと記載されています。机のスペースや、持ち運ぶ頻度で選びましょう。

4. キースイッチ・キー構造

キーの構造によって、押したときの感触や音が変わる傾向があります。仕様表では、Keychron K2 Version2が「Gateron G Pro 赤軸（ホットスワップ対応）」、エレコム Precisionistが「V型パンタグラフ・キーストローク1.5mm」、エレコム TK-FBM120KBK/ECが「メンブレン」、HHKB Professional HYBRID Type-Sが「静電容量無接点方式（Type-Sのキー構造）」、ロジクール G213rが「独自のMech-domeスイッチ（メンブレン）」と記載されています。感触の好みには個人差が大きいため、構造の名称は目安として見てください。

5. マルチペアリング・電源

複数の機器を切り替えて使う場合は、登録できる台数が目安になります。ロジクール PEBBLE KEYS 2は「Easy-Switchで最大3台のデバイスをキーで切り替え」、エレコム Precisionistは「最大4台（Bluetooth 3台・USBレシーバー1台）」、HHKB Professional HYBRID Type-Sは「4台まで」と記載されています。電源は、乾電池式と充電式があり、ロジクール K295GPは単4形乾電池×2（電池寿命最大24ヶ月）、バッファロー BSKBW355BKは単4電池2本で約3年使用可能（メーカー公表値）、ロジクール MX KEYS SはUSB-C充電式と記載されています。電池寿命は使い方によって変わる目安の値です。

6. 対応OS・独自機能

対応OSは、機種ごとに異なります。ロジクール PEBBLE KEYS 2はBluetooth接続時の対応OSとして、Windows 10、11以降、macOS 11以降、iPadOS 14以降、Android OS 9.0以降、Chrome OSなどが記載されています。Keychron B1 ProはmacOS／Windows／Linux対応と記載されています。Keychron K2 Version2はMac用メディアキーが付属します。また、ロジクール MX KEYS Sにはスマートバックライト、HHKB Professional HYBRID Type-Sにはキーマップ変更機能が記載されています。

04使い方別の考え方

パソコンとタブレットを切り替えて使いたい

Bluetoothに対応し、複数台を登録できる機種を確認します。ロジクール PEBBLE KEYS 2やエレコム TK-FBM120KBK/ECのように、マルチペアリングに対応した機種があります。対応OSも、機器ごとに確認してください。

数字入力が多い

テンキー付きのフルサイズを検討する考え方があります。ロジクール K295GP、エレコム TK-FBM120KBK/EC、Keychron B6 Proがテンキー付きと記載されています。机が狭い場合は、本体の寸法も確認しましょう。

持ち運んで使いたい

薄型・軽量の機種を検討します。ロジクール PEBBLE KEYS 2は重量415g、エレコム Precisionistは薄い部分で約9mmと記載されています。持ち運ぶ頻度が高い場合は、電源方式（乾電池式か充電式か）もあわせて確認します。

キーの感触にこだわりたい

キーの構造（メンブレン、パンタグラフ、シザー、メカニカル、静電容量無接点など）の違いを、仕様表で確認します。Keychron K2 Version2のようにホットスワップ対応の機種は、スイッチの交換に対応していると記載されていますが、交換できるスイッチの種類や手順は、取扱説明書の案内に従う必要があります。

ゲームで使いたい

有線接続や、ライティング機能を備えた機種があります。ロジクール ゲーミングキーボード G213rは有線接続・LIGHTSYNC RGB・着脱式パームレスト付属と記載されています。接続の遅れが気になる場合は、無線より有線を検討する考え方があります。

07場面別の選び方

タイピング音が気になる環境で使う

音の大きさをdBで示した記載は、上の仕様表の範囲では見当たりません。そのため、メーカーが名称や特徴で示している情報を手がかりにします。エレコム TK-QT11FMMABKは製品名に「静音フルキーボード」とあり、エレコム Leggeroは「静音赤軸」のメカニカルスイッチと記載されています。ただし、実際の音の感じ方は、机の素材や打ち方でも変わります。

机が狭く、マウスを動かす場所を確保したい

幅の数値を見比べます。仕様表では、ロジクール G512 X 75（テンキーレス）が330.2mm、Alto Keys K98MOW（98キー）が401mm、エレコム Leggero（108キー）が約446mm、バッファロー BSKBU115BK（109キー）が44cmと記載されています。マウスを使う側の余白を広げたいなら、キー数を絞った小さい配列を検討する考え方があります。マウス側の選び方はワイヤレスマウスの選び方ガイドをご覧ください。

数字入力は多いが、キーボード本体はコンパクトにしたい

テンキーを別体にする方法があります。エレコム ワイヤレステンキー TK-TDM017BKは20キー、幅90×奥行140×高さ26.5mm、約107g（電池を含まず）と記載されています。必要なときだけ手元に引き寄せて使えます。ただし、対応OSとして記載があるのはWindowsのみ（Windows 11/10/8.1/7/XP）で、Macでの利用は商品ページから確認できません。

ゲームでキーの反応や入力設定を重視する

ゲーミング向けの商品は、レポートレートやアクチュエーションポイントの記載が目安になります。ロジクール G316 X 98は有線で最大8,000Hz、アクチュエーションポイント1.9mmと記載されています。G512 X 75は、ラピッドトリガー、アクチュエーションポイント調整、マルチポイントアクションなどの機能が記載されています。エレコム Leggeroは最大1,000Hz、Nキーロールオーバー対応です。細かな設定にはソフト（Logicool G HUBなど）が必要と記載されている機能もあるため、対応OSを確認しましょう。

スイッチやキーキャップを自分で替えたい

ホットスワップ対応の記載がある商品が候補です。G316 X 98、Keychron K6 Ultra、Keychron K3 HE、Alto Keys K98MOW（Marble Switch）が、ホットスワップ対応と記載されています。G512 X 75は、スイッチ引き抜き工具、キーキャップ引き抜き工具、磁気アナログスイッチ9個などが付属と記載されています。交換できる種類と作業の手順は、取扱説明書やメーカーの案内に従ってください。

パソコン・タブレット・スマホで1台を使い回したい

接続先を切り替えられる台数と、機器ごとの接続方式を確認します。エレコム TK-QT11FMMABKは最大3台で、初期設定はCH1・CH2がBluetooth、CH3がUSB2.4GHz無線と記載されています。iOS・iPadOS・AndroidはBluetooth接続のみ、という注記もあります。Keychron K6 UltraはBluetoothで3台接続、Alto Keys K98MOWはEasy-Switchで最大3台と記載されています。タブレット側の選び方はタブレットの選び方ガイドもご覧ください。

電池交換や充電の手間を減らしたい

電源の方式で考えます。有線のエレコム LeggeroはUSBバスパワー、バッファロー BSKBU115BKは有線のUSB Type-A接続のため、電池や充電の管理は不要です。無線では、エレコム TK-QT11FMMABKが単4形2本で最長約2年6カ月（アルカリ乾電池使用時の目安）、Alto Keys K98MOWはUSB-C充電式でワイヤレスで12ヵ月使用可能（バックライトオフ）と記載されています。いずれも使い方によって変わる目安です。

キー割り当てや動作を細かくカスタマイズしたい

専用ソフトの記載を確認します。Keychron K6 UltraはオープンソースのZMKを採用し、Keychron Launcher（Webアプリ）でカスタマイズできると記載されています。Alto Keys K98MOWはLogi Options+（キー割り当てのカスタマイズ、Smart Actions）、G512 X 75はロジクール G HUBが記載されています。設定ソフトが対応するOSや、使える機能の範囲は商品ごとに異なります。

08キーボードの仕様表の用語

キーボードの仕様表でよく目にする言葉を、見るときのポイントとあわせてまとめました。

用語意味スペック表で見るときのポイント

ガスケットマウントキーボードの内部で、プレートや基板を弾性のある部材で支える構造打鍵時の振動の伝わり方に関わるとされる。感触は個人差が大きいため、構造の名称を目安にする

18よくある質問

Q.BluetoothとUSBレシーバーは、どちらがよいですか？

どちらが優れているとは一概に言えません。Bluetoothは、USBポートを使わずに接続でき、複数の機器を切り替えられる機種があります。USBレシーバー（2.4GHz）は、パソコン側にBluetoothがなくても使えます。使う機器の台数や、USBポートの空きに合わせて選ぶのが一般的です。

Q.JIS配列とUS配列は、どう選べばよいですか？

普段使っているキーボードの配列に合わせるのが一般的です。日本語配列（JIS配列）は、かな入力や変換キーを備え、US配列は、キーの数が少なくシンプルな並びです。慣れていない配列を選ぶと、打ち間違いが増える場合があるため、商品名や仕様表の「レイアウト」「配列」の記載を購入前に確認してください。

Q.メカニカルと、メンブレン・パンタグラフ式の違いは何ですか？

キーの構造の違いで、押したときの感触や音、厚みが変わる傾向があります。一般的に、メカニカルはキーごとに独立したスイッチを持ち、パンタグラフ式やシザー式は薄型の機種に多く、メンブレンはゴムの膜を押して入力する構造とされます。感触の好みは個人差が大きいため、用途や置き場所と合わせて判断してください。

Q.電池式と充電式は、どちらを選べばよいですか？

電池式は、電池を交換すれば使い続けられる点、充電式は電池を買い足さずに済む点が特徴です。当サイトの仕様表では、バッファロー BSKBW355BKが単4電池2本で約3年使用可能（メーカー公表値）、ロジクール MX KEYS SがUSB-C充電式と記載されています。電池寿命は使い方によって変わる目安の値です。

Q.ホットスワップ対応とは何ですか？

一般的に、はんだ付けをせずに、キースイッチを交換できる構造のことです。当サイトの仕様表では、Keychron K2 Version2が「Gateron G Pro 赤軸（ホットスワップ対応）」と記載されています。交換できるスイッチの種類や、交換の手順は、取扱説明書やメーカー情報に従ってください。

Q.アクチュエーションポイントが小さいほうが良いのでしょうか？

数値が小さいほど浅い位置で入力される傾向がありますが、そのぶん意図しない入力も起きやすくなります。当サイトの仕様表では、エレコム Leggeroが2.0mm、ロジクール G316 X 98が1.9mmと記載されています。打ち方や用途によって合う数値は異なるため、数値は目安として見てください。

Q.レポートレートは数字が大きいほど良いのでしょうか？

数字が大きいほど、入力の情報を送る頻度が多いことを示します。当サイトの仕様表では、G316 X 98が有線で最大8,000Hz、エレコム Leggeroが最大1,000Hz、Keychron K6 Ultraが2.4GHzワイヤレスで1000Hzと記載されています。ただし、実際の使い勝手は接続方式やパソコン側の環境にも左右されます。どの接続での値かを確認してください。

Q.ガスケットマウントとは何ですか？

一般に、キーボード内部のプレートや基板を、弾性のある部材で支える構造とされています。当サイトでは、ロジクール G316 X 98、G512 X 75、Alto Keys K98MOW、Keychron K6 Ultraに、ガスケットに関する記載があります。打鍵の感触や音への影響には個人差があり、名称だけで判断することはできません。

Q.対応OSに書かれていないOSでも使えますか？

使えるかどうかは、商品ページの記載だけでは判断できません。たとえばエレコムのテンキー TK-TDM017BKは、対応OSとしてWindowsのみが記載されています。TK-QT11FMMABKは、iOS・iPadOS・AndroidではBluetooth接続のみ対応という注記があります。使うOSの記載が見当たらない場合は、メーカーに問い合わせるのが確実です。

Q.保証期間は、どの商品も同じですか？

商品によって異なります。当サイトのメーカー仕様では、Alto Keys K98MOWが2年間無償保証、エレコム Leggeroとエレコム TK-QT11FMMABKが1年間、エレコム ワイヤレステンキーが6カ月間と記載されています。ロジクール G512 X 75は、型番末尾にdが付く商品は1年（dなしは2年）と書かれているため、型番で確認が必要です。

Q.テンキー付きとテンキーなしで、横幅はどれくらい違いますか？

当サイトの商品ページで、ページに「テンキー付き」と書かれた7台の横幅は401〜446mm（中央値440）、テンキーレスまたはキー数90以下と書かれた5台は279〜330.2mm（中央値296）で、中央値の差は144mmでした（筆者の計算）。机の使える幅を600mmと仮定すると、マウス側の残りは中央値の比較で160mmと304mmです。寸法の測り方（スタンドを含むかなど）は商品ごとに違うため、購入前に商品ページの寸法の注記を確かめてください。

Q.電池の持続が「8カ月」と書かれていても、同じ長さと考えてよいですか？

同じとは限りません。エレコム TK-FBM120KBKは「約8カ月（アルカリ乾電池使用時、1日8時間のパソコン操作を想定）」、Keychron B1 Pro・B6 Proは「最大8ヶ月（1日5時間使用時、最大1200時間）」と、1日の使用時間の前提が違います。8ヶ月×30日×5時間で1,200時間になり、同じ1日8時間で使うと仮定するとB1 Proは150日（約5.0カ月）です（筆者の計算）。月・年だけが書かれた8台は、1日の使用時間が分からないため、この換算ができません。

Q.キーボードの重さは、電池やケーブルを含んでいますか？

商品ごとに違い、書かれていない場合もあります。質量が書かれた16台のうち、条件の記載がないのは8台、電池含まずが3台（バッファロー BSKBW355BKは「本体 約275g（電池含まず）」など）、ケーブル含まず・除くが3台（エレコム Leggeroは「約1,055g（ケーブル含まず）」など）、電池含むが2台（ロジクール K295GPは「重量（電池を含む） 498g」など）でした。乾電池式の商品を並べるときは、電池の有無をそろえて読んでください。
