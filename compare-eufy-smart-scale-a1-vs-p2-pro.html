02違いのまとめ

  • 測定項目は、A1が12項目（体重、体脂肪率、BMI、筋肉量など）、P2 Proが16項目（体脂肪率・BMI・心拍数・筋肉量・基礎代謝量・内臓脂肪など）と記載されています。A1のページには、内臓脂肪レベルなどより詳細な項目は非対応とあります。
  • 接続は、メーカー公開仕様の欄で、A1がBluetooth（Wi-Fi非対応）、P2 ProがWi-FiとBluetoothと記載されています。
  • サイズと重量は、A1が約26×26×2.3cmで約1.1kg、P2 Proが約28×28×2.6cmで約1.2kgと記載されています。
  • 電源は、A1が単4形電池×3（付属の電池は試用用）、P2 Proが単4形アルカリ乾電池×4本（付属）と記載されています。防水は、A1のページに「防水ではない」、P2 Proのページに「IPX5」と記載されています。
  • アプリ連携は、P2 ProがApple ヘルスケアとFitbit、A1がApple ヘルスケア、Google Fit、Fitbitと商品ページに記載されています。A1のページのメーカー公開仕様の欄には、Eufyアプリ（新）はGoogle Fitに非対応とも記載されています。P2 Proのページには、登録人数に制限なし、ベビーモードとペットモードありと記載されています。
  • 計量範囲と刻みは、Eufy Smart Scale A1のページに「測定範囲5〜150kg」「精度は5〜75kgで±200g、75〜150kgで±400g」、Eufy Smart Scale P2 Proのページに「計量範囲0.1kg〜150kg」「最小表示は50g／100g／200g単位（体重帯で変わる）」と記載されています。項目名が異なるため（精度と最小表示）、数値をそのまま比べることはできません。
  • 年齢についての注意は、Eufy Smart Scale A1のページに「16歳未満は体組成の値が不正確なことがある」、Eufy Smart Scale P2 Proのページに「16歳未満は体脂肪などの測定精度が下がる場合があり、13歳未満は体重のみ測定可能」と記載されています。
  • 保証と付属品は、Eufy Smart Scale P2 Proのページに「18か月保証＋6か月（Ankerへの会員登録後）」、付属品が本体・単4形アルカリ乾電池4本・取扱説明書・測定テープと記載されています。Eufy Smart Scale A1のページには、保証の記載がなく、付属品はお試し用の乾電池の記載があります。

03こんな人にはこちら

▸Eufy Smart Scale A1が向いている人

A1のページでは、体重や体脂肪率など12項目を測定する、約1.1kgのコンパクトなBluetooth接続の体組成計と説明されています。

  • 体重だけでなく体脂肪率や筋肉量もまとめて記録したい人
  • Bluetoothで専用アプリに測定結果を記録したい人
  • 脱衣所などに収納しやすいコンパクトな体組成計を探している人

▸Eufy Smart Scale P2 Proが向いている人

P2 Proのページでは、心拍数・基礎代謝量・内臓脂肪などを含む16項目を測定し、Wi-FiとBluetoothに対応する体組成計と説明されています。

  • 体重・体組成の記録を、自動で残したい人
  • アプリで、測定データを一元管理したい人
  • Fitbitなど、ほかの記録アプリと連携したい人

04場面別の選び方

使う場面ごとに、各商品ページの記載で見ておきたい点をまとめました。あくまで掲載情報にもとづく目安です。

  • 洗面所やすき間に置いて、収納もしたいなら：メーカー公開仕様の欄では、Eufy Smart Scale A1が約26×26×2.3cmで約1.1kg、Eufy Smart Scale P2 Proが約28×28×2.6cmで約1.2kgと記載されています。Eufy Smart Scale A1のページには、26cm正方形・1.1kgのコンパクトサイズで脱衣所などに収納しやすい設計という説明があります。
  • 浴室の近くに置くことが多いなら：Eufy Smart Scale A1のページには「防水ではない」とあり、シャワー付近や濡れた足で使わないよう書かれています。Eufy Smart Scale P2 ProのページにはIPX5と記載がありますが、浴室内には置かず、足をよく拭いてから使うよう案内されています。どちらも、乗る前に足を拭く使い方が前提です。
  • 家族で使い、子どもやペットも記録したいなら：Eufy Smart Scale P2 Proのページには、登録人数に制限はなく、ベビーモードとペットモードがあると記載されています。Eufy Smart Scale A1のページには、アプリ上で複数人分のデータを管理できるとされ、登録人数の上限はAmazon商品ページで確認するよう書かれています。どちらも、16歳未満は体組成の数値の精度が下がるとの注意があります。
  • 心拍数や基礎代謝量も記録したいなら：Eufy Smart Scale P2 Proのページの仕様表に、心拍数、基礎代謝量、内臓脂肪などを含む16項目と記載されています。Eufy Smart Scale A1のページには、測定は12項目で、内臓脂肪レベルなどより詳細な項目は非対応とあります。
  • 電池を用意する手間を減らしたいなら：Eufy Smart Scale P2 Proのページには、単4形アルカリ乾電池4本が付属と記載されています。Eufy Smart Scale A1のページには、単4形電池3本が必要で、付属はお試し用のため寿命が短く、早めの交換が必要になる場合があると書かれています。

05スペック用語のかんたん解説

比較表に出てくる用語を、一般的な意味で簡単に説明します。数値や対応の有無は各商品ページ・Amazon商品ページでご確認ください。

▸体組成の測定方式

家庭用の体組成計は、足裏の電極から微弱な電流を流し、電気の通りやすさから体脂肪率や筋肉量などを推定する方式が一般的です。Eufy Smart Scale P2 Proのページには「体内の電気抵抗をもとにした推定値で、医療目的には使えない」と記載されています。Eufy Smart Scale A1のページにも、体組成の値は推定で、診断には使えない旨があります。

▸読み出し精度と最小表示

読み出し精度は、表示される体重値がどの程度の幅でずれうるかを示す表記です。最小表示は、表示が切り替わる刻みの細かさを示します。Eufy Smart Scale A1のページは「精度」、Eufy Smart Scale P2 Proのページは「最小表示」で記載されているため、同じ基準では比べられません。

▸IPX5

IPコードのうち、水に対する保護等級を示す表記です。5は、あらゆる方向からの噴流水に対する保護を指す区分とされています。Eufy Smart Scale P2 Proのページに「IPX5」と記載があります。Eufy Smart Scale A1のページには「防水ではない」と書かれており、等級の記載はありません。

▸基礎代謝量と内臓脂肪

基礎代謝量は、安静にしているときに体が使うエネルギー量の推定値を指す一般的な言葉です。内臓脂肪は、内臓のまわりについた脂肪の量や指標を指します。どちらもEufy Smart Scale P2 Proのページの測定項目に記載があり、Eufy Smart Scale A1のページには内臓脂肪レベルなどは非対応とあります。数値は目安で、医療目的には使えません。

▸Health ConnectとGoogle Fit

Health Connectは、Android端末で、複数のアプリの健康データをやり取りするための仕組みの名称です。Eufy Smart Scale P2 Proのページには、Google Fitのサードパーティ連携は2025年6月30日で終了し、Health Connectアプリの利用が必要と記載されています。Eufy Smart Scale A1のページには、Eufyアプリ（新）はGoogle Fitに非対応で、旧Eufy Lifeアプリを使うと記載されています。

06購入前のチェックリスト

購入前に見ておくと安心な項目です。各商品ページの記載にもとづくため、最終的にはAmazon商品ページの最新情報もご確認ください。

  • 置き場所：Eufy Smart Scale A1のページには硬く平らな床で使う旨、Eufy Smart Scale P2 Proのページには平らで硬い床が向き、カーペットの上では数値が安定しないことがあると記載されている。
  • 電池：Eufy Smart Scale A1は単4形電池3本、Eufy Smart Scale P2 Proは単4形アルカリ乾電池4本。Eufy Smart Scale A1の付属電池はお試し用で、早めの交換が必要になる場合がある。
  • 体の状態：どちらのページにも、妊娠中の方や、ペースメーカーなど体内に埋め込む医療機器を使っている方は使用を避ける（または医師に相談する）旨の記載がある。
  • 年齢：16歳未満は、どちらも体組成の測定精度が下がる場合がある。Eufy Smart Scale P2 Proは13歳未満が体重のみの測定になる。
  • アプリと連携先：Eufy Smart Scale A1のページには、Google Fit以外の外部アプリとの連携は確認できていないと記載され、Eufyアプリ（新）はGoogle Fitに非対応とある。Eufy Smart Scale P2 ProのページにはApple ヘルスケアとFitbit連携が記載されている。使いたい連携先がある場合は、メーカーの案内で確認する。
  • 測定のしかた：体組成の数値は、測るタイミングで変動する。同じ時間帯、素足、同じ置き場所で続けると、変化を見やすい。

07よくある質問

Q.Eufy Smart Scale A1とP2 Proの主な違いは何ですか？

各商品ページの記載では、測定項目がA1は12項目、P2 Proは16項目です。接続はA1がBluetooth（Wi-Fi非対応）、P2 ProがWi-FiとBluetooth、サイズはA1が約26×26×2.3cm、P2 Proが約28×28×2.6cmと記載されています。

Q.内臓脂肪や心拍数を測れるのはどちらですか？

P2 Proのページの仕様表に、測定項目として心拍数、基礎代謝量、内臓脂肪などが記載されています。A1のページには、内臓脂肪レベルなどより詳細な測定項目は非対応と記載されています。体組成の値は推定値で、医療目的には使えません。

Q.Google Fitと連携できますか？

A1のページの商品説明にはApple ヘルスケア、Google Fit、Fitbitと連携できると記載されています。一方、メーカー公開仕様の欄には、Eufyアプリ（新）はGoogle Fitに対応せず、旧Eufy Lifeアプリを使う旨が記載されています。P2 Proのページには、Apple ヘルスケアとFitbit連携が記載されています。購入前にメーカーの案内をご確認ください。

Q.どちらを選べばいいですか？

体重と体脂肪率、筋肉量などを記録できれば十分で、コンパクトなサイズや単4形電池3本の構成を重視するなら、A1のページが候補です。心拍数や内臓脂肪などを含む16項目、Wi-Fi接続、IPX5の防水、登録人数に制限がない点を重視するなら、P2 Proのページを確認するとよいでしょう。どちらのページにも、医療機器ではなく体組成の値は推定値である旨が記載されています。

Q.測れる体重の範囲を教えてください。

Eufy Smart Scale A1のページには、測定範囲が5〜150kgと記載されています。Eufy Smart Scale P2 Proのページには、計量範囲が0.1kg〜150kgと記載されています。どちらも耐荷重・計量範囲の上限は150kgです。

Q.乾電池は付属していますか？

Eufy Smart Scale A1のページには、お試し用の単4形乾電池3本が付属し、寿命が早く切れる場合があると記載されています。Eufy Smart Scale P2 Proのページには、単4形アルカリ乾電池4本が付属と記載されています。

Q.保証期間はどれくらいですか？

Eufy Smart Scale P2 Proのページには、18か月保証に、Ankerへの会員登録後は6か月が加わると記載されています。Eufy Smart Scale A1のページには、保証期間の記載がありません。必要な場合は、Amazon商品ページやメーカーの案内でご確認ください。

Q.子どもが乗っても測定できますか？

Eufy Smart Scale A1のページには、16歳未満は体組成の値が不正確なことがあると記載されています。Eufy Smart Scale P2 Proのページには、16歳未満は体脂肪などの測定精度が下がる場合があり、13歳未満は体重のみ測定可能と記載されています。

Q.浴室に置いて使えますか？

Eufy Smart Scale A1のページには防水ではないとあり、シャワー付近や濡れた足で使わないよう記載されています。Eufy Smart Scale P2 ProのページにはIPX5と記載がありますが、浴室内には置かず、足をよく拭いてから使うよう案内されています。

Q.使うアプリはどう違いますか？

Eufy Smart Scale A1のページには、Eufyアプリを使い、旧Eufy Lifeアプリも使えるが更新されないと記載されています。Eufy Smart Scale P2 Proのページには、Eufyアプリを使い、Apple ヘルスケアとFitbit連携に対応すると書かれています。ほかのガジェットは、ガジェット・スマホ・PCのカテゴリからもご覧いただけます。
