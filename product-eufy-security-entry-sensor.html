02結論：こんな人に向いている

Eufy Security Entry Sensorは「すでにEufy SecurityのHomeBaseを持っていて、ドアや窓の開閉検知を追加したい」人に向いたセンサーです。仕様表では取り付けタイプはサーフェスマウント、電池寿命は最大2年、商品説明ではドアや窓の開閉を検知するとHomeBaseが最大100dBの警報を鳴らし、アプリ通知でお知らせするとされています。単体では動作せず、別売りのHomeBaseとの接続が必須です。

03選び方のポイント

HomeBase接続が前提という点

商品説明には、本製品を使用するには別売りのEufy Security HomeBase 2またはHomeBase S380との接続が必要と明記されています。すでにEufy Securityのカメラなどでこれらの機器を使っている場合は追加購入なしで導入しやすく、初めて導入する場合はHomeBaseの購入もあわせて検討する必要があります。

室内専用という制限

商品説明では、防水ではないため室内でのみ使用するよう案内されています。屋外の門扉や物置などには使用できません。

取り付け時の距離の目安

商品説明では、ドアまたは窓が閉じている状態でセンサー本体とマグネットの底面の高さを揃え、間の距離が4cm未満になるように取り付けるよう案内されています。取り付け前に設置場所の形状を確認します。

電池寿命の目安

最大2年間の電池寿命とされていますが、使用環境や使用方法により異なるとされています。開閉頻度が高い場所では、電池の減りが早くなる可能性があります。

07使い方・お手入れ・注意点

  • 取り付け前の確認：ドアまたは窓を閉じた状態で、センサー本体とマグネットの高さを揃え、距離が4cm未満になる位置を確認してから取り付けます。
  • HomeBaseとのペアリング：Eufy Securityアプリの案内に従い、HomeBaseとセンサーを接続します。
  • 設置場所の制限：防水非対応のため、屋外や湿気の多い場所には設置しないでください。
  • 電池残量の確認：アプリの通知や本体の状態で、電池残量を定期的に確認します。
  • 保管・お手入れ：直射日光や高温多湿を避けて保管し、汚れは乾いた布で軽く拭き取ります。
