IP等級の読み方｜IPX4・IPX7・IP68の違い（掲載226商品の記載つき）

IP等級の数字の読み方と、2026年のJIS改正を、確認できた資料だけでまとめました。掲載した商品のメーカー記載も、等級ごとに数えています。

執筆・確認：GEARNOTE運営（H＆C）　データの時点：2026年10月31日〜11月11日（集計：2026年11月15日）

01IPコードの読み方

「IP」のあとに数字が2つ並びます。1つ目の数字は固体の異物（粉じんなど）、2つ目の数字は水の浸入に対する、外郭（筐体）の保護等級です（日本規格協会（JSA）のJIS C 0920の資料）。「IPX7」のように、1つ目の数字の場所が「X」になっている書き方は、水の等級だけを示した表記です。

  • 1つ目の数字が6：耐じん形（粉じんが内部に入らない）。
  • IPX4：あらゆる方向から10分間、散水する試験（散水孔1つあたり毎分0.07L）。
  • IPX7：水深1mに30分間、水没させる試験。
  • IPX8：IPX7より厳しい条件で、継続的に水中に沈める試験。深さや時間は、製品ごとに決められます。
  • IPX9：80±5℃の熱水を、毎分14〜16Lで、直接吹き付ける試験（2026年の改正で加わった等級です）。

IPX4は散水、IPX7は水没と、試験の方法そのものが違います。数字だけを見て優劣をつけず、どんな試験の等級なのかを読んでください。この等級が示すのは、規格に決められた試験の条件での保護です。温水・海水・洗剤など、それ以外の条件で使えるかは、取扱説明書で確認してください。

出典：JSA（IPX8・IPX9の説明）、タカチ電機工業の技術資料（PDF）（IPX4・IPX7・IPX8の試験条件は、同社の技術資料にもとづきます。規格の本文は有料のため、GEARNOTE運営は未閲覧です）。

022026年1月の改正：JIS C 0920が廃止され、JIS C 60529:2026に

日本のIPコードの規格だったJIS C 0920:2003は、2026年1月20日に廃止され、JIS C 60529:2026に移りました（JSAの規格ページ）。新しい規格では、水の等級にIPX9が加わっています。

商品の説明書には、旧規格の名前が、そのまま残っていることがあります。等級の数字そのもの（IPX4やIPX7など）の意味は、上の表のとおりです。

04同じ「防水」でも、書き方が違う例

アクションカメラは、IP等級ではなく、「水深○mまで防水」と書くことが多くあります。GEARNOTEに載せているアクションカメラ20台のうち、本体のみの防水の水深を書いているのは16台で、5〜20mでした（アクションカメラの仕様一覧）。別売りのケースを使った場合の水深は、本体のみの数字とは別に書かれています。

05出典と、確認できなかったこと

このページの事実は、2026年11月15日時点で、各ページを実際に開いて確認した公的な資料・規格団体の資料にもとづきます（リンク先は、各項目に付けています）。規格や制度は、改正されることがあります。

  • JIS C 60529:2026とIEC 60529の本文は有料のため、GEARNOTE運営は未閲覧です。試験条件は、上に挙げたJSAの資料とメーカー技術資料にもとづきます。
  • 「IPX7は、IPX5・IPX6の試験を満たす」といった、等級どうしの関係は、確認できなかったので書いていません。
  • IP68の水深・時間は、製品ごとに決められるため、数字は、商品ごとのメーカーの説明で確認してください。

07よくある質問

Q.IPX7とIPX4は、何が違いますか？

試験の方法が違います。IPX4は、あらゆる方向から10分間散水する試験、IPX7は、水深1mに30分間水没させる試験です。どちらが上かではなく、使う場面に合う試験の等級かどうかで読んでください。

Q.IP68のIPのあとの数字は、何を表しますか？

1つ目の数字（6）は固体の異物（粉じん）に対する等級で、6は耐じん形（粉じんが内部に入らない）です。2つ目の数字（8）は水の浸入に対する等級です。

Q.IPX9は、いつからありますか？

2026年1月20日にJIS C 0920が廃止され、JIS C 60529:2026に移りました。新しい規格で、水の等級にIPX9（80±5℃の熱水を毎分14〜16Lで直接吹き付ける試験）が加わっています。
