Elgato Wave XLR MK.2とWave XLR Dock MK.2の違いを比較

02違いのまとめ

  • 使い方の前提が異なります。Wave XLR Dock MK.2のページには、商品名と説明に「Stream Deck +用」と記載され、Stream Deck +と組み合わせて使う製品で、Stream Deck +の本体は別に必要とあります。Wave XLR MK.2のページには、XLRマイクを本体に接続し、付属のUSB-C to CケーブルでPCに接続する使い方が記載されており、Stream Deckとの連携に対応するとされています。
  • ファンタム電源と保護機能は、Wave XLR Dock MK.2のページの仕様表に「ファンタム電源、Clipguard 2.0テクノロジー」と記載されています。Wave XLR MK.2のページには「ファンタム電源の記載は、仕様表にありません」と書かれており、電源は「USBバスパワー」と記載されています。
  • エフェクトは、Wave XLR MK.2が「Voice Tune、コンプレッサー、EQ、エキスパンダー、ローカット」、Wave XLR Dock MK.2が「ボイスエンハンサー、コンプレッサー、EQなどを内蔵」と記載されています。どちらのページにも、Wave FXプロセッサーでDSPエフェクトとVSTを処理する旨の記載があります。
  • 対応ソフトと対応OSは、Wave XLR Dock MK.2のページに「Elgato Wave Link（Windows 11／Appleシリコン搭載Macが必要）」と記載されています。Wave XLR MK.2のページには、メーカーの仕様としてWindows 11（64ビット）以降、macOS Sonoma 14.2以降と記載されています。
  • 接続端子とサイズは、Wave XLR Dock MK.2のページに「マイク入力（メーカー表記） XLR（モノラル）」「ミックスとモニターは前面、XLRマイクは背面に接続」と記載されています。寸法は、Wave XLR MK.2が「約9.3（長さ）×11.8（幅）×7.3（高さ）cm」、Wave XLR Dock MK.2はメーカーの仕様として「115×137×76mm（D×W×H）」とページに記載されています。
  • この2商品は、同じXLRマイク用のオーディオインターフェースでも、使い方の前提が異なる別の種類の機器です。Wave XLR MK.2は単体のUSBオーディオインターフェイス＆DSPミキサーと記載され、Wave XLR Dock MK.2は「Stream Deck +用」のアクセサリーと記載されています。Wave XLR Dock MK.2のメーカー仕様には、必要なハードウェアとしてStream Deck +（別売）が挙げられています。
  • メーカー公式の仕様欄では、どちらも解像度／サンプルレートは24bit／48kHz、周波数特性（XLR入力）は20Hz - 20kHz、消費電力は最大900mAと記載されています。ダイナミックレンジは、Wave XLR MK.2が135dB、Wave XLR Dock MK.2が137dBです。
  • 接続端子は、Wave XLR MK.2がマイク（XLR）、ヘッドホン（3.5mmステレオミニジャック）、ホストI/O（USB-C）、Wave XLR Dock MK.2がマイク（XLR、モノラル）、ヘッドフォン（3.5mmジャック、ステレオ）、ホストI/O（USB-C）と、メーカーの仕様に記載されています。Wave XLR Dock MK.2はドックのUSB-CプラグでStream Deck +に直接接続し、ケーブルは不要とも書かれています。

03こんな人にはこちら

▸Wave XLR MK.2が向いている人

Wave XLR MK.2のページでは、手持ちのXLRマイクを付属のUSB-C to CケーブルでPCにつなぐUSBバスパワーのオーディオインターフェイスで、Voice Tuneなどのオンボードエフェクトとタッチミュートを備えると説明されています。

  • 手持ちのXLRマイクをUSB経由でPCに接続したい人
  • 本体側でボイスエフェクト・EQ処理をかけたい人
  • Stream Deckなど他のElgato機材と連携させたい人

▸Wave XLR Dock MK.2が向いている人

Wave XLR Dock MK.2のページでは、Stream Deck +に取り付けて使うUSB-C接続のオーディオインターフェースアクセサリーで、ファンタム電源とClipguard 2.0を備え、Wave Linkアプリで設定すると説明されています。

  • Stream Deck +を持っていて、XLRマイクも使いたい人
  • ミックスやモニターの調整を1か所で済ませたい人
  • DSPエフェクトやVSTプラグインを使いたい人

04場面別の選び方

使う場面ごとに、各商品ページの記載で見ておきたい点をまとめました。あくまで掲載情報にもとづく目安です。

  • Stream Deck +を持っていないなら：Wave XLR Dock MK.2のページには、必要なハードウェアとしてStream Deck +（別売）が挙げられ、「Stream Deck +を持っていない人」は向いていない人の欄にも入っています。Stream Deck +を使わない場合は、付属のUSB-C to CケーブルでPCにつなぐ使い方が記載されているWave XLR MK.2のページが参考になります。
  • Stream Deck +のダイヤルやボタンと同じ機材にまとめたいなら：Wave XLR Dock MK.2のページには、Stream Deck +に取り付けて使うアクセサリーで、ダイヤルなどで音量を操作する使い方が想定されると書かれています。ミックスやモニターの調整を1か所で済ませたい人向けという記載もあります。
  • ファンタム電源が必要なマイクを使うなら：Wave XLR Dock MK.2の仕様表には「ファンタム電源、Clipguard 2.0テクノロジー」、メーカーのよくある質問には48Vファンタム電源への対応が記載されています。Wave XLR MK.2のページには、ファンタム電源の記載が仕様表にもメーカーの技術仕様の表にもないと書かれています。使うマイクの電源条件は、購入前に必ず確認してください。
  • 机の上のスペースが限られているなら：メーカー仕様の寸法は、Wave XLR MK.2が93×118×73mm（D×W×H）、重量は320gです。Wave XLR Dock MK.2は115×137×76mm（D×W×H）で、重量の記載はありません。ただしWave XLR Dock MK.2はStream Deck +に装着するため、設置面積はStream Deck +本体も含めて考える必要があります。
  • Macで使う予定があるなら：Wave XLR MK.2のメーカー仕様には、Windows 11（64ビット）以降、macOS Sonoma 14.2以降と記載されています。Wave XLR Dock MK.2のページには、Wave LinkがWindows 11またはAppleシリコン搭載Macを必要とすると書かれており、Windows 10は向いていない人の欄に入っています。

05スペック用語のかんたん解説

比較表に出てくる用語を、一般的な意味で簡単に説明します。数値や対応の有無は各商品ページ・Amazon商品ページでご確認ください。

▸XLR端子

プロ用のマイクなどで広く使われる、3つのピンを持つ丸形の端子です。この種の機器では、マイク本体は別に用意して接続するのが一般的です。Wave XLR MK.2のページには「マイク本体は付属しません」、Wave XLR Dock MK.2のページには対応マイクはXLRマイクで、USBマイクは接続できないと記載されています。

▸ファンタム電源

コンデンサーマイクなどに、機器側から電力を送る仕組みです。電力が必要なマイクと、不要なマイクがあります。Wave XLR Dock MK.2のページには、ファンタム電源が不要なマイクでは必ずOFFにし、マイクを接続したままONにすることは避けるよう書かれています。

▸ゲイン（80dB）

マイクの小さな信号を、扱いやすい大きさまで増幅する量を示す値です。必要な量は使うマイクの感度によって変わります。Wave XLR MK.2のページには「最大80dB」、Wave XLR Dock MK.2のページには「80dB」と記載されています。

▸Clipguard 2.0

Wave XLR Dock MK.2の仕様表に「Clipguard 2.0テクノロジー」と記載されている名称です。一般にクリップ（音割れ）に関わる保護機能の名称として使われますが、詳しい動作は商品ページに記載がないため、メーカーの案内で確認してください。Wave XLR MK.2のページには記載がありません。

▸DSPとVSTプラグイン

DSPは音声を処理する専用の回路で、VSTは音を加工するソフトウェア部品の規格です。どちらのページにも、Wave FX ProcessorでDSPエフェクトとVSTを処理する旨が記載されています。Wave XLR MK.2のページでは、DSPエフェクトとVSTインサートを1系統で処理すると書かれています。

06購入前のチェックリスト

購入前に見ておくと安心な項目です。各商品ページの記載にもとづくため、最終的にはAmazon商品ページの最新情報もご確認ください。

  • Stream Deck +の有無：Wave XLR Dock MK.2は、Stream Deck +（別売）が必要と記載されている。すでに持っているか、同時に用意するかを先に決める。
  • 取り付け可能な機種：Wave XLR Dock MK.2のメーカー仕様に、Stream Deck + XLには装着できないと記載がある。手元のStream Deckの型を確認する。
  • マイクの種類：どちらもXLRマイクが前提で、マイクは付属しない。USBマイクはWave XLR Dock MK.2に接続できない。
  • ファンタム電源：マイクが電源を必要とするか、仕様を確認する。Wave XLR MK.2は仕様表に記載がないため、Amazon商品ページとメーカーの案内で確かめる。
  • PCの条件：Wave XLR MK.2はWindows 11（64ビット）以降またはmacOS Sonoma 14.2以降、Wave XLR Dock MK.2はWindows 11またはAppleシリコン搭載Mac（Wave Link）と記載されている。
  • USB-Cポートと付属品：Wave XLR MK.2は150cmのUSB-C to Cケーブルが付属。Wave XLR Dock MK.2はドックのUSB-CプラグでStream Deck +に直接接続する。

07よくある質問

Q.Wave XLR MK.2とWave XLR Dock MK.2の主な違いは何ですか？

各商品ページの記載では、Wave XLR Dock MK.2はStream Deck +に取り付けて使うアクセサリーで、仕様表にファンタム電源とClipguard 2.0が記載されています。Wave XLR MK.2はUSBバスパワーで、付属のUSB-C to CケーブルでPCにつなぐ単体のオーディオインターフェイスとして記載されています。どちらもゲインは80dBと記載されています。

Q.Stream Deck +がなくても使えますか？

Wave XLR Dock MK.2のページには「Stream Deck +用」と記載があり、Stream Deck +と組み合わせて使う製品で、Stream Deck +の本体は別に必要とされています。Wave XLR MK.2のページにはStream Deckとの連携に対応と記載されていますが、Stream Deckが必須とは書かれていません。

Q.ファンタム電源に対応していますか？

Wave XLR Dock MK.2のページの仕様表には、ファンタム電源の記載があります。Wave XLR MK.2のページには、ファンタム電源の記載は仕様表にないと書かれています。使うマイクがファンタム電源を必要とする場合は、購入前にAmazon商品ページとメーカーの仕様をご確認ください。

Q.対応OSに違いはありますか？

Wave XLR Dock MK.2のページには、Wave LinkがWindows 11またはAppleシリコン搭載Macを必要とすると記載されています。Wave XLR MK.2のページには、メーカーの仕様としてWindows 11（64ビット）以降、macOS Sonoma 14.2以降と記載されています。お使いのPCの環境をご確認ください。

Q.どちらを選べばいいですか？

Stream Deck +をすでに使っていて、ミックスやモニターの調整もまとめたい場合は、Wave XLR Dock MK.2のページの記載が参考になります。Stream Deck +を使わず、USBでPCにつなぐ単体のインターフェイスを探す場合は、Wave XLR MK.2のページが参考になります。マイクの種類や接続方式はマイクの選び方ガイドにまとめています。各商品ページはWave XLR MK.2とWave XLR Dock MK.2です。

Q.2商品は同じ種類の製品ですか？

どちらもXLRマイクをつなぐオーディオインターフェース機能を持つと記載されていますが、種類は異なります。Wave XLR MK.2は単体のUSBオーディオインターフェイス＆DSPミキサー、Wave XLR Dock MK.2はStream Deck +に取り付けるアクセサリーとして記載されています。そのため、同じ用途の代わりとしてではなく、持っている機材や使い方に合わせて比べる製品です。

Q.Wave XLR Dock MK.2はStream Deck + XLにも装着できますか？

Wave XLR Dock MK.2のメーカー仕様には「Stream Deck + XLには装着できません」と記載されています。対象はStream Deck +で、Stream Deck +の商品ページもあわせてご確認ください。

Q.ゲインと周波数特性に違いはありますか？

ゲインは、Wave XLR MK.2が最大80dB、Wave XLR Dock MK.2が80dBと記載されています。メーカーの仕様では、周波数特性（XLR入力）はどちらも20Hz - 20kHzです。Wave XLR Dock MK.2には「最大ゲイン偏差」が0.3dB未満という記載もあります。

Q.ダイナミックレンジとサンプルレートは同じですか？

解像度／サンプルレートは、どちらも24bit／48kHzとメーカー仕様に記載されています。ダイナミックレンジは、Wave XLR MK.2が135dB、Wave XLR Dock MK.2が137dBです。等価入力雑音（EIN）と最大入力レベルはWave XLR MK.2のページにのみ記載があり、Wave XLR MK.2はそれぞれ-130dB、6dBVです。

Q.ヘッドホンやモニター用の出力はありますか？

メーカー仕様では、Wave XLR MK.2にヘッドホン（3.5mmステレオミニジャック）、Wave XLR Dock MK.2にヘッドフォン（3.5mmジャック、ステレオ）の端子が記載されています。Wave XLR Dock MK.2のページには、ミックスとモニターは前面、XLRマイクは背面に接続するとあります。

Q.付属品の違いは何ですか？

Wave XLR MK.2は、本体、USB-C to Cケーブル（150cm）、ユーザーマニュアルがAmazonの仕様表に記載され、メーカー仕様ではクイックスタートガイドが挙げられています。Wave XLR Dock MK.2は、メーカー仕様に「Stream Deck +用XLRドックとクイックスタートガイド」と記載されており、ケーブルは不要とされています。

Q.ソフトウェアはどちらも同じですか？

Wave XLR Dock MK.2のページには、対応ソフトとしてElgato Wave Linkが記載されています。Wave XLR MK.2のメーカー仕様にも、ソフトウェアとしてWave Link（無料）と記載されています。対応するOSの条件は、Wave XLR MK.2がWindows 11（64ビット）以降／macOS Sonoma 14.2以降、Wave XLR Dock MK.2がWindows 11／Appleシリコン搭載Macです。
