リュック・バックパックの選び方ガイド｜容量・PC収納・サイズ・重量・撥水・背面のつくりの見方

リュックの仕様表には、「容量19ℓ」「W290×H430×D160mm」「945g」「15inch PC対応」「B4サイズ」「2気室」「撥水加工」「背面長 S42cm／M48cm」などが並びます。何を入れて持つか（PC・書類・水筒・着替え）と、どのくらいの距離を背負うか（通勤・通学・旅行・山歩き）で、見るべき項目が変わります。このページでは、当サイトの商品ページに載っている仕様の数値をもとに、リュックの種類、見る項目と読み方、使う場面別の考え方を整理しました。耐荷重や使い方の注意は、必ず各商品の取扱説明書とメーカーの案内に従ってください。財布や小物の選び方は財布・カードケース・キーケースの選び方ガイド、肩掛けのバッグはショルダーバッグ・トートバッグの選び方ガイドも参考になります。

01まず知っておきたいリュックの種類

リュックは、使う場面と容量で大きく分けられます。以下は一般的な説明で、実際の機能は商品ごとに異なります。

タイプ容量の目安（一般的な傾向）一般的な特徴気をつけたい点

スポーツ・通学向けの大容量25〜35L前後シューズやボールの収納スペースを備える商品がある容量が大きいぶん、荷物を詰めすぎると重くなる

どのタイプが優れているかではなく、毎日入れる荷物の量と、背負う時間に合わせて選ぶのが一般的です。

02スペック表で見る7つのポイント

1. 容量（L／ℓ）

容量は、入れられる荷物の量の目安です。同じ容量でも、形によって入れやすさは異なります。仕様表やメーカー公開仕様では、Kanana project PJ8-3rd フリーウェイリュックが8L、Kanana project PJ1-4thが7L、Kanana project PJ-14 2wayリュックが9L、Kanana project エブリーリュック 31662が15L、ace.GENE ガジェタブルRが14L、PORTER インタラクティブ デイパックが16ℓ、PORTER プラン リュックサックが17ℓ、PORTER タイム リュックが19ℓ、PORTER ユニオン 2WAYリュックサックが24ℓ、Karrimor cleave 30が30Lと記載されています。

2. 外寸と重量

外寸は、荷物が入るかと、見た目の大きさの目安になります。重量は、荷物を入れる前の本体の重さです。仕様表では、Kanana project PJ1-4thが490g、PJ8-3rdが540g、PORTER プランが630g（W270×H380×D140mm）、ace.GENE ガジェタブルRが900g（W28×H39×D12cm）、PORTER タイムが945g（W290×H430×D160mm）、ace.GENE ガジェタブルヘザー2が1150gと記載されています。

3. PC・書類の収納（インチ・A4・B4・B5）

PC対応サイズは、ノートPCの画面サイズ（インチ）で示されます。書類は、A4・B4・B5などの判型で示されます。仕様表では、ace.GENE ガジェタブルRが14.0インチ対応（参考収納寸法 W33×H24×D2.5cm）・A4ファイル収納、ace.GENE ラグレンティスが14.0インチ対応・A4ファイル収納（参考 31.3×23.1cm）、ace.GENE ガジェタブルヘザー2が15.6インチ対応・B4ファイル収納、PORTER タイムとPORTER インタラクティブが15inch PC対応、Kanana project PJ8-3rdがB5、エブリーリュック 31662がA4と記載されています。

4. 気室の数と開閉方式

気室は、荷物を仕切って入れられる空間の数です。開閉方式は、出し入れのしやすさに関わります。仕様表では、ace.GENE ラグレンティス・ガジェタブルR・ガジェタブルヘザー2が2気室、Kanana project エブリーリュック 31662とPJ8-3rdが1気室、PORTER ユニオン 2WAYがラウンド式ダブルファスナー（3辺フルオープン）、Karrimor cleave 30がロールトップ（容量調整可能）とフロントアクセスと記載されています。

5. ポケット・ボトルホルダー

ペットボトルや折りたたみ傘の収納場所があるかは、毎日の使いやすさに関わります。仕様表では、PORTER インタラクティブが外装3・内装11のポケット（ペン1、PC1、ペットボトルホルダー2を含む）、PORTER タイムが内装にペットボトルや折り畳み傘を収納できるササマチポケット、PUMA バズ バックパックが傘用とウォーターボトル用のサイドメッシュポケット、Ponbaby マザーズリュック 23Lがポケット数16と記載されています。

6. 素材と撥水加工

素材名と加工名は、お手入れや雨の日の使い方の目安になります。撥水加工の記載があっても、完全に水を防ぐとは限りません。仕様表では、PORTER プランが表地ナイロンツイル（弱撥水加工・裏面PVCコーティング）、PORTER タイムがコーデュラナイロンツイル（テフロンファブリックプロテクター加工・PVC加工）、PORTER インタラクティブが表ポリエステルオックス（表面：撥水加工、裏面：TPU加工）、Kanana project PJ1-4thが撥水加工生地、ace.GENE ガジェタブルヘザー2が撥水、Ponbaby マザーズリュックが撥水剤加工と記載されています。

7. 背負いやすさに関わる装備（ベルト・背面長・チェストベルト）

ベルトの長さ調節や、チェストベルトの有無は、背負い心地の好みに関わります。仕様表では、PORTER タイムが背負いベルト約43〜88cmで長さ調節可、PORTER ユニオン 2WAYがベルト長さ〜91cm・持ち手長さ39cm、ace.GENE ガジェタブルヘザー2とガジェタブルRが取り外せるチェストベルト付き、Karrimor cleave 30が背面長S 42cm／M 48cm（ワンタッチバックルのチェストストラップ・取り外し可能なヒップベルト）と記載されています。

07使う場面別の選び方

通勤でPCと書類を持ち歩きたい

PC対応サイズと書類の判型が合うかを先に確認します。PORTER タイムは15inch PC・B4対応、ace.GENE ガジェタブルヘザー2は15.6インチ・B4対応、ace.GENE ガジェタブルRは14.0インチ・A4対応と記載されています。重量も、ガジェタブルRの900gからガジェタブルヘザー2の1150gまで差があります。

身軽に、小物とA4・B5の書類だけ持ちたい

小型のリュックが候補です。Kanana project PJ1-4th（7L・490g）、PJ8-3rd（8L・540g）、エブリーリュック 31661（11L・約550g）が、B5サイズを収納できる目安として記載されています。

リュックとトートを切り替えたい

2WAYタイプを確認します。Kanana project PJ-14はリュック・トートの2way（エキスパンド時W42cm）、PORTER ユニオン 2WAYはリュック／トートの2WAYで、ベルト長さ〜91cm・持ち手長さ39cmと記載されています。

荷物の量に合わせて、容量を変えたい

容量拡張や調整の仕組みを確認します。ace.GENE ラグレンティスは19/24L（エキスパンダブル）、ガジェタブルヘザー2は19/23L、Karrimor cleave 30はロールトップで容量調整可能と記載されています。

山歩きやハイキングに使いたい

Karrimor cleave 30は、30L・ロールトップ・チェストストラップ・取り外し可能なヒップベルトと背面長（S 42cm／M 48cm）が記載されています。Columbia キャッスルロック 25Lは、収納式レインカバー付きで、用途は登山・ハイキング・旅行・タウンユースと記載されています。背面長は体格に合うサイズを確認します。

ジムや部活で、シューズやボールも入れたい

New Balance 35Lは底部シューズ収納、NIKE フープス エリート 32Lはボール収納スペースと記載されています。Dickies アイコンロゴ 約30LやPUMA バズ 約28Lもあります。

雨の日にも使うことがある

素材名と加工名を確認します。PORTER プランは弱撥水加工、PORTER インタラクティブは表面に撥水加工、Columbia キャッスルロックは収納式レインカバー付きと記載されています。撥水加工でも、完全に水を防ぐ意味とは限りません。ファスナーまわりや縫い目から水が入ることもあります。

11失敗しやすいポイントと、安全に使うための基本

✅ こうすると失敗しにくい

  • 毎日入れる荷物（PC・書類・水筒・傘）の寸法を確認してから、容量と外寸を見る
  • PCの対応インチと、書類の判型（A4・B4・B5）が、持ち物に合うかを確認する
  • 本体の重量も確認し、荷物を入れた総重量を考える
  • 撥水加工の記載は、完全に水を防ぐ意味ではないと考えて、雨の日の使い方を決める
  • 登山用は、背面長（S／Mなど）を、体格に合わせて選ぶ

⚠️ 避けたいこと

  • 容量だけで選び、PCや書類が入る外寸・収納を確認しない
  • 荷物を詰めすぎて、ファスナーやベルトに負担をかける
  • 濡れたまま、リュックを閉じて保管する
  • 直射日光の当たる場所や、高温になる車内に置いたままにする
  • 耐荷重の記載がない商品に、重い荷物を入れ続ける

13よくある質問

Q.リュックの容量は、何Lを選べばよいですか？

毎日入れる荷物の量で考えるのが一般的です。当サイトの仕様表・メーカー公開仕様では、Kanana project PJ8-3rd（8L）、ace.GENE ガジェタブルR（14L）、PORTER プラン（17ℓ）、PORTER タイム（19ℓ）、PORTER ユニオン 2WAY（24ℓ）、Karrimor cleave 30（30L）などと記載されています。容量だけでなく、外寸やポケットの構成も確認してください。

Q.ノートPCは、どのサイズまで入りますか？

リュックごとに『対応インチ』が記載されています。当サイトの仕様表では、ace.GENE ガジェタブルRとラグレンティスが14.0インチ対応、ace.GENE ガジェタブルヘザー2が15.6インチ対応、PORTER タイムとインタラクティブが15inch PC対応と記載されています。PC本体の厚みやACアダプターも含めて確認してください。

Q.A4、B4、B5は、どう違いますか？

紙の判型です。一般的に、A4は210×297mm、B5は182×257mm、B4は257×364mmです。当サイトの仕様表では、ace.GENE ガジェタブルRがA4ファイル収納、ace.GENE ガジェタブルヘザー2がB4ファイル収納、Kanana project PJ8-3rdがB5と記載されています。書類の厚みも考えて選びましょう。

Q.エキスパンダブルとは何ですか？

マチ（奥行き）を広げて、容量を増やせる機能です。当サイトの仕様表では、ace.GENE ラグレンティスが19/24L（W28×H46×D16/20cm）、ace.GENE ガジェタブルヘザー2が19/23L（D14/18cm）、Kanana project PJ-14 2wayがエキスパンド時W42cmと記載されています。

Q.2気室とは、どういう意味ですか？

荷物を仕切って入れられる空間が2つあることです。当サイトの仕様表では、ace.GENE ラグレンティス、ガジェタブルR、ガジェタブルヘザー2が2気室、Kanana project エブリーリュック 31662とPJ8-3rdが1気室と記載されています。PCと衣類を分けたいときなどに確認します。

Q.撥水加工のリュックは、雨でも使えますか？

撥水加工は、水を弾きやすくする加工で、完全に水を防ぐ意味とは限りません。当サイトの商品ページでは、PORTER プランが弱撥水加工、PORTER インタラクティブが表面に撥水加工、Columbia キャッスルロックが収納式レインカバー付きと記載されています。大切な荷物は、袋に入れるなどの工夫をしましょう。

Q.リュックの重さは、どれくらいを目安にすればよいですか？

本体が軽いほど、荷物を入れた総重量を抑えやすい傾向があります。当サイトの仕様表では、Kanana project PJ1-4thが490g、PORTER プランが630g、ace.GENE ガジェタブルRが900g、PORTER タイムが945g、ace.GENE ガジェタブルヘザー2が1150gと記載されています。収納の仕様と合わせて比べてください。

Q.2WAYのリュックは、どう使い分けますか？

背負って運ぶ場面と、手で持つ場面を切り替えられます。当サイトの仕様表では、Kanana project PJ-14 2wayがリュック・トートの2way、PORTER ユニオン 2WAYがリュック／トートの2WAYで、ベルト長さ〜91cm・持ち手長さ39cmと記載されています。

Q.登山用のリュックで、背面長は何を見ますか？

背中側の長さの区分で、体格に合わせて選びます。当サイトの仕様表では、Karrimor cleave 30が背面長 S 42cm／M 48cm、重量 S 940g／M 950gと記載されています。ほかに、ロールトップ（容量調整可能）、チェストストラップ、取り外し可能なヒップベルトなどが記載されています。

Q.PORTER ユニオンの2つの商品は、何が違いますか？

当サイトの商品ページでは、メーカー公開仕様で、782-08690がW320×H440×D140mm・1030g・24ℓ、782-08692がW300×H420×D180mm・815g・15ℓで、かぶせタイプと記載されています。2WAYで使うのは782-08690で、ラウンド式ダブルファスナー（3辺フルオープン）と記載されています。

Q.スポーツ向けのバックパックは、何を見ればよいですか？

容量と、収納スペースの種類を確認します。当サイトの商品ページでは、New Balance 35Lが底部シューズ収納・A4対応、NIKE フープス エリート 32Lがボール収納スペース、PUMA バズ（約28L）が傘用とウォーターボトル用のサイドメッシュポケットと記載されています。荷物を詰めすぎると重くなる点にも注意してください。
