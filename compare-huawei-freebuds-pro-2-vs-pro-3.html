02違いのまとめ

  • ドライバーは、Pro2が「11mmクアッドマグネットダイナミックドライバー＋平面振動板ドライバー」、Pro 3が「ハルバッハ配列マイクロ平面振動板＋11mmダイナミックドライバー」のデュアル構成と記載されています。
  • ノイズキャンセリングは、Pro2のページに「50Hz〜3000Hzの帯域で最大-47dB」、Pro 3のページに「インテリジェント・ダイナミックANC3.0」と記載されています。Pro 3のページにはdBの数値の記載がありません。
  • ANCオン時の再生時間は、メーカー情報の欄でPro2がイヤホン4時間・ケース併用18時間、Pro 3がイヤホン4.5時間・ケース併用22時間です。ANCオフ時は、どちらも6.5時間・30時間です。
  • 重さは、メーカー情報の欄でPro2がイヤホン6.1g・充電ケース52.1g、Pro 3がイヤホン5.8g・充電ケース45.5gです。ワイヤレス充電の満充電時間（充電ケース）は、Pro2が120分、Pro 3が150分と記載されています。
  • Bluetooth 5.2、コーデック（SBC／AAC／LDAC／L2HC）、再生周波数帯域（14Hz〜48,000Hz）、IP54は、メーカー情報の欄で両機種に共通です。Pro 3のページの仕様表には、デュアルデバイス接続（iOS/Android間の切り替え対応）が記載されています。
  • 通話用のマイクは、メーカー情報の欄で、どちらも片側3マイク＋風ノイズ低減設計＋DNNと記載されています。骨伝導のセンサーは、HUAWEI FreeBuds Pro 2が「VACC」、HUAWEI FreeBuds Pro 3が「VPU」と書き分けられています。ANC用のマイク構成（片側3マイク＋風ノイズ低減設計＋REM）は、両機種で共通です。
  • 充電は、有線がどちらも「40分 / 60分（イヤホン / 充電ケース）」と記載されています。ワイヤレス充電は、HUAWEI FreeBuds Pro 2が40分 / 120分、HUAWEI FreeBuds Pro 3が40分 / 150分です。
  • 同梱物は、HUAWEI FreeBuds Pro 2のページが「イヤークッション、ケーブル」、HUAWEI FreeBuds Pro 3のページが「イヤーピース、ケーブル、取扱説明書」と記載されています。色は、HUAWEI FreeBuds Pro 2がセラミックホワイト、HUAWEI FreeBuds Pro 3がグリーンのページです。型番は、HUAWEI FreeBuds Pro 3が「FreeBuds Pro 3（Piano-T100）」と記載されています。

04場面別の選び方

使う場面ごとに、各商品ページの記載で見ておきたい点をまとめました。あくまで掲載情報にもとづく目安です。

  • 通勤中に、ノイズキャンセリングを使って長めに聴くなら：ANCオン時の再生時間は、メーカー情報の欄でHUAWEI FreeBuds Pro 2がイヤホン4時間・ケース併用18時間、HUAWEI FreeBuds Pro 3が4.5時間・22時間です。ANCオフ時は、どちらも6.5時間・30時間と記載されています。
  • オンライン会議や通話が多いなら：どちらのページにも、骨伝導の仕組みを使った通話のノイズリダクションが記載されています。メーカー情報の欄では、通話用に片側3マイクと風ノイズ低減設計を備える点が共通です。聞こえ方は使う環境で変わります。
  • パソコンとスマートフォンを切り替えて使うなら：HUAWEI FreeBuds Pro 3のページの仕様表に、デュアルデバイス接続（iOS/Android間の切り替え対応）が記載されています。HUAWEI FreeBuds Pro 2のページは、記載の表現が分かれているため、購入前にAmazon商品ページで確認が必要です。
  • 耳への負担を考えて、軽いイヤホンを選ぶなら：メーカー情報の欄で、イヤホン1個の重さはHUAWEI FreeBuds Pro 2が6.1g、HUAWEI FreeBuds Pro 3が5.8gです。充電ケースはHUAWEI FreeBuds Pro 2が52.1g、HUAWEI FreeBuds Pro 3が45.5gと記載されています。
  • 周囲の音を聞きたい場面でも使うなら：HUAWEI FreeBuds Pro 2のページに「外部音取り込みモード」の記載があります。HUAWEI FreeBuds Pro 3のページの仕様表には、外部音取り込みの記載がありません。記載がないことが、機能がないことを意味するわけではありません。

05スペック用語のかんたん解説

比較表に出てくる用語を、一般的な意味で簡単に説明します。数値や対応の有無は各商品ページ・Amazon商品ページでご確認ください。

▸LDACとハイレゾ認証

LDACは、Bluetoothで音声をより多くの情報量で送るためのコーデック（圧縮方式）のひとつです。どちらのページにも、LDAC対応とHWA／ハイレゾ認証が記載されています。実際にLDACで再生するには、スマートフォンなどの再生機器側が対応し、設定で有効になっている必要があります。

▸ANCの「最大-47dB」

ノイズキャンセリングで、騒音をどれだけ小さくできるかを示す値で、「最大」は条件がそろったときの上限を意味します。HUAWEI FreeBuds Pro 2のページに「50Hz〜3000Hzの帯域で最大-47dB」と記載されています。HUAWEI FreeBuds Pro 3のページには、dBの数値の記載がありません。

▸平面振動板とハルバッハ配列

平面振動板は、薄くて平らな振動板を使ったドライバーのことです。ハルバッハ配列は、磁石を特定の並びで組み合わせる配置方式の名前とされます。HUAWEI FreeBuds Pro 3のページに「ハルバッハ配列マイクロ平面振動板＋11mmダイナミックドライバー」と記載されています。

▸デュアルデバイス接続

2台の機器と同時に接続しておき、切り替えの手間を減らす機能です。HUAWEI FreeBuds Pro 3のページでは、iOSとAndroid間でペアリングし直さずに切り替えられる機能と説明されています。HUAWEI FreeBuds Pro 2のページは、後継モデルで追加された機能に含まれると読める記載もあり、表現が分かれています。

▸IP54

防塵と防滴の等級を示す表記です。最初の数字が防塵、次の数字が防滴の等級を表します。IP54は、粉塵の侵入を完全には防がないものの、水の飛まつを想定した区分とされています。メーカー情報の欄では、どちらも「IP54」と記載されています。

購入前に見ておくと安心な項目です。各商品ページの記載にもとづくため、最終的にはAmazon商品ページの最新情報もご確認ください。

  • 充電の記載：HUAWEI FreeBuds Pro 3の仕様表は「約40分でケース充電」だが、メーカー情報の欄では、充電ケースの有線の満充電時間が60分、イヤホンが40分と記載されている。表記が異なるため、メーカーの最新情報で確認する。
  • 接続機能の表記：HUAWEI FreeBuds Pro 2のデュアルデバイス接続は、ページ内で表現が分かれている。複数機器で使うつもりなら、Amazon商品ページで確認する。
  • 後継モデルとの違い：HUAWEI FreeBuds Pro 3のページには、空間オーディオなど最新世代の機能は搭載されていないと書かれている。機能を重視する場合は、後継モデルのページも確認する。
  • 同梱物と色：HUAWEI FreeBuds Pro 2はイヤークッション、HUAWEI FreeBuds Pro 3はイヤーピースと記載。色はページごとに異なる（セラミックホワイトとグリーン）。購入する色を確認する。

07よくある質問

Q.FreeBuds Pro2とFreeBuds Pro 3の主な違いは何ですか？

各商品ページの記載では、ドライバーの構成（Pro 3はハルバッハ配列の平面振動板）、ANCオン時の再生時間（Pro2はイヤホン4時間、Pro 3は4.5時間）、重さ（イヤホンはPro2が6.1g、Pro 3が5.8g）、ワイヤレス充電の満充電時間が異なります。Bluetooth 5.2、LDAC対応、IP54は共通です。

Q.デュアルデバイス接続はどちらが対応していますか？

Pro 3のページの仕様表には、デュアルデバイス接続（iOS/Android間の切り替え対応）と記載されています。Pro2のページは、商品説明にデュアルデバイス接続の記載がある一方で、FAQには後継モデルで追加された機能に含まれると読める記載もあり、表現が分かれています。購入前にAmazon商品ページでご確認ください。

Q.どちらも外部音取り込みモードはありますか？

Pro2のページには「外部音取り込みモード」と記載されています。Pro 3のページの仕様表には、外部音取り込みの記載がありません。

Q.どちらを選べばいいですか？

ANCの帯域と最大-47dBの数値が記載されていることや、外部音取り込みモード、ANCオフ時の再生時間を基準にするならFreeBuds Pro2のページが参考になります。デュアルデバイス接続、軽量なイヤホン、ANCオン時の長い再生時間を重視する場合はFreeBuds Pro 3のページも候補になります。ノイズキャンセリングイヤホンを横並びで見たい場合はノイズキャンセリングイヤホンの比較もご覧ください。

Q.イヤホンの重さは、どれくらい違いますか？

メーカー情報の欄では、イヤホンはHUAWEI FreeBuds Pro 2が6.1g、HUAWEI FreeBuds Pro 3が5.8g、充電ケースはHUAWEI FreeBuds Pro 2が52.1g、HUAWEI FreeBuds Pro 3が45.5gと記載されています。

Q.防水性能は同じですか？

メーカー情報の欄では、どちらも防水防塵はIP54と記載されています。水に濡れたときの扱いは、取扱説明書に従ってください。

Q.通話用のマイクに違いはありますか？

どちらも通話用に片側3マイクと風ノイズ低減設計、DNNを備えると記載されています。骨伝導のセンサーが、HUAWEI FreeBuds Pro 2は「VACC」、HUAWEI FreeBuds Pro 3は「VPU」と書き分けられています。

Q.対応するコーデックは同じですか？

メーカー情報の欄では、どちらもSBC / AAC / LDAC / L2HCと記載されています。HUAWEI FreeBuds Pro 3の仕様表は「LDACコーデック3」と書かれていますが、コーデックの一覧は両機種で共通です。

Q.ワイヤレス充電の時間を教えてください。

メーカー情報の欄では、ワイヤレス充電の満充電時間（イヤホン / 充電ケース）が、HUAWEI FreeBuds Pro 2は40分 / 120分、HUAWEI FreeBuds Pro 3は40分 / 150分と記載されています。

装着タイプやコーデックの考え方はワイヤレスイヤホンの選び方ガイドでご覧いただけます。
