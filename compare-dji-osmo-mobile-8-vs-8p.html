02違いのまとめ

  • 重量は、メーカー公開情報でOsmo Mobile 8が約370g、Osmo Mobile 8Pが約386gと記載されています。重量に含まれる付属品は、8Pがジンバル・内蔵三脚・磁気スマートフォンクランプ5・マルチファンクションモジュール2・Osmo FrameTap、8が内蔵三脚・磁気スマートフォンクランプ・マルチファンクションモジュールと、記載内容が異なります。
  • サイズは、メーカー公開情報で展開時が8は288×107×96mm、8Pは291×110×101mm、折りたたみ時が8は190×95×46mm、8Pは196×105×38mmと記載されています。
  • 8Pのページには、被写体追尾のActiveTrack 8.0（人・ペットなど）と、着脱式のリモコンOsmo FrameTap（1.4インチ・240×240のタッチスクリーン、GNSS、29g、防水ではない）の記載があります。8のページには、ActiveTrackとOsmo FrameTapの記載がありません。
  • バッテリーは、どちらもメーカー公開情報で3350mAh（12.06Wh）、動作時間は約10時間（ジンバルを水平に保ちアクセサリーなしの場合）と記載されています。延長ロッドは最大215mmまでと記載され、どちらも内蔵の延長ロッドと三脚を備えます。
  • 8Pのメーカー公開情報には、パン軸360°連続回転（最大速度120°/s）、Bluetooth 5.3、底面の1/4インチ-20 UNCポート、対応スマートフォンの厚さ6.9〜11mm、発売日2026年5月7日（ページの仕様欄）が記載されています。8のページにはパン軸360°回転と、対応スマートフォンの重量170〜300g・幅67〜84mmが記載されています。
  • 付属品は、Osmo Mobile 8のページに「ジンバル、磁気スマートフォンクランプなど」、Osmo Mobile 8Pのページに「磁気スマートフォンクランプ5、Osmo FrameTap、スマホ充電ケーブル（USB-C・15cm）、電源ケーブル（USB-C・50cm）」と記載されています。Osmo Mobile 8のページには、4つの購入オプション（スタンダード、アドバンストトラッキング、クリエイター×2）があり、コンボごとの構成は購入前に確認するよう書かれています。
  • 充電時間は、Osmo Mobile 8が10W USB-C充電器で約2.5時間、Osmo Mobile 8Pが約2.5時間（0%から100%、DJI 65W充電器、電源オフ、25℃の試験）と記載されています。使った充電器が異なるため、同じ条件の値ではありません。
  • アプリは、Osmo Mobile 8Pのページに、DJI MimoアプリがGoogle Playから削除されており、DJI公式サイトから最新版をダウンロードするよう案内されていると記載されています。Osmo Mobile 8のページには、アプリの入手についての記載がありません。

03こんな人にはこちら

▸Osmo Mobile 8が向いている人

Osmo Mobile 8のページでは、3軸の手ブレ補正、360°のパン軸回転、内蔵の延長ロッドと三脚、約10時間の動作を備え、撮影中のスマートフォンへの給電にも対応した折りたたみ式ジンバルと説明されています。

  • スマートフォンで手ブレの少ない動画を撮りたい人
  • 旅行や外出先に持ち運べるジンバルを探している人
  • 三脚や延長ロッド内蔵の1台で済ませたい人

▸Osmo Mobile 8Pが向いている人

Osmo Mobile 8Pのページでは、3軸ジンバルにActiveTrack 8.0と着脱式のOsmo FrameTapを備え、約10時間駆動・USB-Cでのスマートフォン給電にも対応したモデルと説明されています。

  • 旅行や子どもの行事など、歩きながらのスマホ動画をブレなく撮りたい人
  • 被写体を自動で追いかけてほしい人
  • 離れた位置から自撮りや集合写真を撮りたい人

04場面別の選び方

使う場面ごとに、各商品ページの記載で見ておきたい点をまとめました。あくまで掲載情報にもとづく目安です。

  • 子どもの行事やペットを、自動で追いかけて撮りたいなら：Osmo Mobile 8Pのページに、ActiveTrack 8.0（人・ペットなど）の記載があります。Osmo Mobile 8のページにはActiveTrackの記載がありません。Osmo Mobile 8Pのページには、追尾は被写体の動きの速さや周囲の明るさで変わると説明されています。
  • 少し離れた位置から構図を見ながら撮りたいなら：Osmo Mobile 8Pには着脱式のリモコンOsmo FrameTapが付属すると記載されています。メーカー公開情報には、1.4インチ・240×240のタッチスクリーン、GNSS、29g、防水ではないと記載されています。Osmo Mobile 8のページには、リモコンの記載がありません。
  • バッグの中での薄さを重視するなら：折りたたみ時のサイズは、メーカー公開情報でOsmo Mobile 8が190×95×46mm、Osmo Mobile 8Pが196×105×38mmと記載されています。Osmo Mobile 8Pのほうが厚みは小さく、縦と横は大きい数値です。重量はOsmo Mobile 8が約370g、Osmo Mobile 8Pが約386gですが、含まれる付属品の内訳が異なります。
  • ケース付きのスマートフォンを載せたいなら：対応スマートフォンは、どちらもメーカー公開情報で重量170〜300g、幅67〜84mmと記載されています。厚さはOsmo Mobile 8Pのみ6.9〜11mmと記載されています。ケースを付けた状態で測り、範囲に収まるか確認します。
  • 追尾をオンにして長時間撮りたいなら：動作時間は、どちらも約10時間（ジンバルを水平に保ちアクセサリーなしの場合）と記載されています。インテリジェントトラッキングをオンにすると、約5時間、フィルライト最大で約4時間と短くなる旨が、どちらのメーカー公開情報にもあります。

05スペック用語のかんたん解説

比較表に出てくる用語を、一般的な意味で簡単に説明します。数値や対応の有無は各商品ページ・Amazon商品ページでご確認ください。

▸3軸ジンバル

スマートフォンを、上下の傾き、左右の向き、横の傾きの3方向でモーターが支え、手ブレを抑える仕組みです。歩きながらの撮影でも映像が揺れにくくなることを狙った構造です。Osmo Mobile 8は「3軸」、Osmo Mobile 8Pは「3軸スマートフォン用ジンバル」と記載されています。

▸パン軸360°回転

横方向にどこまで回転できるかを示します。Osmo Mobile 8のページに「360°回転」、Osmo Mobile 8Pのメーカー公開情報に「パン 360°連続回転、最大速度120°/s」と記載されています。

▸ActiveTrack

画面の中の人やペットを認識して、自動でカメラの向きを追わせる機能の名称です。Osmo Mobile 8Pのページに「ActiveTrack 8.0（人・ペットなど）」と記載があり、Osmo Mobile 8のページには記載がありません。

▸mAhとWh（バッテリー容量）

mAhは電池の電気量、Whは電力量を示す単位です。どちらも大きいほど、一般に長く使える目安になります。Osmo Mobile 8とOsmo Mobile 8Pは、どちらもメーカー公開情報で3350mAh（12.06Wh）と記載されています。

▸1/4インチ-20 UNCポート

一般に、カメラの三脚穴などで使われるネジの規格です。Osmo Mobile 8Pのメーカー公開情報に、底面に1/4インチ-20 UNCポートがあると記載されています。Osmo Mobile 8のページには、同じ項目の記載がありません。

  • スマートフォンの寸法：重量170〜300g、幅67〜84mmが対象。Osmo Mobile 8Pは厚さ6.9〜11mmも記載がある。ケース込みで確認する。
  • コンボの内容：Osmo Mobile 8のページには4つの購入オプションがあると記載。スタンダードコンボに含まれる付属品を、Amazon商品ページで確認する。
  • 重量の内訳：Osmo Mobile 8の約370gは内蔵三脚・磁気クランプ・マルチファンクションモジュールを含む値。Osmo Mobile 8Pの約386gはFrameTapなども含む値。内訳が違うため、単純には比べられない。
  • アプリの入手：Osmo Mobile 8Pのページには、DJI MimoアプリがGoogle Playから削除されていると記載。使っている端末でアプリを入手できるか確認する。

07よくある質問

Q.Osmo Mobile 8とOsmo Mobile 8Pの主な違いは何ですか？

各商品ページの記載では、重量が8は約370g、8Pは約386gです。8Pのページには、ActiveTrack 8.0による被写体追尾と、着脱式リモコンOsmo FrameTapの記載があります。バッテリー（3350mAh）、動作時間（約10時間）、延長ロッド（最大215mm）は両機種で共通です。

Q.バッテリー駆動時間に違いはありますか？

メーカー公開情報では、どちらも約10時間（ジンバルを水平に保ちアクセサリーなしの場合）と記載されています。トラッキングをオンにした場合は、フィルライトの使用条件によって約5時間や約4時間と短くなる旨も記載されています。

Q.使えるスマートフォンの条件は同じですか？

メーカー公開情報では、どちらも重量170〜300g、幅67〜84mmのスマートフォンが対象と記載されています。8Pは厚さ6.9〜11mmの記載もあります。ケースを付けたまま使う場合は、購入前にサイズをご確認ください。

Q.どちらを選べばいいですか？

ActiveTrack 8.0やOsmo FrameTapの記載を重視するなら8Pのページ、基本の3軸手ブレ補正、内蔵の延長ロッドと三脚、約10時間の動作で足りるなら8のページが候補になります。折りたたみ時のサイズは8が190×95×46mm、8Pが196×105×38mmと記載されているので、収納するバッグの大きさも確認しておくと安心です。

Q.アプリはどこから入手しますか？

Osmo Mobile 8Pのページに、プラットフォームの互換性の問題によりDJI MimoアプリはGoogle Playから削除されており、DJI公式サイトから最新版をダウンロードするよう案内されていると記載されています。Osmo Mobile 8のページには、アプリの入手についての記載がありません。お使いの端末で入手できるかは、購入前にご確認ください。

Q.充電にどのくらいかかりますか？

Osmo Mobile 8のメーカー公開情報では、10W USB-C充電器で約2.5時間です。Osmo Mobile 8Pのメーカー公開情報では、約2.5時間（0%から100%、DJI 65W充電器、電源オフ、25℃の試験）です。充電器の条件が異なります。

Q.延長ロッドと三脚は付いていますか？

どちらも内蔵と記載されています。延長ロッドは、どちらも最大215mmまで伸びると記載されています。Osmo Mobile 8Pのメーカー公開情報には、内蔵三脚の長さ82mmの記載もあります。

Q.リモコンのOsmo FrameTapは防水ですか？

Osmo Mobile 8Pのメーカー公開情報に、Osmo FrameTapは29gで、防水ではないと記載されています。Osmo Mobile 8Pのページには、ジンバル本体の防水性能も仕様表に記載がないとあります。

Q.付属のケーブルを教えてください。

Osmo Mobile 8Pのページに、スマホ充電ケーブル（USB-C・15cm）と電源ケーブル（USB-C・50cm）が付属と記載されています。Osmo Mobile 8のページには、「ジンバル、磁気スマートフォンクランプなど」とあり、ケーブルの記載がありません。

Q.発売日を教えてください。

Osmo Mobile 8Pの仕様表に、発売日は2026年5月7日と記載されています。Osmo Mobile 8のページには、発売日の記載がありません。
