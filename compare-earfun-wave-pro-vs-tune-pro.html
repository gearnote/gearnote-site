02違いのまとめ

  • 再生時間は、Wave Proのページに「最大80時間（ANCオフ）／最大55時間（ANC常時オン）」、Tune Proのページに「最大120時間（ANCオフ時）」と記載されています。Tune Proのメーカー公開仕様の欄には、ANCオンで最大80時間という記載もあります。
  • 対応コーデックは、Wave Proのページに「LDAC対応（ハイレゾオーディオ＆ハイレゾワイヤレス認証取得）」、メーカー公開仕様の欄に「LDACとSBC」と記載されています。Tune Proのページには、対応コーデックの記載がありません。
  • ドライバーは、Wave Proが「40mm径 DLCコーティング振動板」、Tune Proが「40mm PET複合膜＋10mm液晶ポリマー(LCP)のデュアルダイナミックドライバー」と記載されています。ハイブリッドANCの低減量は、どちらも最大45dBと記載されています。
  • 接続は、Wave Proのページに「3.5mm端子対応（付属ケーブル使用）」、Tune Proのページに「ワイヤレス／USB-C／3.5mm AUX有線接続」と記載されています。Tune Proのページには、Bluetooth 5.4・マルチポイント対応の記載もあります。
  • メーカー公開仕様の欄では、バッテリー容量はWave Proが800mAh、Tune Proが1100mAh、充電時間はWave Proが2時間、Tune Proが3時間、重量はWave Proが268g、Tune Proが289.5gと記載されています。Tune Proは非防水、Wave Proのページには防水性能の記載がありません。
  • ノイズキャンセリングの数値は、EarFun Wave Proのページに「最大-45dB」、EarFun Tune Proのページに「Bluetooth接続時最大45dB、有線時最大30dB低減（Amazon掲載）」と記載されています。数値は同じですが、EarFun Tune Proのページだけ接続方法ごとの条件が書かれています。EarFun Wave Proのページには、有線時の数値の記載がありません。
  • ページごとの記載の偏りとして、EarFun Wave Proのページには専用アプリ「EarFun Audio」、シアターモード、55ms低遅延ゲームモードの記載があり、EarFun Tune Proのページには購入日から18か月の保証と非防水の記載があります。片方にしか書かれていない項目は、機能の有無の違いを示すものではありません。
  • 寸法は、メーカー欄にEarFun Wave Proが159.7×82.4×210.8mm、EarFun Tune Proが195.3×164.9×81.4mmと記載されています。どちらも折りたたみ時の寸法かどうかの記載がなく、数字の並び順も異なるため、このページの掲載情報だけで大小を比べることはできません。

03こんな人にはこちら

▸EarFun Wave Proが向いている人

Wave Proのページでは、LDAC対応、ANCオフ時最大80時間の再生、専用アプリ、シアターモード、55ms低遅延ゲームモードを備えた折りたたみ式ヘッドホンと説明されています。

  • LDAC対応の高音質を、ワイヤレスヘッドホンで楽しみたい人
  • 長時間の移動でも充電を気にせず使いたい人
  • ノイズキャンセリングと有線接続の両方を使い分けたい人

▸EarFun Tune Proが向いている人

Tune Proのページでは、40mm＋10mmのデュアルドライバー、ANCオフ時最大120時間の再生、USB-C・3.5mmの有線接続に対応した折りたたみ式の密閉型ヘッドホンと説明されています。

  • 長時間のバッテリー持ちを重視する人
  • オーバーイヤー型でしっかり遮音したい人
  • 有線・無線の両方を使い分けたい人

04場面別の選び方

使う場面ごとに、各商品ページの記載で見ておきたい点をまとめました。あくまで掲載情報にもとづく目安です。

  • ノイズキャンセリングを常にオンにして長時間使いたいなら：ANCオン時の再生時間は、EarFun Wave Proのページに「最大55時間（ANC常時オン）」、EarFun Tune Proのメーカー公開仕様の欄に「ANCオンで最大80時間」と記載されています。ANCオフ時は、EarFun Wave Proが最大80時間、EarFun Tune Proが最大120時間です。
  • LDAC対応の機器で高音質のワイヤレス再生を使いたいなら：EarFun Wave Proのページに「LDAC対応（ハイレゾオーディオ＆ハイレゾワイヤレス認証取得）」と記載されています。EarFun Tune Proのページには、対応コーデックの記載がありません。LDACを使うには、再生する機器側もLDACに対応している必要があります。
  • 動画やゲームで、音のずれを気にしたくないなら：EarFun Wave Proのページに、シアターモードと55ms低遅延ゲームモードの記載があります。EarFun Tune Proのページには、低遅延モードの記載がありません。
  • 有線でも使い分けたいなら：EarFun Wave Proは3.5mm端子（付属ケーブル使用）、EarFun Tune ProはUSB-Cと3.5mm AUXの有線接続に対応と記載されています。EarFun Wave Proのページの注意点には、USB-Cのデジタル接続には非対応との記載があります。
  • 汗や雨のある場面で使うことが多いなら：EarFun Tune Proのページに「非防水」と記載されています。EarFun Wave Proのページには防水性能の記載がありません。どちらも、水に濡れる場面を前提にした記載は見当たりません。

05スペック用語のかんたん解説

比較表に出てくる用語を、一般的な意味で簡単に説明します。数値や対応の有無は各商品ページ・Amazon商品ページでご確認ください。

▸ハイブリッドANC

ノイズキャンセリングの方式の一つで、本体の外側と内側の両方で拾った音をもとに騒音を打ち消す方式とされています。EarFun Wave Proのページに「ハイブリッド式」、EarFun Tune Proのページに「ハイブリッドANC」と記載があります。

▸dB（デシベル）

音の大きさの単位です。ノイズキャンセリングの「最大45dB」は、条件が最も良い場合の低減量を示す表記で、実際の聞こえ方は周囲の音の種類によって変わります。EarFun Tune Proのページには、接続方法によって最大値が変わる旨が書かれています。

▸LDAC

Bluetoothで音声データを送るときの方式（コーデック）の一つで、通常のSBCより多くの情報を送れるとされています。送る側と受ける側の両方が対応している必要があります。EarFun Wave Proのページに記載があり、メーカー欄には「LDACとSBC」とあります。

▸ドライバー（40mmと40mm＋10mm）

ドライバーは音を出す部品です。EarFun Wave Proは「40mm径 DLCコーティング振動板」、EarFun Tune Proは「40mm PET複合膜＋10mm液晶ポリマー(LCP)のデュアルダイナミックドライバー」と記載されています。構成による音の違いは、ページに数値での記載がありません。

▸オーバーイヤー（密閉型）

耳全体をイヤーパッドで覆う形のヘッドホンです。密閉型は、外の音が入りにくい構造とされます。EarFun Wave Proのページに「オーバーイヤー（密閉型）」（Amazon掲載）、EarFun Tune Proのページに「オーバーイヤー（密閉型・折りたたみ式）」と記載されています。

06購入前のチェックリスト

購入前に見ておくと安心な項目です。各商品ページの記載にもとづくため、最終的にはAmazon商品ページの最新情報もご確認ください。

  • 再生機器のコーデック：EarFun Wave ProのLDACを使う場合は、手持ちのスマートフォンなどがLDACに対応しているか確認する。
  • 再生時間の条件：最大値はANCオフ時の数字。ANCオン時の時間はEarFun Wave Proが55時間、EarFun Tune Proは80時間（メーカー欄）と記載されている。
  • 有線ケーブル：EarFun Wave Proは付属ケーブル使用と記載。EarFun Tune Proの有線接続に使うケーブルの付属内容は、Amazon商品ページで確認する。
  • 防水：EarFun Tune Proは非防水。EarFun Wave Proは防水の記載がないため、雨や汗の多い場面では使用を控えるのが無難。
  • 重さ：メーカー欄にEarFun Wave Proが268g、EarFun Tune Proが289.5gと記載。長時間の装着感には個人差がある。
  • 保証：EarFun Tune Proは購入日から18か月と記載。EarFun Wave Proのページには保証期間の記載がないため、購入前に確認する。
  • 色と版：EarFun Wave Proは「ブラック（2025年新版）」と記載。購入するモデルの表記は、Amazon商品ページで確認する。

07よくある質問

Q.EarFun Wave ProとTune Proの主な違いは何ですか？

各商品ページの記載では、再生時間（Wave Proは最大80時間、Tune Proは最大120時間、いずれもANCオフ時）、ドライバー構成（Wave Proは40mmの単一、Tune Proは40mm＋10mmのデュアル）、コーデックの記載（Wave Proのみ記載あり）が異なります。ハイブリッドANCは、どちらも最大45dBと記載されています。

Q.有線でも使えますか？

どちらのページにも有線接続の記載があります。Wave Proは3.5mm端子（付属ケーブル使用）、Tune Proは「ワイヤレス／USB-C／3.5mm AUX有線接続」と記載されています。ケーブルの付属内容は、購入前にAmazon商品ページでご確認ください。

Q.防水性能はありますか？

Tune Proのページには「非防水」と記載されています。Wave Proのページには防水性能の記載がありません。汗や雨の中で使う場合は、購入前にメーカーの最新情報をご確認ください。

Q.どちらを選べばいいですか？

ページにLDAC対応の記載があり、専用アプリや低遅延ゲームモードの記載も使いたいならWave Pro、ANCオフ時の再生時間が長く、デュアルドライバー構成と有線のUSB-C接続の記載があるTune Proは、長時間の使用を想定する場合の候補になります。ヘッドホン選び全般はヘッドホンの選び方ガイドもご覧ください。

Q.ノイズキャンセリングの最大値は同じですか？

EarFun Wave Proは「最大-45dB」、EarFun Tune Proは「Bluetooth接続時最大45dB、有線時最大30dB低減」と記載されています。数値は同じですが、EarFun Tune Proのページには接続方法ごとの条件が書かれています。EarFun Wave Proのページには条件の記載がありません。

Q.通話用のマイクに違いはありますか？

EarFun Wave Proのページには「計5基内蔵（ANC用含む）」、EarFun Tune Proのページには「5マイク＋AIノイズキャンセリング」と記載されています。マイクの数はどちらも5基です。通話時の聞こえ方を示す数値は、どちらにも記載がありません。

Q.本体の重さはどれくらい違いますか？

メーカー公開仕様の欄に、EarFun Wave Proは268g、EarFun Tune Proは289.5gと記載されています。差は21.5gです。装着時の感じ方は、頭の形やイヤーパッドの当たり方で変わります。

Q.保証期間はありますか？

EarFun Tune Proのページに「購入日から18か月」と記載されています。EarFun Wave Proのページには、保証期間の記載がありません。

Q.2台の機器につないで使えますか？

EarFun Wave Proのページの対応機能に「マルチポイント接続」、EarFun Tune Proのページにも「Bluetooth 5.4・マルチポイント対応」と記載されています。同時に接続できる台数の記載は、どちらのページにもありません。

Q.充電にかかる時間は同じですか？

メーカー公開仕様の欄に、EarFun Wave Proは充電時間2時間（バッテリー容量800mAh）、EarFun Tune Proは充電時間3時間（1100mAh）と記載されています。EarFun Wave Proのページの仕様表には「約2時間（800mAh）」と記載があります。

Q.専用アプリはありますか？

EarFun Wave Proのページに、専用アプリ「EarFun Audio」の記載があります。EarFun Tune Proのページには、専用アプリの記載がありません。

Q.ヘッドホン選びの基本を知りたいときは？

装着タイプやノイズキャンセリングの見方はヘッドホンの選び方ガイド、ほかの機種はヘッドホン・イヤホンの比較でご覧いただけます。
