02違いのまとめ

  • キー数は、Elgato日本公式サイトの仕様として、Miniのページに「6個のカスタム可能なLCDキー」、MK.2のページに「カスタム可能な15個のLCDキー」、Neoのページに「8個のカスタム可能なLCDキー、タッチセンサー2つのTouch Points、カスタム可能なInfobar」と記載されています。Miniのページの仕様表には、キー数の項目がありません。
  • サイズと重量は、Miniが84×60×58mm・160g、MK.2が118×84×25mm（スタンドを含まない）・145g（スタンドなし）／270g（スタンドあり）、Neoが107×26×78mm・210gと、それぞれのメーカー仕様の欄に記載されています。
  • ケーブルは、Miniが一体型USB 2.0ケーブル（150cm、取り外し不可）、MK.2がUSB-C to USB-Cケーブル（90度コネクター、150cm）、Neoが公式のよくある質問で固定式で取り外せないと記載されています。Neoの仕様表にはケーブル長が約90cmとあります。
  • 同梱物は、MK.2のページに卓上スタンドとUSB-Cケーブルが記載されています。Miniの同梱物は本体とクイックスタートガイドで、Neoのページには同梱物の項目がありません。
  • 対応OSは、Neoのページに「Windows 11以降／macOS 13以降」と記載されています。MiniとMK.2のページは「Mac／PC対応」で、バージョンの記載はありません。保証は、MiniとMK.2が2年6カ月、Neoが2年間（条件付き）と記載されています。
  • Stream Deck Miniのページの仕様表は接続を「USB-C」としていますが、メーカー仕様の欄には「一体型USB 2.0ケーブル（150cm、取り外し不可）」と記載されています。本体側の端子の形やケーブルの扱いは、Amazon商品ページの写真や説明でご確認ください。
  • 割り当てを増やす方法は機種で異なります。Stream Deck Neoのページには、ページやフォルダを切り替えて割り当てを8個以上に増やせると記載されています。Stream Deck MK.2は15キーが並ぶ構成で、Stream Deck Miniはキー数が少ない分、割り当てられる数に制約があると注意点に書かれています。
  • 設置の形も違います。Stream Deck MK.2のページには卓上スタンドの同梱が記載され、Stream Deck Neoのページには薄型の本体寸法（約10.7×2.6×7.8cm）が記載されています。Stream Deck Miniは約8.4×6×5.8cm・約160gと記載されています。

03こんな人にはこちら

▸Stream Deck Miniが向いている人

Miniのページでは、約8.4×6×5.8cm・約160gのコンパクトな本体で、Zoom・Teams・PowerPoint・Office系アプリのショートカットを割り当てるモデルと説明されています。

  • Zoom・Teams・PowerPointなど日常業務のショートカットを効率化したい人
  • デスクの省スペースを重視する人
  • ノートPCと一緒に持ち運べるコンパクトなコントローラーを探している人

▸Stream Deck MK.2が向いている人

MK.2のページでは、15個のLCDキーと卓上スタンドを備え、OBS・Twitch・Discordなど幅広いプラグインに対応するモデルと説明されています。

  • 配信・動画編集・オフィス作業のショートカットを物理キーにまとめたい人
  • OBSやTwitch、Discordなど複数のツールを組み合わせて使う人
  • 視覚的にアイコンを確認しながら操作したい人

▸Stream Deck Neoが向いている人

Neoのページでは、8個のLCDキーと2つのTouch Pointsを備え、アプリ起動・配信操作・マクロ・スマート家電の操作を無料のStream Deckアプリで設定するモデルと説明されています。

  • OBSでの配信・録画やマイクのミュートを、物理ボタンで操作したい人
  • よく使うアプリやショートカットを、1タッチで呼び出したい人
  • 動画編集やオフィス作業で、繰り返しの操作を減らしたい人

04場面別の選び方

使う場面ごとに、各商品ページの記載で見ておきたい点をまとめました。あくまで掲載情報にもとづく目安です。

  • オンライン会議やOfficeの操作を減らしたいなら：Stream Deck Miniのページには、Zoom・Teams・PowerPoint・Excel・Wordなど日常で使うアプリに対応し、ドラッグ＆ドロップの簡単設定でショートカットを割り当てられると記載されています。割り当てる操作が少なめの使い方を想定して見ておけます。
  • 配信や動画編集で複数のツールを切り替えるなら：Stream Deck MK.2のページの仕様表には、OBS、Twitch、Discord、Spotify、Philips Hueなどのプラグインが記載されています。15個のLCDキーにアイコンを表示して、実行の確認ができると説明されています。
  • 机の上のスペースが限られているなら：Stream Deck Miniのページには、約8.4×6×5.8cm・約160gでノートPCと一緒に持ち運べるコンパクトなコントローラーと書かれています。Stream Deck Neoのページにも、薄型の本体寸法が記載されています。置きたい場所の幅と奥行きを測って見比べてください。
  • マイクのミュートや録画の開始を物理ボタンにしたいなら：Stream Deck Neoのページには、OBSでの配信・録画やマイクのミュートを物理ボタンで操作したい人に向くと記載されています。8個のキーと2つのTouch Pointsで、よく使う操作を手元に置く使い方です。
  • スマート家電の操作も1か所にまとめたいなら：Stream Deck Neoのページには、スマートライトやプラグなどスマート家電の操作にも使えると記載されています。対応する機器は、使っている製品ごとにStream Deckアプリ側の対応状況を確認してください。

05スペック用語のかんたん解説

比較表に出てくる用語を、一般的な意味で簡単に説明します。数値や対応の有無は各商品ページ・Amazon商品ページでご確認ください。

▸LCDキー

ボタンの表面が小さな画面になっていて、割り当てた操作に合わせたアイコンを表示できるキーのことです。押す前に何のキーかが見分けやすくなります。キーの数はStream Deck Miniが6個、Stream Deck MK.2が15個、Stream Deck Neoが8個と、各ページに記載されています。

▸Touch Points

Stream Deck Neoのページにある用語で、8個のキーとは別に用意された2つのタッチ式の操作部分を指します。どんな操作を割り当てられるかの詳細は、メーカーの案内でご確認ください。

▸プラグイン

ほかのアプリやサービスと連携するための追加機能のことです。Stream Deck MK.2のページの仕様表には、対応プラグインとしてOBS、Twitch、Discord、Spotify、Philips Hueなどが記載されています。

▸ドラッグ＆ドロップ設定

操作や機能の一覧からキーへ項目をマウスで移して割り当てる設定方法です。3機種のページに、この方法で設定できる旨の記載があります。使い始める前に、無料のStream Deckアプリをパソコンに入れる必要があるとStream Deck Neoのページに書かれています。

▸USB-C

パソコンとつなぐ小型の端子の規格です。パソコン側にUSB-Cのポートがない場合は、変換アダプターが必要になることがあるとStream Deck Neoのページの注意点に記載されています。

06購入前のチェックリスト

購入前に見ておくと安心な項目です。各商品ページの記載にもとづくため、最終的にはAmazon商品ページの最新情報もご確認ください。

  • キー数：よく使う操作の数を数えて、Stream Deck Miniの6個、Stream Deck MK.2の15個、Stream Deck Neoの8個（ページ切り替えで増やせる）のどれに収まるかを考える。
  • 対応OS：Stream Deck NeoのページはWindows 11以降／macOS 13以降と記載。Stream Deck MiniとStream Deck MK.2は「Mac／PC対応」のみの記載なので、お使いのバージョンはAmazon商品ページで確認する。
  • 接続端子：パソコンにUSB-Cのポートがあるか確認する。ない場合は変換アダプターが必要になることがある。
  • ケーブル：Stream Deck MiniとStream Deck Neoは取り外し不可の固定式と記載。Stream Deck MK.2はUSB-C to USB-Cケーブルの同梱が記載されている。配線の取り回しを事前に考えておく。
  • 設置スペース：Stream Deck MK.2は約11.8×8.4×2.5cmで卓上スタンドつき。机の上に置く場所の寸法を測っておく。
  • 初期設定の時間：アプリのダウンロードと各キーへの割り当てが必要。Stream Deck MK.2のページには、初期設定にある程度の時間がかかる場合があると書かれている。

07よくある質問

Q.Stream Deck Mini・MK.2・Neoの主な違いは何ですか？

各商品ページの記載では、キー数がMiniは6個、MK.2は15個、Neoは8個とTouch Points 2つです。サイズはMiniが84×60×58mm、MK.2が118×84×25mm、Neoが107×26×78mmで、MK.2には卓上スタンドが同梱されます。ケーブルはMiniとNeoが固定式、対応OSはNeoがWindows 11以降／macOS 13以降と記載されています。

Q.Neoにはどんな特徴がありますか？

Neoのページには、8個のLCDキーに加えて、タッチ式の2つのTouch Pointsとカスタム可能なInfobarを備えると記載されています。キーを増やしたい場合はページやフォルダの切り替えを使うと説明されています。

Q.Miniのキー数はいくつですか？

Miniの商品ページの仕様表にはキー数の項目がありません。Elgato日本公式サイトの仕様として、同ページに「6個のカスタム可能なLCDキー」と記載されています。購入前にAmazon商品ページとメーカーの最新情報もご確認ください。

Q.どれもオーディオミキサー機能やダイヤルはありますか？

3機種のページに、ダイヤルやオーディオミキサー機能の記載はありません。Miniのページには、オーディオミキサー機能やダイヤル操作は搭載していないと書かれています。ダイヤルのあるモデルは、Stream Deck +のページをご覧ください。

Q.どれを選べばいいですか？

デスクの省スペースや持ち運びを重視し、割り当てる操作が少ないなら、Miniのページが参考になります。配信や動画編集で複数のツールを切り替えるなら、キー数の多いMK.2のページ、薄型の本体で8個のキーとTouch Pointsを使いたいならNeoのページを確認するとよいでしょう。キー数をさらに増やしたい場合はStream Deck + XLのページもご覧ください。

Q.卓上スタンドは付いていますか？

Stream Deck MK.2のページの同梱物に卓上スタンドが記載されています。Stream Deck Miniの同梱物は本体とクイックスタートガイド、Stream Deck Neoのページには同梱物の項目がありません。スタンドの有無は、購入前にAmazon商品ページでご確認ください。

Q.ケーブルは取り外せますか？

Stream Deck Miniはメーカー仕様の欄に取り外し不可と記載され、Stream Deck Neoもケーブル固定式で長さの変更や交換ができないと記載されています。Stream Deck MK.2はUSB-C to USB-Cケーブルが同梱品として記載されています。

Q.MacとWindowsのどちらで使えますか？

Stream Deck MiniとStream Deck MK.2のページは「Mac／PC対応」、Stream Deck Neoのページは「Windows 11以降／macOS 13以降」と記載されています。Stream Deck MiniとStream Deck MK.2はバージョンの記載がないため、お使いのOSの対応状況はメーカーの案内でご確認ください。

Q.保証期間はどれくらいですか？

Stream Deck Miniは2年6カ月のメーカー保証、Stream Deck MK.2は購入日より2年6カ月（レシートまたは領収書が必要）、Stream Deck Neoは2年間のメーカー保証（条件付き）とそれぞれ記載されています。条件の詳細は、保証書やメーカーの案内でご確認ください。

Q.設定は難しいですか？

3機種のページとも、ドラッグ＆ドロップで設定できると記載されています。ただしStream Deck MK.2のページには、多機能な分だけ初期設定に時間がかかる場合があると注意点に書かれ、Stream Deck Neoのページには、アプリのダウンロードと設定が必要で、買ってすぐには使えないと記載されています。

Q.対応しているアプリには何がありますか？

Stream Deck Miniのページの仕様表には、Zoom、Teams、PowerPoint、Excel、Word、Google Suite、MS Office、Photoshop、Adobe Creative、Spotifyなどが記載されています。Stream Deck MK.2のページには、OBS、Twitch、Discord、Spotify、Philips Hueなどのプラグインが記載されています。

スペック・メリット・デメリット・Amazonへのリンクは、各商品ページでご確認いただけます
