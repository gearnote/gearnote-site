ゼンハイザー ACCENTUM OpenとACCENTUM True Wirelessの違いを比較

02違いのまとめ

  • 装着方式は、ACCENTUM Openのページでは「オープンイヤー（インイヤー装着）」、ACCENTUM True Wirelessのページでは「完全ワイヤレス（インイヤー）」と記載されています。
  • ノイズ制御は、ACCENTUM Openのページには「ノイズキャンセリング非搭載」と記載されています。ACCENTUM True Wirelessのページには「ハイブリッドノイズキャンセリング＋外音取り込み機能」と記載されています。
  • 防滴・防塵は、ACCENTUM OpenがIPX4（防滴）、ACCENTUM True WirelessがIP54と記載されています。ACCENTUM True Wirelessのページでは、IP54は完全防水ではないと説明されています。
  • ドライバーは、ACCENTUM Openの仕様表が「ダイナミックドライバー」（メーカー情報欄では11mmのダイナミック型）、ACCENTUM True Wirelessの仕様表が「7mm径ダイナミックドライバー（TrueResponseトランスデューサー）」と記載されています。
  • 再生時間は、ACCENTUM Openのページがイヤホン単体で最大6時間・ケース併用で最大24時間、ACCENTUM True Wirelessのページがケース併用で最大28時間と記載されています。ACCENTUM Openのページには充電時間約1時間（Amazon掲載情報（メーカー公式ページには記載がありません））、マルチポイントペアリング対応の記載があり、ACCENTUM True Wirelessのページにはワイヤレス充電対応と国内正規新品メーカー1年保証の記載があります。
  • 重さは、ACCENTUM Openのページの仕様表に「イヤホン 約4.35g（片耳、メーカー公式）」と記載されています。ACCENTUM True Wirelessのメーカー情報欄には、イヤホンが片側5.5g、ケースが41g、イヤホンとケースの合計が52gと記載されています。
  • 対応コーデックは、ACCENTUM Openのメーカー情報欄がSBCとAAC、ACCENTUM True Wirelessのメーカー情報欄がSBC、AAC、aptX、LC3と記載されています。ACCENTUM True Wirelessのページには、日本向けの製品ページに仕様表がなく、米国向けの値であるとの注記があります。
  • マルチポイントは、ACCENTUM Openのページに「マルチポイントペアリング対応」とあり、メーカー情報欄には2台同時接続、ペアリング登録は最大8台と記載されています。ACCENTUM True Wirelessのページには、マルチポイントの記載は確認できなかったと書かれています。

03こんな人にはこちら

▸ACCENTUM Openが向いている人

ACCENTUM Openのページでは、耳をふさがないオープンイヤー設計で、周囲の音を意識しながら使えるとされるノイズキャンセリング非搭載のモデルと説明されています。

  • 周囲の音を聞きながら音楽や通話を楽しみたい人
  • ジョギングや通勤などで長時間イヤホンを使いたい人
  • 耳への圧迫感を抑えたい人

▸ACCENTUM True Wirelessが向いている人

ACCENTUM True Wirelessのページでは、ハイブリッドノイズキャンセリングと外音取り込み機能、IP54の防滴・防塵性能、ワイヤレス充電を備えた完全ワイヤレスイヤホンと説明されています。

  • 通勤やスポーツなど日常使いでワイヤレスイヤホンを使いたい人
  • コンパクトなケースで持ち運びやすいモデルを探している人
  • IP54の防滴・防塵性能を重視する人

04場面別の選び方

使う場面ごとに、各商品ページの記載で見ておきたい点をまとめました。あくまで掲載情報にもとづく目安です。

  • 電車や街なかの騒音を抑えて聞きたいなら：ACCENTUM True Wirelessのページの仕様表に「ハイブリッドノイズキャンセリング＋外音取り込み機能」と記載があります。ACCENTUM Openのページには、ノイズキャンセリング非搭載と記載されています。強さを示す数値（dB）は、どちらのページにも記載がありません。
  • 歩きながら周囲の音や呼びかけも聞こえる状態で使いたいなら：耳をふさがない設計のACCENTUM Openのページが参考になります。ACCENTUM Openのページには、オープンイヤー設計で周囲の音を意識しながら使えるとされると記載されています。ACCENTUM True Wirelessにも外音取り込み機能の記載がありますが、装着方式は完全ワイヤレス（インイヤー）です。
  • ジョギングや雨の日の通勤で使うことがあるなら：防滴・防塵の表記は、ACCENTUM OpenがIPX4、ACCENTUM True WirelessがIP54です。IP54は防塵も含む表記です。どちらのページにも、水没は想定されていないと書かれています。ACCENTUM True Wirelessのメーカー情報欄には、IP54はイヤホンのみとの記載があります。
  • ケーブルなしで充電したいなら：ACCENTUM True Wirelessのページの仕様表に、ワイヤレス充電対応と記載があります。メーカー情報欄には充電方法がUSB-CまたはQiとあり、ページには、Qi対応の充電器が別に必要と書かれています。ACCENTUM Openのページには、ワイヤレス充電の記載がありません。
  • スマホとパソコンを行き来して使いたいなら：ACCENTUM Openのページに、マルチポイントペアリング対応と記載があります。対応デバイスも、電話、タブレット、ノートパソコンと仕様表に記載されています。ACCENTUM True Wirelessのページには、マルチポイントの記載が確認できていません。

05スペック用語のかんたん解説

比較表に出てくる用語を、一般的な意味で簡単に説明します。数値や対応の有無は各商品ページ・Amazon商品ページでご確認ください。

▸外音取り込み

マイクで拾った周囲の音をイヤホンから流し、耳に入れたまま周りの音を聞けるようにする機能です。駅のアナウンスを確認したいときなどに使われます。ACCENTUM True Wirelessのページの仕様表のノイズ制御欄に記載があります。ACCENTUM Openのページには記載がありません。

▸ハイブリッドノイズキャンセリング

一般に、イヤホンの外側と内側のマイクを組み合わせて、騒音を打ち消す方式を指すとされます。ACCENTUM True Wirelessのページの仕様表に記載があり、メーカー情報欄には片側2基のビームフォーミングMEMSマイクとあります。強さの数値は、ページに記載がありません。

▸IPX4とIP54

IPコードは防塵と防水の等級を示す国際規格の表記です。「IPX4」のXは防塵の等級を試験していないという意味で、4は水しぶきに対する保護を表します。「IP54」の5は防塵、4は水しぶきへの保護です。ACCENTUM OpenがIPX4、ACCENTUM True WirelessがIP54と記載されています。

▸マルチポイント

1つのイヤホンを複数の機器につないでおき、切り替えながら使える機能です。スマホとパソコンを行き来する人に向くとされます。ACCENTUM Openのメーカー情報欄に「マルチポイント（2台同時）」と記載があります。

▸コーデック（SBC・AAC・aptX・LC3）

音声データを無線で送るための圧縮方式の名前です。接続する機器とイヤホンの両方が対応している方式が使われるのが一般的です。ACCENTUM OpenはSBCとAAC、ACCENTUM True WirelessはSBC、AAC、aptX、LC3と、それぞれメーカー情報欄に記載されています。

06購入前のチェックリスト

購入前に見ておくと安心な項目です。各商品ページの記載にもとづくため、最終的にはAmazon商品ページの最新情報もご確認ください。

  • 音漏れと使う場所：ACCENTUM Openのページには、電車や図書館など静かな場所では音漏れに配慮が必要と書かれている。使う場所を思い浮かべて選ぶ。
  • 騒音への対処：ACCENTUM Openはノイズキャンセリング非搭載。電車内などで騒音を抑えたい用途では、ACCENTUM True Wirelessの記載を確認する。
  • 再生時間の条件：ACCENTUM Openは単体最大6時間・ケース併用最大24時間。ACCENTUM True WirelessはANCオフ最大8時間、ANCオン最大6時間、ケース併用最大28時間（iPhone、85dB）。条件つきの数値のため、使い方で変わる。
  • イヤーチップと装着感：ACCENTUM True Wirelessのメーカー情報欄にはXS・S・M・Lの4サイズが付属と記載されている。ACCENTUM Openのページには、外装素材がシリコーンで、装着位置を調整すると書かれている。
  • 保証：ACCENTUM True Wirelessのページには国内正規新品メーカー1年保証と記載されている。ACCENTUM Openのページには、保証の記載がない。
  • 数値の出どころ：ACCENTUM True Wirelessのメーカー情報は米国向けの製品ページの値。日本向けの製品ページには仕様表がないため、購入前にAmazon商品ページも確認する。

07よくある質問

Q.ACCENTUM OpenとACCENTUM True Wirelessの主な違いは何ですか？

各商品ページの記載では、装着方式とノイズ制御が異なります。ACCENTUM Openはオープンイヤー設計でノイズキャンセリング非搭載、ACCENTUM True Wirelessはハイブリッドノイズキャンセリングと外音取り込み機能を備えた完全ワイヤレス（インイヤー）です。防滴・防塵は、Openが「IPX4」、True Wirelessが「IP54」と記載されています。

Q.ノイズキャンセリングがあるのはどちらですか？

ACCENTUM True Wirelessのページに、ハイブリッドノイズキャンセリングと外音取り込み機能の記載があります。ACCENTUM Openのページには、ノイズキャンセリング機能は搭載していないと記載されています。

Q.再生時間に違いはありますか？

ACCENTUM Openのページには、イヤホン単体で最大6時間、ケース併用で最大24時間と記載されています。ACCENTUM True Wirelessのページには、ケース併用で最大28時間（iPhone、85dB）と記載されています。ACCENTUM True Wirelessのメーカー情報欄には、ANCオフ時は単体で最大8時間、ANCオン時は最大6時間と記載されています。条件の詳細は購入前にご確認ください。

Q.ワイヤレス充電やマルチポイントに対応していますか？

ACCENTUM True Wirelessの仕様表のバッテリー欄に、ワイヤレス充電対応と記載されています。ACCENTUM Openの仕様表の操作方法欄には、マルチポイントペアリング対応と記載されています。ACCENTUM True Wirelessの仕様表には、マルチポイントの記載はありません。

Q.どちらを選べばいいですか？

周囲の音を聞きながら使うオープンイヤー設計を重視するなら、ACCENTUM Openのページが候補になります。ノイズキャンセリングや外音取り込み、IP54の防滴・防塵、ワイヤレス充電の記載を重視するなら、ACCENTUM True Wirelessのページを確認するとよいでしょう。イヤホン選び全般はワイヤレスイヤホンの選び方ガイドもご覧ください。

Q.イヤホン本体の重さに違いはありますか？

ACCENTUM Openのページの仕様表に、イヤホンは片耳約4.35g（メーカー公式）と記載されています。ACCENTUM True Wirelessのメーカー情報欄には、イヤホンが片側5.5g、ケースが41g、合計52gと記載されています。ACCENTUM Openのページには、ケースの重さの記載がありません。

Q.対応コーデックを教えてください。

ACCENTUM Openのメーカー情報欄にはSBCとAAC、ACCENTUM True Wirelessのメーカー情報欄にはSBC、AAC、aptX、LC3と記載されています。ACCENTUM True Wirelessのメーカー情報欄には、LC3について、Auracastはファームウェア更新が必要との記載もあります。

Q.充電にかかる時間は同じですか？

ACCENTUM Openのページには、充電時間約1時間がAmazon掲載情報（メーカー公式ページには記載がありません）で記載されています。ACCENTUM True Wirelessのメーカー情報欄には、フル充電約1.5時間、10分の充電で約1時間再生と記載されています。ただしACCENTUM True Wirelessの値は米国向けの製品ページにもとづきます。

Q.通話用のマイクの構成は同じですか？

ACCENTUM Openのメーカー情報欄には、片耳2つのマイク（ビームフォーミング）と記載されています。ACCENTUM True Wirelessのメーカー情報欄には、片側2基のビームフォーミングMEMSマイクと記載されています。通話の聞こえ方を示す数値は、どちらのページにもありません。

Q.オープンイヤー型は音が外に漏れますか？

ACCENTUM Openのページには、オープンイヤー設計のため密閉型より遮音性は高くなく、電車や図書館など静かな場所では音漏れに配慮が必要と記載されています。音漏れの程度を示す数値は記載がありません。

Q.ページごとに再生時間の数字が違って見えるのはなぜですか？

ACCENTUM Openのページ内の見比べ表には、ACCENTUM True Wirelessの単体再生が「最大7時間」と書かれていますが、ACCENTUM True Wirelessのページの仕様表とメーカー情報欄は、ANCオフ最大8時間、ANCオン最大6時間です。このページでは、ACCENTUM True Wirelessのページの仕様表の記載を基準にしています。購入前にAmazon商品ページの最新の記載もご確認ください。
