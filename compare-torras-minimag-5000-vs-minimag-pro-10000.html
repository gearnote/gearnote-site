04場面別の選び方

使う場面ごとに、各商品ページの記載で見ておきたい点をまとめました。あくまで掲載情報にもとづく目安です。

  • ポケットや小さなバッグに入れて、薄さと軽さを優先するなら：TORRAS MiniMag 5000mAhは、102×64×8mm、110gとメーカー公開仕様に記載されています。TORRAS MiniMag Pro 10000mAhは103.6×70.1×14mm、195gです。TORRAS MiniMag 5000mAhのほうが、数値の上では薄くて軽い構成です。
  • 長めの外出に備えて、容量が多いほうがよいなら：容量はTORRAS MiniMag 5000mAhが5000mAh、TORRAS MiniMag Pro 10000mAhが10000mAhです。TORRAS MiniMag 5000mAhのページには、スマホ1回分に満たない場合がある容量という記載があります。TORRAS MiniMag Pro 10000mAhのページには、10000mAhはスマホ1〜2回分の充電が目安という記載があります。
  • 有線でも手早く充電したいなら：TORRAS MiniMag Pro 10000mAhのページに「PD30W」、メーカー公開仕様の欄に有線最大30W（Type-C）と記載されています。TORRAS MiniMag 5000mAhはケーブル最大15W（電圧5V）です。30Wを活かすには、対応するUSB-Cケーブルが必要と書かれています。
  • 充電の残りを、数値やゲージで確かめたいなら：仕様表に「LEDディスプレイ搭載」と記載のあるTORRAS MiniMag Pro 10000mAhのページが参考になります。TORRAS MiniMag 5000mAhのページには、残量表示の記載がありません。
  • AirPodsも一緒に充電したいなら：TORRAS MiniMag 5000mAhのメーカー案内にAirPodsが記載されています。ワイヤレス充電に対応した充電ケース付きのモデルのみ使えるとも書かれています。TORRAS MiniMag Pro 10000mAhのページには、対応機種の記載がないため、購入前にメーカーの案内でご確認ください。

05スペック用語のかんたん解説

比較表に出てくる用語を、一般的な意味で簡単に説明します。数値や対応の有無は各商品ページ・Amazon商品ページでご確認ください。

▸mAhとWh

mAhは電池に蓄えられる電気の量、Whはそれに電圧をかけたエネルギー量を示す単位です。一般に、mAhに3.7Vをかけて1000で割ると、おおよそのWhが分かります。TORRAS MiniMag 5000mAhのページに5000mAhでおよそ18.5Wh、TORRAS MiniMag Pro 10000mAhのページに10000mAhで約37Whと記載されています。

▸MagSafe（マグネット式ワイヤレス充電）

磁石でスマートフォンの背面に取り付け、ケーブルなしで充電する方式です。位置がずれたり、ケースが厚かったりすると、充電が不安定になる場合があります。TORRAS MiniMag 5000mAhは「MagSafe対応（マグネット式ワイヤレス充電）」、TORRAS MiniMag Pro 10000mAhは「PD30W（MagSafe対応）」と記載されています。

▸PD30W

USB Power Deliveryという充電規格で、最大30Wの出力に対応することを示す表記です。一般に、スマートフォンやタブレット、一部の薄型ノートパソコンの充電に使われる出力帯とされます。TORRAS MiniMag Pro 10000mAhのページに記載があります。ワイヤレス側は、メーカー公開仕様の欄で最大15Wです。

▸半固体電池

電解質を、従来のリチウムイオン電池より固体に近い状態にした電池です。液漏れや発火のリスクを抑える方向の技術として、紹介されています。TORRAS MiniMag Pro 10000mAhのページに「ATL製半固体電池」と記載があります。ただし、安全を保証するものではないと書かれています。

▸機内持ち込みの目安（100Wh）

航空機への持ち込みは、一般に100Wh以下であれば制限が少ないとされます。ただし個数や機内での使用ルールは、航空会社ごとに異なります。TORRAS MiniMag 5000mAhのメーカー公開仕様の欄に「可（100Wh未満）」、TORRAS MiniMag Pro 10000mAhの仕様表に「機内持ち込み可」と記載されています。

06購入前のチェックリスト

購入前に見ておくと安心な項目です。各商品ページの記載にもとづくため、最終的にはAmazon商品ページの最新情報もご確認ください。

  • ケースの厚み：どちらもマグネット式のため、ケースが厚いと吸着が弱まり、位置がずれて充電が止まる場合がある。MagSafe対応のケースかを確認する。
  • 手持ちの機種：TORRAS MiniMag 5000mAhの対応機種はメーカー案内でiPhone 17〜12シリーズなど。TORRAS MiniMag Pro 10000mAhのページには対応機種の記載がないため、お使いの機種はメーカー情報で確認する。
  • ケーブルの規格：TORRAS MiniMag Pro 10000mAhの30W出力を活かすには、対応するUSB-Cケーブルが必要。低出力のケーブルでは、充電速度が上がらない場合がある。
  • サイズと重量：TORRAS MiniMag 5000mAhは102×64×8mm・110g、TORRAS MiniMag Pro 10000mAhは103.6×70.1×14mm・195g。スマホと重ねた状態の厚みや重さも考える。
  • 機内での使用：機内持ち込みの可否は、航空会社の規定にも従う。搭乗前に、最新の規定を確認する。
  • 認証と保証：TORRAS MiniMag 5000mAhはPSE認証が取得済みと記載がある。TORRAS MiniMag Pro 10000mAhは保証期間がご購入日より1年間と記載されている。TORRAS MiniMag 5000mAhの保証期間の記載はない。

07よくある質問

Q.MiniMag 5000mAhとMiniMag Pro 10000mAhの主な違いは何ですか？

各商品ページの記載では、容量が5000mAhと10000mAh、サイズが102×64×8mmと103.6×70.1×14mm、重量が110gと195gです。出力はMiniMagがワイヤレス最大7.5W・ケーブル最大15W、MiniMag Proが有線最大30W・ワイヤレス最大15Wと記載されています。

Q.どちらもMagSafe対応ですか？

はい。MiniMagのページに「MagSafe対応（マグネット式ワイヤレス充電）」、MiniMag Proのページに「MagSafe対応」と記載されています。対応機種は、MiniMagのメーカー案内にAirPodsとiPhone 17〜12シリーズなどのMagSafe対応スマートフォンと記載されています。お使いの機種は購入前にメーカー情報でご確認ください。

Q.機内持ち込みはできますか？

MiniMagのメーカー公開仕様の欄に「機内持ち込み：可（100Wh未満）」、MiniMag Proの仕様表に「機内持ち込み可」と記載されています。実際の持ち込みの可否は航空会社の規定にも従うため、搭乗前にご確認ください。

Q.どちらを選べばいいですか？

薄さ・軽さと容量のどちらを基準にするかで整理しやすくなります。0.8cmの厚さと110gを重視するならMiniMag、10000mAhの容量と有線最大30Wの出力、LEDディスプレイの記載を重視するならMiniMag Proのページが候補になります。選び方の基本はモバイルバッテリーの選び方ガイドにまとめています。

Q.ワイヤレス充電の出力は、どちらが大きいですか？

メーカー公開仕様の欄に、TORRAS MiniMag 5000mAhがワイヤレス最大7.5W、TORRAS MiniMag Pro 10000mAhがワイヤレス最大15Wと記載されています。TORRAS MiniMag Pro 10000mAhの仕様表には、ワイヤレス側の出力値の記載がなく、「PD30W（MagSafe対応）」とだけ書かれています。

Q.有線で充電できますか？

TORRAS MiniMag 5000mAhのメーカー公開仕様の欄に、ケーブル最大15W（電圧5V）と記載されています。TORRAS MiniMag Pro 10000mAhのメーカー公開仕様の欄には、有線最大30W（Type-C）と記載されています。ケーブルの規格によっては、記載の出力に届かない場合があります。

Q.何色がありますか？

TORRAS MiniMag 5000mAhの仕様表にはスペースグレー、TORRAS MiniMag Pro 10000mAhの仕様表には月灰・グレーと記載されています。TORRAS MiniMag Pro 10000mAhのメーカー公開仕様の欄には、月灰、雲紫、島青、Stellar Pinkの4色が記載されています。購入できる色は、Amazon商品ページでご確認ください。

Q.保証期間はどれくらいですか？

TORRAS MiniMag Pro 10000mAhのメーカー公開仕様の欄に、保証期間はご購入日より1年間と記載されています。TORRAS MiniMag 5000mAhのページには、保証期間の記載がありません。

Q.PSE認証の記載はどのページにありますか？

TORRAS MiniMag 5000mAhは、商品説明にPSE＆CCC認証済み、メーカー公開仕様の欄にPSE認証：取得済みと記載されています。TORRAS MiniMag Pro 10000mAhは、仕様表にPSEの記載がありません。購入前にAmazon商品ページでご確認ください。

Q.モバイルバッテリー選びの基本を知りたいときは？

容量や出力の見方はモバイルバッテリーの選び方ガイド、ほかの機種はモバイルバッテリーの比較でご覧いただけます。
