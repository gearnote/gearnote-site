02違いのまとめ

  • ドライバーは、TOUR PRO 3のメーカー公開情報の欄に「10.2mmダイナミックドライバー＋5.1×2.8mmバランスド・アーマチュア」、LIVE BUDS 4に「10mmドライバー」と記載されています。感度とインピーダンスは、TOUR PRO 3が104dB・32Ω、LIVE BUDS 4が106dB・16Ωです。
  • Bluetoothのバージョンは、TOUR PRO 3が5.3、LIVE BUDS 4が6.0と記載されています。LIVE BUDS 4のページには、LE AudioとAuracast対応の記載もあります。
  • 最大再生時間は、イヤホン本体がTOUR PRO 3でANCオフ時11時間・ANCオン時8時間、LIVE BUDS 4でANCオフ時10時間・ANCオン時8時間です。ケース込みは、TOUR PRO 3が44時間（ケースのバッテリー寿命は最大33時間）、LIVE BUDS 4が48時間（同最大30時間）と記載されています。
  • 付属品は、TOUR PRO 3がUSB Type-C to アナログ3.5mmケーブルを含み、シリコンイヤーチップ5サイズとフォームイヤーチップ1サイズ、LIVE BUDS 4がイヤーチップ4サイズと記載されています。
  • 防水防塵（IP55）、マイク6個、充電時間2時間、連続通話時間5.5時間、スマートタッチディスプレイ付きケース、マルチポイントとトゥルー・アダプティブ・ノイズ・キャンセリング 2.0の記載は、両ページで共通です。
  • 重量は、JBL TOUR PRO 3のページのメーカー公開情報の欄に「重量欄83g、チャージングケースの重量71.8g、イヤーピースの重量5.6g」、JBL LIVE BUDS 4のページに「重量欄80.6g、チャージングケース71g、イヤーピース9.6g」と記載されています。「重量欄」が何を指すかは、どちらのページにも説明がありません。
  • ノイズ制御の表記は、JBL TOUR PRO 3のページの仕様表が「ハイブリッドノイズキャンセリング」、メーカー公開情報の欄の特徴が「トゥルー・アダプティブ・ノイズ・キャンセリング 2.0」と記載されています。JBL LIVE BUDS 4のページの仕様表は「True Adaptive Noise Cancelling 2.0（アクティブ・アダプティブ・ハイブリッド）」です。同じ名称に見えて表記が分かれているため、方式の違いを数値で比べることはできません。
  • Auracastは、JBL LIVE BUDS 4のページの仕様表に「LE Audio、Auracast対応」と記載されています。JBL TOUR PRO 3のページの仕様表には記載がありませんが、メーカー公開情報の欄の特徴に「Auracast対応」とあります。ワイヤレス充電は、JBL TOUR PRO 3のページの機能欄に記載があり、JBL LIVE BUDS 4のページではメーカー公開情報の欄の充電時間の項目に「ワイヤレス充電は「有」」と記載されています。

  • ハイブリッドノイズキャンセリング搭載のイヤホンを探している人
  • ケースのスマートタッチディスプレイやワイヤレス充電など、多機能なモデルを求める人
  • 2台同時接続のマルチポイントを使いたい人

▸JBL LIVE BUDS 4が向いている人

LIVE BUDS 4のページでは、バッズスタイルの本体にBluetooth 6.0、LE Audio、Auracastの記載があり、ケース込み最大48時間再生のモデルと説明されています。

  • ケースのディスプレイで操作したい人
  • メーカーの仕様で再生時間と防水等級（IP55）を確認して選びたい人
  • ノイズキャンセリング付きの小型イヤホンを探している人

04場面別の選び方

使う場面ごとに、各商品ページの記載で見ておきたい点をまとめました。あくまで掲載情報にもとづく目安です。

  • スマホとパソコンを行き来しながら使うなら：マルチポイントは、JBL TOUR PRO 3のページの機能欄に記載があり、JBL LIVE BUDS 4のページではメーカー公開情報の欄の特徴に「有」と記載されています。2台同時に待ち受けできる機能で、切り替えの手間を減らしたい場面が想定されます。使えるコーデックが制限される機種もあるため、取扱説明書の確認が必要です。
  • イヤーチップのサイズ選びで失敗したくないなら：同梱品は、JBL TOUR PRO 3のページに「シリコンイヤーチップ5サイズ＋フォームイヤーチップ1サイズ」、JBL LIVE BUDS 4のページに「イヤーチップ4サイズ×左右各1」と記載されています。選べるサイズが多いのはJBL TOUR PRO 3のページの記載です。ノイズキャンセリングは装着の密着具合で感じ方が変わるとされるため、サイズ違いの有無は目安になります。
  • 有線接続の機器ともつなぎたいなら：JBL TOUR PRO 3のページの同梱品に「USB Type-C to アナログ3.5mmケーブル」と記載されています。JBL LIVE BUDS 4のページの同梱品には、このケーブルの記載がありません。アナログ入力のある機器で使えるかどうかは、機器側の端子もあわせて確認してください。
  • 新しい無線規格を試したいなら：Bluetoothのバージョンは、JBL TOUR PRO 3が5.3、JBL LIVE BUDS 4が6.0と記載されています。JBL LIVE BUDS 4のページにはLE AudioとAuracastの記載があります。これらを使うには、接続する側の機器も対応している必要があります。
  • 1回の外出で充電を挟まず使いたいなら：イヤホン本体の最大再生時間は、ANCオン時が両方とも8時間です。ANCオフ時はJBL TOUR PRO 3が11時間、JBL LIVE BUDS 4が10時間と記載されています。ケース込みの最大再生時間は、JBL TOUR PRO 3が44時間、JBL LIVE BUDS 4が48時間です。ケースのバッテリー寿命は、JBL TOUR PRO 3が最大33時間、JBL LIVE BUDS 4が最大30時間と記載されています。

05スペック用語のかんたん解説

比較表に出てくる用語を、一般的な意味で簡単に説明します。数値や対応の有無は各商品ページ・Amazon商品ページでご確認ください。

▸ダイナミックドライバーとバランスド・アーマチュア

ダイナミックは振動板を動かして音を出す一般的な方式で、バランスド・アーマチュア（BA）は小型の部品で特定の音域を受け持つ方式とされます。両方を組み合わせた構成は、音域ごとに役割を分けるねらいがあります。JBL TOUR PRO 3のページに「10.2mmダイナミックドライバー＋5.1×2.8mmバランスド・アーマチュア」、JBL LIVE BUDS 4のページに「10mmダイナミックドライバー」と記載されています。数だけでは音の好みは判断できません。

▸感度（dB）とインピーダンス（Ω）

感度は同じ入力に対する音の大きさの目安、インピーダンスは電気的な抵抗の値です。一般に、これらの数値だけで音質の優劣は決まりません。JBL TOUR PRO 3のページに「104dB、32Ω」、JBL LIVE BUDS 4のページに「106dB、16Ω」と記載されています。

▸IP55

IPコードは防塵と防水の等級を表す国際規格の表記です。JBL TOUR PRO 3のページでは、IP55は粉塵に対する保護（5）と噴流水に対する保護（5）の等級と説明されています。JBL TOUR PRO 3のページには、水没に耐える等級ではない旨の記載があります。

▸LE AudioとAuracast

LE Audioは新しいBluetoothの音声規格で、Auracastはその仕組みを使って1つの音源を複数の機器に届ける機能とされます。使うには、スマホや放送側の機器も対応している必要があります。JBL LIVE BUDS 4のページの仕様表と、JBL TOUR PRO 3のページのメーカー公開情報の欄に、Auracast対応の記載があります。

▸コーデック（LDACなど）

コーデックは、Bluetoothで音を送るときの圧縮方式です。再生側の機器との組み合わせで使える方式が決まります。JBL TOUR PRO 3とJBL LIVE BUDS 4のページの仕様表にLDAC対応の記載がありますが、どちらもAmazon掲載情報で、メーカーの仕様欄には記載がないと注記されています。

06購入前のチェックリスト

購入前に見ておくと安心な項目です。各商品ページの記載にもとづくため、最終的にはAmazon商品ページの最新情報もご確認ください。

  • 対応コーデック：LDACの記載はAmazon掲載情報のみで、メーカーの仕様欄には両ページとも記載がない。重視するなら、購入前にAmazon商品ページと取扱説明書で確認する。
  • 使う端末：LE AudioとAuracastは、スマホなど接続側の対応も必要。手持ちの機器がBluetooth 6.0やLE Audioに対応しているか確認する。
  • イヤーチップ：JBL TOUR PRO 3はシリコン5サイズとフォーム1サイズ、JBL LIVE BUDS 4は4サイズが同梱。耳に合うサイズを選び、装着後の密着感を確かめる。
  • ケースの画面：どちらもスマートタッチディスプレイ付きケース。JBL LIVE BUDS 4は日本語表示に対応と記載があるが、JBL TOUR PRO 3はケース画面で操作できる項目がメーカー仕様欄に記載なし。
  • ワイヤレス充電：使うにはQi規格の充電器が必要。ケースカバーを付けていると充電できない場合があると、JBL TOUR PRO 3のページに記載がある。
  • 型番と色：JBL TOUR PRO 3はJBLTOURPRO3BLK、JBL LIVE BUDS 4はJBLLIVEBUDS4BLK。どちらもブラックのページ。保証や交換部品の確認には型番を使う。

07よくある質問

Q.JBL TOUR PRO 3とLIVE BUDS 4の主な違いは何ですか？

各商品ページの記載では、ドライバー構成（TOUR PRO 3はダイナミック＋バランスド・アーマチュア、LIVE BUDS 4は10mm）、Bluetoothのバージョン（5.3と6.0）、再生時間（ケース込みで44時間と48時間）、付属品の内容が異なります。防水防塵のIP55とANCオン時8時間は共通です。

Q.どちらもLDACに対応していますか？

TOUR PRO 3のページには「LDAC（Amazon掲載情報。メーカーの仕様欄には記載なし）」、LIVE BUDS 4のページには「ハイレゾ認証・LDAC対応はAmazon掲載情報。メーカーの仕様欄には記載なし」と記載されています。どちらもLDACの記載はAmazon掲載情報のみで、メーカーの仕様欄にはどちらも対応コーデックの記載がないため、使う端末側の対応とあわせて、購入前にAmazon商品ページで確認してください。

Q.防水防塵の等級に違いはありますか？

メーカー公開情報の欄では、どちらのページにも「IP55（防滴『有』）」と記載されています。等級は同じです。

Q.どちらを選べばいいですか？

デュアルドライバー構成、ワイヤレス充電、3.5mmアナログケーブルの付属の記載を重視するならTOUR PRO 3のページが候補になります。Bluetooth 6.0、LE AudioとAuracastの記載、ケース込み48時間の再生時間を重視するならLIVE BUDS 4のページを確認するとよいでしょう。イヤホン選び全般はワイヤレスイヤホンの選び方ガイドもご覧ください。

Q.マルチポイントに対応しているのはどちらですか？

JBL TOUR PRO 3のページの機能欄に「マルチポイント」と記載されています。JBL LIVE BUDS 4のページの仕様表には記載がありませんが、メーカー公開情報の欄の特徴に「マルチポイント」が「有」と記載されています。

Q.ワイヤレス充電は使えますか？

JBL TOUR PRO 3のページの機能欄に「ワイヤレス充電」と記載されています。JBL LIVE BUDS 4のページの仕様表には記載がありませんが、メーカー公開情報の欄に「急速充電・ワイヤレス充電は「有」」と記載されています。使うにはQi規格の充電器が必要で、対応する出力などは取扱説明書で確認してください。

Q.Auracastに対応していますか？

JBL LIVE BUDS 4のページの仕様表に「LE Audio、Auracast対応」と記載されています。JBL TOUR PRO 3のページの仕様表には記載がありませんが、メーカー公開情報の欄の特徴に「Auracast対応」とあります。どちらも、使うには接続側の機器の対応が必要です。

Q.付属品に違いはありますか？

JBL TOUR PRO 3のページには、スマート充電ケース、USB Type-C to Type-Cケーブル、USB Type-C to アナログ3.5mmケーブル、USB Type-C充電用ケーブル、シリコンイヤーチップ5サイズ＋フォームイヤーチップ1サイズなどが記載されています。JBL LIVE BUDS 4のページには、充電ケース、イヤーチップ4サイズ、保証書、クイックスタートなどが記載されています。JBL LIVE BUDS 4のページの同梱品には、充電ケーブルやアナログケーブルの記載がありません。

Q.通話に関する仕様は違いますか？

どちらのページにも、マイク6個、連続通話時間5.5時間、充電時間2時間と記載されています。通話中の聞こえ方を示す数値は、どちらのページにも記載がありません。

Q.ケースのバッテリー寿命は同じですか？

ケース込みの最大再生時間はJBL TOUR PRO 3が44時間（ケースのバッテリー寿命は最大33時間）、JBL LIVE BUDS 4が48時間（同最大30時間）と記載されています。ケース込みの時間はイヤホン本体の再生時間を含む値なので、ケースだけで何回充電できるかは、ページの記載からは読み取れません。

Q.ほかのイヤホンも見比べたいときは？

イヤホンの装着タイプやノイズキャンセリングの見方はワイヤレスイヤホンの選び方ガイド、同じブランドの商品はJBLの商品一覧でご覧いただけます。
